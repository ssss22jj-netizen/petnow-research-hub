# 비문 wants 조사: 펫 신분증·디지털 ID 사업체 목록

확인일: 2026-09-16 · 미국·캐나다·영국 등 영어 판매 사이트의 공개 상품 안내 기준

## 집계 결과

- 사진 카드·신분증 상품을 안내하는 서로 다른 판매 브랜드/사이트 **9곳** 확인. 펫 신분증·선물 브랜드 5, 등록 서비스 Petkey 1, 범용 ID 인쇄사 3으로 구분.
- QR/NFC 태그와 디지털 프로필 서비스를 기준으로 범위를 넓히면 **추가 8곳**, 이번 조사 명단 **총 17곳**. 카드와 QR를 함께 파는 MyPetDMV·TheDogBadge·Petkey는 중복 합산하지 않음.
- 이 수는 **이번에 이름·상품을 확인한 관측 수**. 전체 시장 사업체 수의 추정치, 등록 법인 전수조사, 기술 도입 적격 업체 수, 광고 매체 도달 가능 계정 수는 아님. 독립 브랜드를 우선 집계하고 같은 주문경로는 합침. 모든 업체의 최종 지배주주·계열관계까지 검증한 것은 아님.
- 시장 전체 사업체 수를 산출할 직접 통계/완전한 명부는 이번 검색에서 확보하지 못함. 검색 결과 수·상품 수·리뷰 수로 업체 수를 외삽하지 않음. 공식 판매 안내를 확인했으며 실제 주문·결제·연동·최근 영업 활동을 시험하지 않음.

## 중복·제외·확인 한계

- **PetDriversLicense.com 제외:** Design Now가 MyPetDMV 주문경로로 이동함. 별도 사업체로 합산하지 않음. [확인한 이동 링크](https://www.petdriverslicense.com/product/custom-design/), [도착 주문경로](https://www.mypetdmv.com/card_maker/order_petdmv_form.php).
- TheDogBadge는 홈페이지 직접 요청이 시간 초과였으나 공식 컬렉션 본문·일반 펫 신분증·가격·등록/조회 메뉴 확인. 서비스견 배지 상품만으로 포함한 것이 아님. 본사 소재와 실제 기술 소유권은 미확인.
- The Bonny Burrows Co와 Secure ID의 파싱 본문에는 `Sold out`과 `Add to cart`가 함께 나타남. 판매 안내 존재만 확인했으며 실재고·현재 주문 가능성을 확정하지 않음.
- 범용 인쇄사 3곳은 기존 상품 존재만 확인한 확장 후보. 자체 펫 고객 기반·디지털 서비스 운영 의사·펫나우 도입 권한을 검증한 것이 아님.
- Etsy에서 PetMorphStudio·BeamMeUpCrafts·SeekForAdventure·PankasLife 등 추가 상점/상품이 노출됨. 독립 운영 규모·중복 및 디지털 서비스 적용 주체 확인 전 이번 17곳에 합산하지 않음. 제품 검색 결과를 사업체 총수로 바꾸지 않음.
- PetNIC(파키스탄), PetHubPH(필리핀) 등은 지리 범위 차이로 합산하지 않음. 서비스견/ESA 증명 판매사, 일반 각인 태그만 파는 업체, 마이크로칩 전용 DB, GPS 전용 업체도 제외.
- 기존 계약 고객은 신규 후보 집계에서 제외. ByFido는 MyPetDMV의 제휴 기술 공급자로, 이번 보호자 대상 판매사 명단과 별도 취급.

## 업체 규모를 보여주는 참고 지표

- TagsforHope 홈페이지는 **100만+ 반려동물**, **22,000+ 5점 후기**를 자체 표기. 태그 외 목줄·하네스·액세서리를 포함한 브랜드 전체 안내로, ID 카드 연간 판매량·매출·독립 구매자 수로 환산하지 않음. [홈페이지](https://www.tagsforhope.com/), [브랜드 연혁](https://www.tagsforhope.com/our-story/).
- PetHub QR 상품 페이지는 **100만+ 보호자**를 자체 표기. 누적·기간·활성의 구분과 외부 감사 여부 미확인. 시장 업체 수를 나타내는 숫자가 아님. [상품 페이지](https://shop.pethub.com/products/pick-your-style-qr-id-pet-tag).
- MyPetDMV 등의 직원 수·연간 매출은 신뢰도 있는 공개 근거를 이번 조사에서 확보하지 못함. 디렉토리 추정 매출·트래픽을 사실로 사용하지 않음.

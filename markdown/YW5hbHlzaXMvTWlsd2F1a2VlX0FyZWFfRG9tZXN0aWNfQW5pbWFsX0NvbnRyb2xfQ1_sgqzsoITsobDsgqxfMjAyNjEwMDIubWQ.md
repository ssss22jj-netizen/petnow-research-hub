## 미팅에서 바로 쓸 핵심 5줄

1. **레스큐가 아니라 연 13,138마리를 처리하는 지방정부 합동기관이다 — 2026년 총예산 $4,780,699, 상근 34 FTE.** 2026 예산서 회원청구 시트의 "Animals Handled" 실적이 2022년 10,958 → 2023년 11,738 → **2024년 13,138마리**이고, 그 중 80.7%가 Milwaukee 시 건이다. 기부·소규모 운영 화법을 쓰면 첫 1분에 어긋난다
2. **콜 6일 전(2026-10-01) Karen 본인 서명으로 「신규 입양·전원 전략」을 공표했고, 그 안에 우리 제품이 들어갈 자리가 그대로 적혀 있다.** ①개 전체에 **체류일수 기반 입양비 인하**(14일 경과 후 인하, 이후 7일마다 재인하) ②**3단 우선순위 전원 홀드 큐**(Tier1 스트레이홀드 중 선점 / Tier2 Day5 19:00 / Tier3 Day6 19:00). 둘 다 개체별 체류 시계와 예약 상태를 상시 들여다봐야 성립한다
3. **포스터·오프사이트 업데이트가 Chameleon 밖 4개 경로로 들어온다.** Weekenders 는 사진·영상을 **`k***@madacc.org` 로 메일**, 행동·성격 리포트는 **종이로 개와 함께 반납**, 반납 전 **온라인 서베이** 별도 작성, 게재용 사진·설명은 **`f***@madacc.org` 로 보내 담당자가 Petfinder 에 수기 업로드**한다. 포스터 보호 중인 고양이 입양 신청은 **구글폼**이다. 소재 B(임시보호자 업데이트 수집)에 반응한 지점이 여기일 개연이 가장 크다
4. **오프사이트 프로그램이 4종 동시 운영인데 조직도상 담당은 Volunteer/Outreach Coordinator 1명이다.** 전통 포스터 / Adoptioneers(포스터가 직접 입양 성사) / Weekenders(주말 1박) / Fido Field Trips(당일 4~8시간, 일정은 **Calendly**) + WHS 공동 `Home Stretch`. 2025 예산서는 이 1인이 "**175명 넘는 자원봉사자** 지도 + 오프사이트 포스터 조정"을 함께 맡는다고 적고 있다
5. **구매 결정은 ED 재량 + 10월 전체 이사회 예산 승인 2단이고, 지금이 그 창이다.** 2026-08-18 회의록에 "**2027 예산 작업 중, 직무 재배치 중**" 이 명시돼 있고, 2027 예산 승인 이사회는 **2026-10-20**(콜 13일 뒤)다. 다만 2026년 IT 소프트웨어 자본지출 라인은 **$6,000** 뿐이다 — 금액 프레임을 여기에 맞춘다

- **포스터·오프사이트 복귀 보고가 Chameleon 밖 4경로로 들어온다.** Weekenders 규정 원문 — 반납 전 온라인 서베이 작성 / 행동·성격 메모는 **종이 Itinerary/Report 로 개와 함께 반납** / 사진 5장 이상·30~90초 영상은 `k***@madacc.org` 로 메일 / 게재용 사진·설명은 `f***@madacc.org` 로 보내 **담당자가 Petfinder 에 수기 업로드**. 네 경로가 한 개체 기록으로 합쳐지는 지점이 공개 자료에 없다. (근거 있음 / 합류 지점은 **직접 확인 필요**)
- **포스터 보호 중 동물의 입양 접수가 구글폼이다.** 3페이지 폼의 첫 문항이 입양희망자가 직접 타이핑하는 `Animal ID #` 다. ID 오기·중복·누락이 발생하면 사람이 대조해 바로잡아야 하고, 접수 내용을 Chameleon 으로 옮기는 것도 재입력이다. (근거 있음 / 재입력 여부는 **직접 확인 필요**)
- **공개 게재 89마리 vs 시설 내 116마리의 차이.** 24Petconnect 는 Chameleon 자동 연동이므로, 포스터 보호 중인 개체가 자동 게재 대상에 포함되는지가 갈린다. 포스터 고양이 입양을 별도 구글폼으로 받는다는 사실은 **포스터 중 개체가 표준 게재 흐름 밖에 있다**는 쪽을 가리킨다. (정황 / **직접 확인 필요**)
- **오프사이트 프로그램 4종이 각각 다른 도구로 돌아간다.** 전통 포스터·Adoptioneers(Volgistics 접수) / Weekenders(Volgistics + 종이 waiver + 메일) / Fido Field Trips(Calendly + Field Trip Agreement) / Home Stretch(WHS 로 넘어가 **타 기관 입양 프로그램에 편입**). 프로그램 간 개체 이동 시 상태를 누가 어디에 기록하는지 공개 자료에 없다. (근거 있음 / 기록 위치 **직접 확인 필요**)
- **담당이 1명으로 수렴한다.** 2025 예산서가 Volunteer Coordinator/Community Outreach director 1명에게 "175명 넘는 자원봉사자 지도 + 오프사이트 포스터 조정 + 19개 지자체 대상 마케팅·정보 배포"를 함께 부여했다. 조직도상 ED 직속 라인이 Operations Manager 와 이 자리 둘뿐이다. (근거 있음 / 현재 실제 인원은 **직접 확인 필요**)
- **2026-10-01 전략이 새로운 수기 작업을 두 건 추가했다.** ①개별 개의 체류일수를 보고 14일·21일·28일… 시점마다 입양비를 내리고 게시물·안내문·결제 금액을 맞춰야 한다 ②전원 파트너 3단 큐에 Day5 19:00·Day6 19:00 라는 시각 조건이 붙은 예약 선점을 운영해야 한다. Chameleon 은 체류일수를 계산할 수 있지만, **단계별 요금 자동 적용과 파트너 티어별 예약 큐는 표준 기능으로 확인되지 않는다**. 발표 직후라 아직 스프레드시트·메일로 돌릴 개연이 크다. (정황 / **직접 확인 필요 — 콜의 1번 질문**)
- **pathway 상태값이 이미 8종으로 정의돼 있다.** 직무기술서 원문 — Adoption Candidate / Transfer to Shelter / Transfer to Rescue / **Foster Care – Behavior** / **Foster Care – Medical** / **Hospice Foster** / Potential Euthanasia Candidate / Other. 같은 문서가 "**봉사자와 포스터로부터 행동 관찰과 이력을 수집**", "**새 정보가 들어오면 재평가**", "**쉘터 관리 시스템에 문서화**"를 모두 이 1인의 책임으로 적었다. 즉 포스터의 관찰이 기록에 닿는 경로가 사람 1명을 거친다. (근거 있음 / 그 직위가 채워졌는지는 **직접 확인 필요 — 공고는 CLOSED**)
- **동물 상태 조회가 사람 중개다.** 자원봉사 핸드북 원문 — "알고 지낸 동물이 어떻게 됐는지 모르겠으면 **직원에게 묻지 말고 Volunteer Coordinator 를 찾아가라**". 결과 정보가 봉사자·포스터에게 셀프서비스로 열려 있지 않다. (근거 있음)
- **입양 심사가 현장·대면 중심이다.** Pre-Select 안내 원문 — 직접 방문 권유, 현장에서 `Adopter Profile` 작성, "**전화로는 동물에 대한 질문에 답하지 않는다**", "**프런트 직원은 입양 가능 동물 정보를 갖고 있지 않다**". 입양 가능 여부·보유 상태가 부서 간에 공유되지 않는 구조를 시사한다. (근거 있음 / 내부 공유 수단은 **직접 확인 필요**)
- **월별 통계·재무 보고가 consent agenda 로 일괄 승인된다.** 2026년에 운영위가 그 방식으로 전환했다. 보고서 자체는 매월 만들어야 하므로 **집계 산출물을 누가 어떻게 만드는지**가 숨은 수기 업무일 수 있다. Operations Manager 직무 목표에 "의사결정용 통계 데이터 생성"이 들어 있다. (정황 / **직접 확인 필요**)
- **범백 유행 중이다(2026-08~).** 격리·접수중단·코호트 관리가 겹쳐 개체별 상태 추적 부하가 평시보다 높다. 다만 질병 대응을 영업 소재로 쓰면 안 되고, "지금 가장 손이 많이 가는 게 무엇인지" 를 묻는 각도로만 쓴다. (근거 있음)

## 미확인 요약 (콜에서 확인할 것)

1. **2026-10-01 전략의 두 신규 메커니즘을 지금 무엇으로 돌리는지** — 개별 개의 체류일수 시계와 단계별 입양비 인하를 Chameleon 이 자동으로 계산·반영하는지, 전원 파트너 3단 홀드 큐(Day5 19:00 / Day6 19:00)를 어디서 운영하는지. 스프레드시트·메일이면 우리 제안의 자리가 바로 생긴다
2. **포스터 가정 수와 프로그램별 분포** — 폼 자기보고 `More than 30` 의 실제 숫자, 그리고 전통 포스터 / Adoptioneers / Weekenders / Fido Field Trips / Home Stretch 각각 현재 몇 가정·몇 마리인지. "승인된 가정" 과 "지금 동물을 보고 있는 가정" 을 분리해 받는다
3. **포스터에게서 오는 정보가 개체 기록에 닿는 경로** — 온라인 서베이·종이 Itinerary·`khartlund@` 메일·`foster@` 메일 네 갈래가 Chameleon 의 개체 기록으로 합쳐지는지, 합친다면 누가 언제 손으로 옮기는지, 아니면 받은편지함에서 끝나는지
4. **`Animal Pathways & Assessment Specialist` 자리가 채워졌는지** — 채워졌다면 pathway 8종 상태값을 Chameleon 의 무엇으로 관리하는지(필드·메모·외부 시트), 재평가 이력이 남는지. 공석이면 그 판단을 지금 누가 하는지
5. **Chameleon 의 가동 범위와 Volgistics 연동** — 의료·전원·포스터 모듈이 켜져 있는지, Volgistics 의 포스터 명부와 Chameleon 의 개체 기록이 연결돼 있는지, 아니면 두 시스템을 사람이 눈으로 맞추는지
6. **조달 전결 한도와 2027 예산 창** — ED 단독 집행 가능 금액, 2027 예산(2026-10-20 승인 예정)에 소프트웨어 항목을 넣을 여지가 있는지, 아니면 2026년 `IT Equipment/Software` $6,000 안에서 시작해야 하는지
7. **공식 라이브릴리스율과 월별 집계 생산 방식** — 조직 공표 LRR 기준과 최신 수치, 그리고 월별 Animal Disposition Report·Transfer Metrics 를 무엇으로 만드는지(Chameleon 리포트 / 엑셀 수작업)
8. **포스터 접수 단계에서 무엇을 묻는지** — Volgistics 폼을 판독하지 못했다. 가정별 수용 조건(크기·연령·의료 난이도·가용 시점·동시 수용 두수)을 접수에서 받는지, 배치 판단은 누가 무엇을 보고 하는지

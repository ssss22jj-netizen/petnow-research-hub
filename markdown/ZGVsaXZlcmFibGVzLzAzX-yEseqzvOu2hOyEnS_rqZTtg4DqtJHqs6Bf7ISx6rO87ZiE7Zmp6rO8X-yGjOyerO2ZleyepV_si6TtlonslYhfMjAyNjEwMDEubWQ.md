# 메타 광고 성과 현황과 소재 확장 실행안

기준일 2026-10-01 · Petify for Shelters 메타 광고 A·B · 운영 제안

- **현재 신호 · 클릭 반응 약화**<br>A·B 합산 · 8/31~9/13 → 9/14~27<br>클릭률 **1.30% → 1.03%**<br>랜딩 도달당 비용 **$1.22 → $1.61**
- **대응 방향 · 이미지 표현 테스트**<br>인터뷰에서 관심을 확인한 **메시지는 유지**<br>소재 피로 확정이 아닌 **반응 개선 실험**
- **실행안 · A·B 각 1장 추가**<br>기존 주력과 병행<br>**총 주 예산 30만원 안에서 운영**

## 1 현황 판단과 대응 이유

- **A:** 동물별 상태·다음 할 일 확인 / **B:** 임보자 미응답 확인·후속 연락

| 확인한 신호 | 해석 | 대응 |
| --- | --- | --- |
| **광고를 보여주는 비용은 비슷하지만 클릭과 방문이 감소**<br>A·B 합산 · **8/31~9/13 → 9/14~27**<br>노출 1천 회 비용 $14.64→$14.71<br>링크 클릭률 **1.30%→1.03%**<br>랜딩 도달 **345→268회** | 광고 반응을 개선할 필요.<br>클릭률 하락만으로 소재 피로를 확정할 수는 없음 | **새 이미지의 클릭 반응을 테스트.**<br>기존 주력과 병행해 반응이 더 나은 표현 탐색 |
| **리드도 줄었으나 소재별 우열 판단에는 표본 부족**<br>A·B 합산 · **8/31~9/13 → 9/14~27**<br>리드 **24→11건**, 리드당 비용 **$17.59→$39.18**<br>리드 전환율 **7.0%→4.1%**<br>최근 11건 중 A 3건·B 8건 | 방문 이후 전환율도 하락해, 이미지 테스트만으로 리드 회복을 설명하기 어려움.<br>적은 리드 건수로 현재 CPL 차이에 따른 A·B 우열 판단도 어려움 | **A·B 예산 재배분과 기존 광고 전면 교체는 보류.**<br>기존 리드 유입을 이어가며 각 세트에서 신규안 시험 |

## 2 액션플랜

**이번 목표: 기존 리드 유입을 이어가면서, 클릭·랜딩 방문 비용을 개선할 이미지 확보.**

### 캠페인 운영

**기존 A·B 세트에 새 이미지 각 1장 추가, 기존 주력 광고와 병행.**

- **예산:** A 주 15만원 + B 주 15만원 = 총 주 30만원 유지. 추가 지출 없이 신규안을 시험하는 초기 운영안.
- **변경 범위:** 이미지 구도. 메시지·카피·랜딩·타깃은 유지.

### 소재 제작 방향

**일부 인터뷰에서 기존 광고·랜딩의 업무 메시지에 관심을 보인 이유를 확인. 이번에는 이 메시지를 유지한 채, 해당 업무 화면을 더 크게 보여주는 이미지부터 시험하는 순서 제안.**

| 소재 | 기존 이미지에서 바꿀 부분 | 유지할 메시지의 인터뷰 근거 |
| --- | --- | --- |
| **A 신규 1장** | 인물·시설 배경 비중을 줄이고<br>**동물별 현재 상태와 다음 할 일**을 크게 제시 | Luzerne: 상태 화면 광고에 관심.<br>PAWS & More: 남은 업무를 보여주는 랜딩 설명에 반응 |
| **B 신규 1장** | 인물·시설 배경 비중을 줄이고<br>**미응답 목록과 원탭 리마인더**를 크게 제시 | Kzoo: 임보 소통 개선 때문에 광고 클릭.<br>Beatrice: 정기 확인 누락을 2~3주 뒤 발견 |

- 인터뷰는 **메시지를 유지할 근거**이며, 업무 화면 확대가 광고 성과를 높인다는 것은 **이번에 확인할 제작 가설**.
- 제공 가능한 기능만 표현하고, 모바일에서 업무 화면과 문구가 읽히는지 확인 후 제작 완료.

### 투입 후 확인할 것

**10/7 투입 가정. 신규 A는 기존 A-1 needs, 신규 B는 기존 B-2 noanswer와 각각 동일 기간 비교.**

| 일정 | 확인할 내용 | 결과에 따른 조치 |
| --- | --- | --- |
| **10/7 투입** | A·B 신규 이미지 각 1장 등록 | 각 세트에서 기존 주력과 병행 |
| **10/14 집행 점검**<br>10/7~13 집계 | 신규 광고에 실제 노출·클릭이 배분됐는지 확인 | 거의 노출되지 않았다면 실패로 판정하지 않음.<br>다음 시험은 **후보 1개를 신규 전용 세트에서 운영**하는 방식으로 조정.<br>기존 주력 예산 일부를 사용해 총 주 30만원 유지 |
| **10/21 반응 점검**<br>10/7~20 집계 | **신규 광고와 각 세트 기존 주력의 클릭률·랜딩 도달당 비용** 비교 | 신규안의 **클릭률이 높고 방문 비용이 낮으면 추가 운영**.<br>반대 방향이면 이미지 수정 후보로 분류.<br>노출·클릭이 적거나 지표가 엇갈리면 판단 유보 |

- 위 비교는 **다음에 운영할 소재를 고르는 참고**. 자동 배분으로 노출 대상이 달라지므로 이미지의 인과효과나 통계적 승자를 확정하는 실험은 아님.
- **증액은 이번 테스트 범위에서 제외.** 리드 수·리드 전환율·리드당 비용은 함께 기록하되, 적은 리드 건수로 신규안의 획득 효율을 단정하지 않음.

<summary>판단의 한계</summary>

- **리드 표본:** 최근 2주 11건. 비용 상승의 지속성·메시지 우위·랜딩 문제를 확정할 규모는 아님.
- **피로 원인:** 주간 빈도 안정이 누적 피로를 배제하지는 않음. 누적 평균만으로 개별 사용자의 피로 발생도 확인 불가.
- **다른 원인:** 노출 단가 안정만으로 잠재고객 구성·수요·경쟁 변화를 배제할 수 없음.
- **전환율 하락:** 방문자 구성 변화·랜딩/폼 문제·소표본 변동 등 여러 설명 가능. 현재 자료만으로 랜딩 문제나 지속적인 전환율 저하를 확정하지 않음.
- **예약 슬롯:** 리드 제출 이후 단계. 추석 기간 슬롯 부족을 리드 감소의 직접 원인으로 해석하기 어려움.

</details>

## 3 액션플랜

### 캠페인 구조와 일정

**기존 캠페인 유지 · A·B 세트에 새 이미지 각 1장 추가**

- **예산:** A 주 15만원 + B 주 15만원 = **총 주 30만원**.
- **유지:** 기존 주력 광고·타깃·최적화·카피·랜딩.
- **유지 근거:** 기존 광고에서도 최근 2주 리드 11건 발생.
- **시험 목적:** 이미지 외 조건을 유지해 새 이미지의 반응 확인. 소재 피로 입증이 아니라 개선 효과 확인을 위한 운영 시험.
- **제작 우선순위:** A·B 각 1장이 기본. 한 장만 가능하면 개선할 장면과 인터뷰 근거가 더 구체적인 안을 선택. 현재 리드당 비용만으로 A 또는 B 우선을 결정하지 않음.

| 일정 | 실행 | 판단 기준 |
| --- | --- | --- |
| **10/7 투입** | 기존 A·B 세트에 신규 광고 각 1개 추가 | 기존 주력과 함께 운영 |
| **10/14 신규 광고 집행 점검** | 신규 광고의 지출·노출·클릭 확인 | 노출 부족은 **미검증**으로 분류 |
| **10/21 성과 판단** | 기존·신규 광고의 같은 기간 클릭률·랜딩 도달당 비용·리드 수·리드 전환율·리드당 비용 비교 | **유지 후보 / 수정 후보 / 미검증**으로 분류 |

<details>
<summary>신규 광고의 노출이 부족할 때 검토할 운영안</summary>

- **조건:** 미검증 소재를 이번 기간에 확인할 필요가 있을 때, 후보 1개만 신규 전용 세트로 1주 시험.
- **배분 예시:** 해당 세트의 주 15만원을 기존 10만원·신규 5만원으로 나누고, 다른 세트 15만원은 유지. **총 주 30만원 유지**.
- **판단:** 기존 광고의 리드 공급 감소 가능성을 함께 고려. 10만/5만원 배분은 운영 제안이며 검증된 최적 비율은 아님.
- **분리·중단:** 노출 부족만으로 자동 결정하지 않음.
- **주력 중단·증액:** 클릭률만으로 결정하지 않고 리드 성과도 확인.
- **성과 판정:** 임의의 노출 합격선이나 기간 경과만으로 통계적 승자를 확정하지 않음.

</details>

### 소재 확장 방향

- **1차 방향:** 기존 메시지 유지 · 제품 화면 구체화

| 순서 | 보여줄 장면 | 인터뷰 근거 |
| --- | --- | --- |
| **1차 A** | **동물별 현재 상태 + 다음 할 일** 확대 | Luzerne: 상태 화면 광고에 관심.<br>PAWS & More: 남은 업무를 보여주는 랜딩 설명에 반응 |
| **1차 B** | **미응답 목록 + 원탭 리마인더** 확대 | Kzoo: 임보 소통 개선 때문에 광고 클릭.<br>Beatrice: 정기 확인 누락을 2~3주 뒤 발견 |
| **후속 신규 메시지**<br>1차 결과 확인 후 검토 | **담당자 부재에도 이어지는 팀 인계** | Love’s·Black Dog·Cactus: 정보 전달·중복 연락·인계 문제 반복 |
| **B 보조 설명** | **앱·로그인 없이 링크로 응답** | Cactus·Noah’s: 데모 중 긍정 반응.<br>광고 클릭 동기로는 아직 미검증 |

- **화면 구성:** 약 3행 · 행별 정보 2~3개 · 배경 최소화
- **B 기능 표현:** 원탭 리마인더 유지 · 제작 전 제공 가능한 기능 확인
- **표현 범위:** 데모 화면을 구현 완료 기능으로 표현하지 않음

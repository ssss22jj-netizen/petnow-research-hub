# Petnow Shelter HTML pretotype

Clickable interview demo for the Track 2 LMF experiment.

## Run locally

```sh
python3 -m http.server 4173 --directory prototype
```

Open `http://localhost:4173`.

## Demo paths

- A — Readiness: Animals → Milo → Request update → Foster form → Staff review → Approve → Publish
- B — Foster updates: Updates or Foster link → Submit → Review → Approve
- C — Intake to publishing: Add animal → Save checklist, then Publishing → Publish to channels

All content is fictional demonstration data. No backend or external service is connected.

## 3. 절차 준수 여부

| 절차 항목 | v1 규칙 | 독립 실행 | 영향 |
| --- | --- | --- | --- |
| 검색 표면 | LinkedIn 사람 검색과 `site:linkedin.com/in` 검색을 각각 수행 | 공개 검색 결과 중심 | LinkedIn 로그인 검색에서 노출되는 후보 누락 |
| 검색 깊이 | 검색어당 LinkedIn 10페이지 또는 신규 후보 2페이지 연속 0명 | 대부분 검색어당 공개 결과 1페이지 | 후보 모집단 조기 고갈 |
| 목표 후보 수 | 50명 또는 전체 검색어 소진 | 23명에서 검색어 소진 판정 | 기존 53명과 표본 크기 불일치 |
| 고용형태 검증 | LinkedIn 경력 모두 표시·공식 자료·Form 990 | 공개 결과에서 직접 근거 미확보 | 전원 3순위 판정 |

독립 실행은 결과 파일 형식, 중복 제거, 미국 소재, 공란 처리 기준은 준수함. 다만 후보 발견과 우선순위에 가장 큰 영향을 주는 검색 표면·검색 깊이·프로필 직접검증 기준을 축소 적용함.

## 4. 재현 실패 원인

### 4.1 기존 목록의 모집단 미고정

- 기존 53명은 카야 사전 확보 후보, 공개 검색 후보, 조직별 추가 조사 후보, 후속 재감사 후보가 누적된 목록
- 절차 v1은 직함 검색어만 고정하고 기존 조사에서 사용한 조직 목록·검색 URL·검색 페이지를 고정하지 않음
- 동일 직함 검색어라도 LinkedIn 연결망, 검색 시점, 언어, 지역 설정에 따라 결과 순서 변경

### 4.2 검색 행동의 선택 여지

- `LinkedIn 검색과 일반 검색을 각각 사용`이라는 문구가 실행 도구와 페이지 수를 강제하지 못함
- 독립 세션이 공개 검색 결과를 더 안정적이라고 판단해 LinkedIn 검색 깊이를 임의로 축소
- `검색어 소진`의 정의가 검색어 입력 완료로 해석되어 목표 후보 50명 전에 종료

### 4.3 발견과 검증 절차 혼합

- 후보 발견에는 넓은 검색이 필요하지만 1차 편입 단계부터 현재성·개인 URL·미국 소재·업무 관련성을 동시에 요구
- 공개 검색 결과에서 상세 고용형태가 보이지 않아 다수 후보가 검증 단계에 진입하지 못함
- 고용형태 직접 근거를 확보하지 못한 후보 전원을 3순위로 판정하여 기존 1순위와 비교 불가

## 5. 절차 v2 필수 수정사항

| 수정 항목 | v2 기준 |
| --- | --- |
| 조직 모집단 | 기존 후보명을 제공하지 않고 조사 대상 조직 목록을 고정하여 조직별 현직자 탐색 |
| 검색 URL | 직함·지역별 LinkedIn 검색 URL과 일반 검색 쿼리를 실행 순서대로 명시 |
| 페이지 증거 | 검색 결과 페이지별 확인 일시·URL·확인 인원·제외 인원을 기록하지 않으면 검색 완료로 인정하지 않음 |
| 검색 깊이 | LinkedIn 10페이지를 실제 확인하거나, 2페이지 연속 신규 0명을 페이지별 로그로 입증해야 종료 가능 |
| 2단계 분리 | 발견 목록을 먼저 80명 이상 확보한 후 상세 검증을 수행하도록 분리 |
| 조직별 할당 | 조직당 운영·구매 1명과 현장 실무 1명을 우선 확보하며 조직당 최대 3명 제한 |
| 고용형태 재시도 | LinkedIn 경력 모두 표시 접근 실패 시 공식 팀·Form 990 검색을 의무화하고 검색식 기록 |
| 완료 승인 | 목표 미달 종료는 검색 로그의 필수 행이 모두 채워진 경우에만 허용 |

## 6. 실무 판단

- 현재 53명 목록: 검증된 운영 명단으로 사용 가능
- 절차 v1: 기존 후보의 고용형태·우선순위를 다시 판정하는 감사 지침으로 활용 가능
- 절차 v1: 후보를 처음부터 동일하게 발견하는 탐색 지침으로는 사용 불가
- 다음 재현 실험: 조직 모집단과 검색 URL을 고정한 절차 v2로 별도 실행 필요

## 한 줄 결론

1차 LMF에서 소재 A·B가 기준선을 넘겼고 리드가 계속 유입되고 있으므로, 다음 스프린트는 두 트랙으로 재편한다. **트랙 1**은 1차 LMF 리드로 지불 의향과 구매 전환을 확인하고, **트랙 2**는 1차 LMF와 같은 틀로 결이 다른 소재 2종(D 오너 연결·E 신규 인력)을 반복 집행한다. 두 트랙은 병행한다.

## 1. 배경

| 항목 | 1차 결과 | 출처 |
| --- | --- | --- |
| 문제 인식(CTR) | A 2.05% · B 2.73%. 둘 다 목표선 1.10%를 신뢰구간 하단까지 초과 | 중간 보고 §0 |
| 리드 | 9건(8/17 기준), 계속 유입 중. 부부 2인 조직부터 카운티 정부 기관까지 규모 스펙트럼 넓음 | 리드 시트 |
| A·B 우열 | 미확정(B 1.24배, 1.5배 기준 미달) | 중간 보고 §2 |
| 원래 트랙 1(네트워크·LinkedIn 탐색 인터뷰) | 섭외 속도 한계로 정체. LMF 광고가 인터뷰 리드 확보 역할을 대신하게 됨 | PROJECT_STATE |

- 1차 가설 풀은 데스크리서치·인터뷰 1건으로 구성돼 근거가 약했고, 상위 2개만 광고로 검증했다. 상위 2개가 통과한 지금, 검증의 다음 단계는 두 갈래다: 통과한 소구점으로 **돈을 내는지** 확인하는 것과, **결이 다른 축**에도 시장 반응이 있는지 확인하는 것
- 광고 리드가 인터뷰 리드를 대신하게 되면서 원래 트랙 구분(트랙 1 탐색 인터뷰 / 트랙 2 LMF 광고)의 전제가 바뀌었다. 커스텀 CRM 트랙(디스커버리 콜)도 같은 이유로 접는다

## 3. 트랙 1 — 지불 의향·구매 전환

### 3.1 대상과 흐름

- 대상: 1차 LMF 리드 전량(신청·Keep me posted 포함) + 트랙 2 집행 중 유입되는 A·B 리드
- 흐름: `데모 콜(30분) → 온도별 CTA → 유료 PoC 제안 → PoC 진입`
- 데모 콜은 [리드 인터뷰 가이드](Track2_리드인터뷰_가이드_20260817.md)로 통일. 통증 청취 → 데모 → 반응·지불 의향 → CTA 순
- 미예약·미응답 리드는 Lead Radar 팔로업 흐름으로 회수

### 3.2 이 트랙이 답할 것

| 질문 | 수집 지점 |
| --- | --- |
| 광고에서 반응한 통증이 실제 업무 사례로 확인되는가 | 데모 콜 §2 |
| 데모가 그 통증을 해소한다고 보는가 | 데모 콜 §5 |
| 지불 의향과 가격 범위 | 데모 콜 §5 (현재 지출 앵커 후 질문) |
| 유료 PoC에 들어오는가 | CTA "뜨거움" 분기 |
| ICP 규모 두 축(연간 입양·현재 임보자) | 데모 콜 인트로 (폼 빈 축 확인) |

- 성공 기준(데모 콜 N건 중 유료 의향·PoC 진입 M건)은 리드 유입 페이스를 보고 펫나우와 합의해 정한다
- 결과는 가설 보드 §6 인터뷰 후 갱신표와 M1 종합 보고서 부록 D(인터뷰·현장 관찰)로 들어간다

### 3.3 선행 결정 (펫나우)

| 항목 | 내용 |
| --- | --- |
| **PoC 상품 정의** | 데모 콜 CTA 최상단이 유료 PoC 제안인데 "들어오면 뭘 받는가"가 비어 있음. ①컨시어지형 — 체크인 요청·수집·요약을 사람+시트로 수동 운영. 개발 0, 수주 안에 시작 가능, "돈 내고 계속 쓰는가"까지 검증됨 ②개발 선행형 — MVP 후 PoC. 검증이 개발 기간만큼 후행. 마켓핏랩 의견은 ① |
| PoC 가격 | 가설 보드 실험 D의 $300~500 4주 파일럿을 출발점으로 |

## 4. 트랙 2 — LMF 2차 라운드 (소재 D·E)

### 4.1 1차 기획안을 그대로 따르는 항목

아래는 1차 기획안 v1.2의 해당 절을 그대로 적용하며 이 문서에서 다시 정의하지 않는다.

| 항목 | 1차 기획안 참조 |
| --- | --- |
| 실험 대상 고객(ICP)·퍼소나 사후 분류 | §6.1 · §6.2 |
| 채널(Facebook 단독) | §5 |
| 성공 판단 기준 — 기준선 1.10%, 소재 간 1.5배, 해석 범위 | §3.1 · §3.3 |
| 조기 중단 규칙 | §3.2 (예외는 4.3 참조) |
| Meta 캠페인 세팅(ABO·Advantage+·크리에이티브 2개·`Lead` 최적화) | §8.1 |
| 리드 대응 흐름(2단계 폼·`/book/`·예약 호스트) | §7.3 |
| 예산 스펙트럼·판정 우선순위 | 상세 기획 정리(8/7) §5.2 · §5.3 |

### 4.2 검증 가설

| 항목 | D — H-H 오너 연결 | E — H-F 신규 인력 즉시 투입 |
| --- | --- | --- |
| 유즈케이스 | UC-16 입양 후 새 가족 체크인 (2일·10일·6주) | UC-9 신규 직원·봉사자 교육 |
| A·B와의 결 차이 | 조직 **밖 사용자**(입양자)와의 연결. 유일하게 사용자가 쉘터 밖으로 확장 | 사람이 **바뀔 때**의 비용 |
| ICE(8/9) | 72 (I6·C3·E4) | 60 (I5·C3·E4) |
| Confidence 3의 성격 | 증거 부재 — 펫나우 내부 전언 n=2. 정황 정합성은 있음(ASPCA 사후 연락 권고, 파양 다수가 첫 2개월) | 반례 존재 — 원 근거(Chameleon 학습곡선)가 비교군 제외로 무너짐. Pawlytics "배우기 쉽다" 리뷰 다수 |
| 이번 실험의 의미 | 저확신 가설의 첫 시장 접촉 | 반례를 시장 반응으로 판정 |

- H-H는 UC-15(입양 신청)와 UC-16(입양 후 체크인) 중 **UC-16 하나로** 소재를 만든다. UC-15는 A와 거리가 좁고, 한 소재에 두 통증을 넣으면 반응 원인 판별이 안 된다
- 결과는 높든 낮든 정보가 된다: 높으면 우선순위 재편, 동급이면 제품 범위 확장 후보, 낮으면 A·B 축 집중 근거

### 4.3 1차와 다른 것

| 항목 | 내용 |
| --- | --- |
| **세트 구성** | **4세트 동시 집행** — D · E(신규) + A · B(컨트롤). 상대 비교는 동시 집행한 A·B 실측과 하며, 1차 실측치(2.05/2.73%)와 직접 비교하지 않는다(시기·학습 상태 차이) |
| **조기 중단 예외** | 신규 D·E는 소재당 최소 노출 8,000회 전에는 중단하지 않는다(탐색 목적). 컨트롤 A·B는 조기 중단 대상에서 제외 |
| **폼 규모 문항** | 4개 소재 모두 2단계 폼에서 연간 입양 건수·현재 임보자 수를 함께 받는다. 1차 미결("B에도 입양 문항을 넣을지는 2차 시작 시 판단") 종료. 4개 동시 적용이라 마찰 차이 없음 |
| 랜딩 | LP 4 `/adopters/`(D), LP 5 `/newvolunteer/`(E) 신규. LP 1·2 골격 복제, `landing_variant` `d`·`e` 추가. 1차 미결 대소문자 분리도 함께 정리 |
| 데모 화면 | D·E 대응 클릭형 목업 없음. 제작 여부는 §6. 미제작 시 D·E 리드 데모 콜은 통증 인터뷰 중심 |
| 오디언스 중복 | 세트가 4개라 1차(12%)보다 중복 노출 증가. 관측 격차는 실제보다 작게 나오므로 보수적으로 읽는다 |

### 4.4 판정표

| 결과 | 해석 | 후속 |
| --- | --- | --- |
| 신규 ≥ 1.5 × max(A, B) | 우세 소구점 | 우선순위 재편, 3단계 수렴형 후보 |
| 기준선 이상 · A·B의 1/1.5 이상 | 동급 페인포인트 | 제품 범위 확장 후보, 트랙 1 데모 콜에서 심화 |
| 기준선 이상 · A·B의 1/1.5 미만 | 존재하나 열위 | 인터뷰 질문으로만 유지 |
| 기준선 미만 | 광고 언어로는 미확인 | 가설 보류. 문구 문제인지 통증 부재인지는 리드 발언으로 보완 판단 |

### 4.5 소재 (카피 후보, 제작 단계에서 확정)

| 소재 | 핵심 문구 후보 | 근거 |
| --- | --- | --- |
| D | "Day 2. Day 10. Week 6. Check in on every adopter — without the email chain." | ASPCA 권고 시점. 발화 원문 없음 |
| E | "It shouldn't take a few months to get a new volunteer up to speed." | Gina `a few months` (UC-9) |

- D는 통증 주체를 쉘터로 둔다("입양자가 연락 안 받는다"가 아니라 "체크인 챙기는 손이 간다")
- E는 소프트웨어 학습곡선을 직접 공격하지 않는다(경쟁 대비 근거 부재). "새 사람이 바로 일한다"는 결과만 약속

## 5. 예산과 일정

| 세트 | 역할 | 금액 |
| --- | --- | ---: |
| D 오너 연결 | 신규 검증 | 20만 원 |
| E 신규 인력 | 신규 검증 | 20만 원 |
| A · B | 컨트롤 | 각 15만 원 |
| **합계** | | **70만 원** (1차 예비 예산 전액) |

- 신규를 컨트롤보다 크게 잡은 이유: 컨트롤은 상대 비교용 표본만 있으면 되고, 신규는 절대·상대 판정 둘 다 필요
- 세트당 15만 원 ≈ 노출 5,000회·클릭 약 100건(1차 CPM $21.79·CTR 2% 가정). 1차 1.5배 기준 산출 전제와 부합
- 증액 시 우선순위: ① D·E 각 +10만(최소 노출 8,000회) → ② 데모 콜 예약 전환이 확인되는 세트에 후반 집중

| 주차 | 트랙 1 | 트랙 2 |
| --- | --- | --- |
| 1주 차 | 데모 콜 진행(가이드 적용), PoC 상품 정의 | 소재 D·E 제작, LP 4·5 구축, 폼 문항 4개 LP 적용, 추적 QA |
| 2주 차 | 데모 콜 계속, 유료 PoC 첫 제안 | 4세트 동시 집행, 4일 차 중간 점검 |
| 3주 차 | 콜 결과 → 가설 보드 갱신표, PoC 진입 집계 | CTR·신청률·리드 구성비 분석, 판정표 작성, D·E 리드 데모 콜 |
| 4주 차 | 지불 의향 결과 정리 | 가설 풀 좌표 갱신(H-A·B·F·H), 3단계 방향 결정 |

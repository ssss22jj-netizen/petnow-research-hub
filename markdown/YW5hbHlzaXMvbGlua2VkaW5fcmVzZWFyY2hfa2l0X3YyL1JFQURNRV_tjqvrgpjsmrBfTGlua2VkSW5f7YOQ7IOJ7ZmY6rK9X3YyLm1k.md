# 펫나우 LinkedIn 인터뷰 후보 탐색 환경 v2

> 결론: 고정 조직 40개를 순서대로 탐색하고, 후보 발견과 상세 검증을 분리하여 1차 후보 40명 이상과 고신뢰 1순위 후보 15명 이상을 확보하는 운영 환경임.

## 1. 제공 파일

| 파일 | 용도 |
| --- | --- |
| `organization_registry.csv` | 탐색 대상 조직·지역·조직 유형·조직별 공수 상한 |
| `search_query_matrix.csv` | 조직명과 후보명을 대입하여 사용하는 고정 검색식 |
| `execution_log_template.csv` | 검색 페이지·신규 후보·제외 사유 기록 |
| `discovery_pool_template.csv` | 공개 검색에서 발견한 원시 후보 저장. 검증 완료 목록과 분리 |
| `candidate_template.csv` | 최종 후보 28개 검증 항목 입력 |
| `linkedin_research_qa.py` | 중복·필수값·우선순위·근거 URL 자동 검사 |

## 2. 권장 운영 목표

| 단계 | 목표 | 공수 상한 |
| --- | ---: | ---: |
| Tier A 조직 20개 후보 발견 | 이름·LinkedIn·현재 역할을 확인한 후보 40명 | 조직당 8분, 총 160분 |
| Tier A 후보 빠른 검증 | 검증 대기 후보 30명 | 후보당 2분, 총 60분 |
| 1순위 상세 검증 | 풀타임·역할·공식 근거를 확인한 후보 15명 | 후보당 6분, 총 90분 |
| Tier B 보완 | 1순위 15명 미달 시에만 실행 | 조직당 6분, 최대 120분 |

Tier A만 실행할 때 목표 공수는 약 5시간임. 조직별 검색 결과가 없으면 공수 상한에 도달하는 즉시 다음 조직으로 이동함.

## 3. 실행 순서

### 3.1 후보 발견

1. `organization_registry.csv`의 Tier A 조직을 `org_id` 순으로 진행
2. 조직별로 `search_query_matrix.csv`의 Q001~Q005 실행
3. 일반 검색 결과가 부족할 때만 Q006 LinkedIn 사람 검색 실행
4. 이름이 표시되는 개인 LinkedIn URL, 현재 직책, 지역만 `discovery_pool_template.csv`에 수집
5. 조직별 `max_candidates`는 최종 후보가 아니라 상세 검증 대기 후보에 적용
6. 실행한 검색은 `execution_log_template.csv`에 한 행씩 기록

후보 발견 단계에서는 고용형태와 공식 근거를 조사하지 않음. 발견 단계와 상세 검증을 분리하여, 초기에 한 후보에게 과도한 시간을 사용하지 않도록 함.

원시 후보 저장소는 고객 공유용 검증 목록이 아님. `조직 소속`, `직함 미표시`, `역할 미확인` 상태의 후보를 `candidate_template.csv`로 이동하지 않음.

### 3.2 빠른 검증

아래 조건을 모두 충족한 후보만 상세 검증 대상으로 편입함.

| 조건 | 합격 기준 |
| --- | --- |
| 개인 식별 | 실명이 표시되는 LinkedIn 개인 URL 확보 |
| 현재성 | 현재 동물보호소·레스큐·동물서비스 역할 확인 |
| 미국 소재 | 프로필 지역 또는 현재 조직 근무지가 미국 |
| 역할 관련성 | 운영·임보·자원봉사·입양·입소·수송·재무·시설·조직 총괄 |

마케팅·모금 단일 직무, 과거 경력, 일반 임보자, 조직 페이지뿐인 결과는 제외함.

빠른 검증 합격자는 LinkedIn 헤드라인 또는 경력 섹션에서 구체적인 현재 직책을 확인한 사람만 해당함. 조직 소속 여부만 확인된 사람은 원시 후보 저장소에 유지함.

### 3.3 상세 검증

1. LinkedIn 상단의 이름·헤드라인·지역·현재 조직 확인
2. 소개 확인
3. 경력 `모두 표시`에서 현재 직책·기간·고용형태 확인
4. 봉사 경력과 일반 경력 구분
5. 추천사 확인
6. 최근 게시물·댓글·반응 확인
7. Q007로 공식 개인 근거 검색
8. 고용형태가 직접 표시되지 않으면 Q008과 Form 990 검색
9. `candidate_template.csv` 28개 열 작성

LinkedIn 로그인 세션을 사용할 수 없으면 상세 검증을 완료 처리하지 않음. 공개 검색만 사용한 실행은 원시 후보 저장소와 실행 로그까지만 산출하고, 고객 공유용 후보 목록 생성은 로그인 검증 담당자에게 인계함.

## 4. 탐색 완료 조건

아래 항목을 모두 충족해야 Tier A 탐색을 완료한 것으로 인정함.

- Tier A 20개 조직의 Q001~Q005 실행 로그 존재
- 검색 결과가 부족한 조직은 Q006 실행 로그 존재
- 검색 로그마다 확인 페이지·신규 후보·제외 후보·제외 사유 기록
- 검증 대기 후보 30명 이상 또는 Tier A 전체 검색 완료
- 구체적인 현재 직책이 확인된 상세 검증 대상 20명 이상
- 1순위 15명 이상 또는 구체적인 현재 직책이 확인된 Tier A 후보 전체 상세 검증 완료

`검색어를 입력했다`는 기록만으로 완료 처리하지 않음. 확인한 페이지 또는 결과 세트와 후보 수가 기록되어야 함.

## 5. 고용형태 판정

| 판정 | 직접 근거 |
| --- | --- |
| 풀타임 직접 확인 | LinkedIn `정규직`·`Full-time`·`Permanent Full-time`, 공식 full-time 표기, Form 990 주 35시간 이상과 보수 |
| 유급 직원 확인·시간 미확인 | Form 990 보수 또는 공식 유급 직원 근거만 확인 |
| 시간제 직접 확인 | LinkedIn 또는 공식 자료의 `Part-time`·시간제 표기 |
| 봉사 직접 확인 | LinkedIn 봉사 경력 또는 공식 volunteer 표기 |
| 미확인 | 직함만 확인되고 고용형태 직접 근거 없음 |

직함만으로 풀타임을 추정하지 않음.

## 6. 발송 우선순위

| 우선순위 | 조건 |
| --- | --- |
| 1순위 | 개인 LinkedIn URL, 미국 현직, 풀타임 직접 확인, 구매·예산 또는 운영 실무, 공식 개인 근거 또는 최근 활동 확인 |
| 2순위 | 미국 현직·업무 관련성 확인, 시간제 또는 유급 직원의 근무시간 미확인 |
| 3순위 | 미국 현직 봉사자 또는 고용형태 미확인 실무자 |
| 보류 | 현재성 미확인 또는 관련 역할이 과거 경력 |
| 제외 | 개인 LinkedIn URL 미확보, 미국 외, 역할 관련성 낮음, 중복 |

## 7. 근거 URL 규칙

- 본문에서 후보 이름을 확인할 수 있는 URL만 개인 근거로 채택
- 중간 이름·자격 표기 생략은 동일 인물로 인정
- 조직명만 있고 후보 이름이 없으면 외부 개인 근거에서 제외
- 여러 URL은 같은 셀에서 줄바꿈
- 외부 개인 근거가 없으면 LinkedIn URL만 기록하고 `LinkedIn만 확인` 표시

## 8. 저공수 운영 원칙

| 상황 | 처리 |
| --- | --- |
| 조직별 신규 후보 0명 | 6~8분 공수 상한 도달 시 다음 조직으로 이동 |
| LinkedIn 경력 접근 제한 | 공식 팀·Form 990 2회 검색 후 `미확인` 처리 |
| LinkedIn 로그인 불가 | 원시 후보·검색 로그만 저장하고 최종 후보 생성 중단 |
| 외부 개인 근거 미확보 | 1순위 상향 금지, 추가 검색 반복 금지 |
| 동일 조직 후보 과다 | `max_candidates` 적용 |
| 1순위 15명 확보 | Tier B 탐색 생략 가능 |

## 9. 품질검수

조사 종료 후 아래 명령으로 자동 검사함.

```bash
python3 linkedin_research_qa.py candidate_results.csv execution_log.csv organization_registry.csv
```

오류가 1건이라도 있으면 고객 공유 전 수정함. 경고는 근거 한계를 확인한 뒤 유지 가능함.

## 10. 재현성 기준

| 지표 | v2 목표 |
| --- | ---: |
| Tier A 조직 검색 완료율 | 100% |
| 기준 목록의 Tier A 후보 재현율 | 60% 이상 |
| 독립 실행 1순위 정밀도 | 85% 이상 |
| 고용형태 일치율 | 90% 이상 |
| 주·도 일치율 | 95% 이상 |
| 1순위 1명 확보 평균 상세 검증 공수 | 10분 이하 |

후보명 전체 일치보다 조직 검색 완료율과 1순위 정확도를 우선 관리함. LinkedIn 검색 개인화 때문에 동일 후보 100% 재현은 목표로 하지 않음.

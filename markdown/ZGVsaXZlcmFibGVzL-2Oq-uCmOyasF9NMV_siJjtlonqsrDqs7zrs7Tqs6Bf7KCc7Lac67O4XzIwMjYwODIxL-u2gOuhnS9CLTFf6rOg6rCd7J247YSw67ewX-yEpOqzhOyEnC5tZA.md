# Gina 인터뷰 최종 체크리스트

대상: Gina, KK9R 대표  
권장 시간: 60분  
인터뷰 성격: **조직·구매·도입 맥락 인터뷰**

## 오늘의 목표

1. KK9R이 어떤 ICP에 속하는지 정의한다.
2. Gina의 구매 페르소나와 실제 권한을 정의한다.
3. 현재 툴스택·비용·유지 이유·교체 장벽을 파악한다.
4. Shelter CRM이 어떤 툴과 비용을 어떤 순서로 흡수할 수 있는지 확인한다.
5. 파일럿 성공 기준, 구매 절차, 조건부 WTP를 확인한다.
6. 임보 관리 실무자와 다음 ICP 후보 조직을 소개받는다.

> **주의:** Gina를 CRM의 일상 실무 사용자로 가정하지 않는다. 조직 대표·문제 책임자·도입 추진자·구매 결정권자라는 가설에서 시작하되, 실제 역할과 권한은 인터뷰에서 확인한다.

---

## 실시간 사용법

- **P0 필수:** 오늘 반드시 확보한다. 시간이 부족하면 다른 질문을 생략한다.
- **P1 중요:** P0 답변을 구체화한다.
- **P2 선택:** 시간이 남을 때만 확인한다.
- 질문을 전부 읽지 않는다. **`확보 기준`을 충족했으면 체크하고 넘어간다.**
- Gina가 직접 경험하지 않은 업무는 세부 기능을 묻지 말고 담당자를 확인한다.
- 의견보다 최근 실제 사건, 비용, 계약, 승인 행동을 우선한다.
- 마지막 8분의 소개 및 후속 약속은 생략하지 않는다.

- [ ] **도입 트리거:** CRM 개발 요청 또는 교체 검토를 만든 실제 사건을 확보했다.
- [ ] **툴스택:** Petstablished·Pawlytics·Airtable·DocuSign의 역할과 비용을 확인했다.
- [ ] **교체 장벽:** 불편해도 기존 툴을 유지하는 가장 큰 이유를 확인했다.
- [ ] **최근 운영 문제:** Gina에게까지 보고된 실제 사건 1개와 영향을 확인했다.
- [ ] **예산 이동:** 어떤 기능이 구현되면 어떤 툴의 비용을 이동할 수 있는지 확인했다.
- [ ] **파일럿·구매:** 성공 기준, 실제 사용자, 승인자, 절차, 가능한 시점을 확인했다.
- [ ] **WTP:** 가격 숫자 또는 최소한 가격을 판단할 조건과 예산 출처를 확인했다.
- [ ] **실무자 소개:** 임보 관리 등 실제 사용성을 확인할 담당자를 소개받았다.
- [ ] **다음 ICP 소개:** domestic shelter를 포함한 비교 조직 2~3곳의 warm intro를 확보했다.
- [ ] **후속 약속:** 가설 검토 미팅과 소개 실행 시점을 정했다.

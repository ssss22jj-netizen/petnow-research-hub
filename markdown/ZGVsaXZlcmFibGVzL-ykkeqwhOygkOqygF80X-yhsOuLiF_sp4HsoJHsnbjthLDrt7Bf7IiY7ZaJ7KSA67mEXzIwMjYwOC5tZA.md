# 4. 조니 직접 인터뷰 수행 준비

> 미팅 배정: 15분  
> 대상: 인터뷰 경험이 많지 않은 진행자  
> 권장 세션: 디스커버리 인터뷰 30~40분

## 제안 결론

조니가 모든 질문을 외우기보다 다음 세 구간을 놓치지 않도록 진행표를 설계한다. `최근 실제 사례 1건의 전 과정 복원`, `현재 도구와 우회 행동 확인`, `비용과 도입 맥락 확인` 구간이다. 첫 인터뷰 전에는 폴과 30분 모의 세션을 1회 진행한다.

## 인터뷰에서 반드시 확보할 다섯 가지

1. 최근 실제 업무 사례
2. 시작부터 종료까지의 사람, 도구, 정보 이동
3. 막힌 지점과 당시의 우회 행동
4. 시간, 빈도, 지연, 재작업 가운데 확인 가능한 손실
5. 도구 변경을 검토한 계기와 결정에 관여한 사람

의견이나 기능 아이디어보다 실제로 일어난 행동을 먼저 기록한다.

## 30~40분 진행표

| 시간 | 진행 | 목표 |
| ---: | --- | --- |
| 0~3분 | 목적, 녹화, 판매 미팅이 아님을 안내 | 신뢰와 동의 확보 |
| 3~7분 | 역할과 조직 맥락 | 인터뷰이의 실제 책임 범위 확인 |
| 7~22분 | 최근 사례 1건 복원 | 사람, 순서, 도구, 정보, 예외 파악 |
| 22~30분 | 반복 빈도와 영향 | 문제의 강도와 우회 비용 확인 |
| 30~36분 | 구매·도입 맥락 | 챔피언, 승인자, 예산, 전환 장벽 확인 |
| 36~40분 | 요약 확인과 소개 요청 | 오해 수정, 후속 대상 확보 |

## 그대로 읽어도 되는 시작 문구

> 오늘은 제품을 설명하거나 판매하려는 자리가 아닙니다. 현재 구조·임보·입양 업무가 실제로 어떻게 진행되는지 배우려는 인터뷰입니다. 정답은 없고, 최근에 직접 겪은 사례를 중심으로 말씀해 주시면 됩니다. 기록을 위해 녹화해도 괜찮을까요?

## 핵심 질문 카드

### 역할 확인

- 현재 맡고 있는 업무를 하루 또는 일주일 기준으로 설명해 주세요.
- 말씀하신 업무 중 직접 처리하는 일과 다른 사람에게 요청하는 일을 나눠 주실 수 있나요?

### 최근 사례 복원

- 가장 최근에 동물 한 마리의 상태나 기록을 확인했던 일을 처음부터 설명해 주세요.
- 그 일을 시작하게 된 계기는 무엇이었나요?
- 누구에게 무엇을 요청했고, 어떤 도구를 열었나요?
- 다음 단계로 넘어가기 전에 무엇이 빠져 있었나요?
- 결국 어떻게 처리했나요?

### 문제의 강도

- 비슷한 일이 최근 한 달에 몇 번 있었나요?
- 그때 다시 입력하거나 확인한 정보는 무엇이었나요?
- 늦어지거나 누락되면 동물, 임보자 또는 운영팀에 어떤 영향이 생기나요?
- 현재는 어떤 방식으로 문제를 피하거나 복구하나요?

### 구매와 전환

- 현재 도구를 마지막으로 검토하거나 바꾼 때는 언제였나요?
- 누가 문제를 제기했고, 누가 후보를 조사했으며, 누가 최종 승인했나요?
- 기존 도구를 유지해야 하는 가장 큰 이유는 무엇인가요?
- 이미 비용을 지불하는 도구나 수작업은 무엇인가요?

### 마무리

- 제가 이해한 내용을 짧게 말씀드리겠습니다. 잘못 이해한 부분을 고쳐 주세요.
- 이 업무를 더 직접 처리하는 분이나 도구 구매를 결정하는 분을 소개해 주실 수 있나요?

## 막혔을 때 쓰는 후속 질문

- “최근 한 번만 예로 들어주실 수 있나요?”
- “그 직전에는 무엇을 하셨나요?”
- “그다음에는 누가 무엇을 했나요?”
- “그 정보는 어디에 남았나요?”
- “말씀하신 ‘어렵다’는 상황에서 실제로 무슨 일이 생겼나요?”
- “잠시 생각하셔도 괜찮습니다.”

## 피해야 할 질문과 바꾼 표현

| 피할 질문 | 문제 | 바꾼 질문 |
| --- | --- | --- |
| 임보 기록 관리가 불편하시죠? | 답을 유도함 | 최근 임보 기록을 받은 과정을 설명해 주세요. |
| 이런 기능이 있으면 쓰시겠어요? | 미래 예측과 호의적 답변을 부름 | 비슷한 문제를 해결하려고 지금 무엇을 쓰고 있나요? |
| 가장 큰 문제는 무엇인가요? | 추상적인 의견으로 흐름 | 최근 업무가 막힌 한 번을 떠올려 주세요. |
| CRM이 왜 별로인가요? | 제품 평가로 범위를 좁힘 | 한 동물의 최신 상태를 확인할 때 어떤 도구를 순서대로 보나요? |
| 월 99달러면 괜찮나요? | 가격을 먼저 제시함 | 현재 어떤 도구에 얼마를 쓰고, 누가 승인하나요? |

## 인터뷰 중 놓치기 쉬운 신호

- “보통”, “항상”, “대체로”라는 표현: 최근 사례로 다시 좁히기
- 해결책 아이디어: 기록하되 현재 행동과 섞지 않기
- CEO의 의견: 실사용자의 실제 업무로 일반화하지 않기
- 임보자의 불편: 조직의 구매 의향으로 해석하지 않기
- “좋다”, “쓸 것 같다”: 현재 지출, 우회 행동, 승인 절차가 없으면 약한 신호로 기록
- 크로스보더 문제: 미국 로컬 레스큐의 공통 문제와 분리

## 인터뷰 직후 10분 기록

| 항목 | 기록 내용 |
| --- | --- |
| 실제 사건 | 언제, 어떤 동물, 어떤 목표였는가 |
| 업무 흐름 | 사람, 순서, 도구, 정보 이동 |
| 문제 | 누락, 지연, 재입력, 재확인 |
| 현재 대안 | CRM, 시트, 문자, 이메일, 구두 확인 |
| 강도 | 빈도, 시간, 비용, 결과 영향 |
| 구매 | 챔피언, 실사용자, 승인자, 예산 |
| 근거 수준 | 사실, 인터뷰이의 의견, 추가 확인 항목 |
| 다음 대상 | 소개받을 역할과 연락 경로 |

## 폴의 보조 세션 제안

첫 실전 전에 30분 모의 세션 1회를 권장한다.

- 15분: 조니가 진행하고 폴이 인터뷰이 역할 수행
- 10분: 유도 질문, 후속 질문 누락, 시간 배분 피드백
- 5분: 질문 카드를 조니의 말투로 수정

첫 실전 인터뷰에는 폴이 참관하되, 조니가 진행을 맡는다. 폴은 필수 질문이 빠지거나 답이 추상적으로 끝날 때만 개입한다. 두 번째 인터뷰부터는 녹화본을 15분만 함께 검토하고 독립 수행 여부를 결정한다.

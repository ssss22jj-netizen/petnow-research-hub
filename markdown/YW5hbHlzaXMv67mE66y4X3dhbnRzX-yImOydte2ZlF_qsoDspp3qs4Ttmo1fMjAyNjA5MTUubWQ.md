# 비문 wants 리서치: 판매할 상품과 수익화 검증 계획

기준일: 2026-09-15 · 공개 자료 기반 제안 · 상품·과금 초안, 효과·구매 의향 미검증

## 1. 결론: 기업을 더 찾기보다 판매 제안 두 개를 검증

**검증할 사업 기회는 ‘가족 같은 반려동물에게 실제 동물과 연결된 등록·회원 자격을 제공하고, 이를 편리하게 이어 쓰게 하는 상품’이다.** 감정적 의미와 실용적 편의의 결합을 유지하되, 다음 작업은 기업 명단 확대보다 구매할 수 있는 제안의 구체화에 집중한다.

| 제안 | 누구에게 무엇을 판매하나 | 펫나우 매출이 발생하는 경로 | 지금 투입할 리소스 |
|---|---|---|---|
| **A. 기존 펫 ID의 유료 추가 옵션** | 보호자가 기존 ID에 생체 등록·프로필 재연결 기능을 추가 구매 | 보호자 → ID 판매사에 옵션 대금 → 판매사가 펫나우에 등록 유지 비용 지급 | **먼저 제안 검증.** 기본 상품과 옵션의 차이·가격·구매 시점을 명확히 비교할 수 있기 때문 |
| **B. 회원 서비스에 기본 포함** | 사업자가 반려동물별 회원 경험에 생체 등록·재확인을 포함 | 보호자 → 기존 회비 지불 → 사업자가 서비스 개선의 대가로 펫나우에 사용료 지급 | **조건부 병행.** 실제 재이용 장면에서 달라지는 경험을 하나 특정한 뒤 검증 |

이 순서는 **판매 제안을 구체화하고 시험하는 리소스의 투입 순서**다. 시장 규모·매출 가능성 또는 개별 기업의 구매 가능성 순위가 아니다. 기존 상품·사용 장면을 명확히 비교할 수 있는 A부터 시작하되, B의 계약 근거가 먼저 확보되면 실행 순서를 바꾼다.

최종 판단에 필요한 것은 **보호자의 선택·사용 → 사업자의 이익·비용 → 펫나우 유료 계약**의 연결이다. 추가 옵션 수요가 없다고 B가 자동으로 성립하지 않으며, 두 제안은 각각의 지불 근거로 평가한다.

## 2. QR이 있어도 제안 가능: 비문이 바꾸는 경험을 비교

### 2.1 DMWYD는 기술이 아닌 교육·성취 인증 사업자

**DMWYD는 Do More With Your Dog!의 약칭**이다. 반려견의 트릭 수행을 평가자가 확인하면 단계별 타이틀을 신청할 수 있는 교육·인증 사업자다. 조사 시점 Trick Dog 타이틀 신청 가격은 $28이며, 이미 취득한 타이틀을 모은 PDF도 무료 제공한다. 따라서 QR과 DMWYD를 같은 종류의 대안으로 나열하면 안 된다. 비교 대상은 **QR 조회 방식**, 그리고 **DMWYD가 이미 제공하는 타이틀·기록 서비스**다. [타이틀 상품](https://domorewithyourdog.com/DogTricks/product/trick-dog-title-ntd-itd-atd-etd/), [기존 타이틀 PDF](https://domorewithyourdog.com/DogTricks/product/request-title-or-registration-pdf-free/)

### 2.2 기존 대안의 존재는 탈락 조건이 아닌 비교 기준

| 검증할 추가 가치 | 구체적인 사용 장면 가설 | 비문이 맡는 역할과 비교 조건 |
|---|---|---|
| **더 실제적인 등록이라는 의미** | 이름·사진을 넣은 카드에 더해, 해당 반려동물의 생체정보와 연결된 프로필을 보유 | 같은 디자인·혜택에서 생체 연결이 주는 의미와 선택 차이 확인. 공적 신분·소유권을 증명하는 상품으로 표현하지 않음 |
| **표식에 덜 의존하는 편의** | 카드·태그를 지참하지 않은 상황에서 동일한 동물 프로필 재조회 | 등록 집단 내 생체 검색과 결과 확인. QR·계정 검색·직원 조회보다 전체 과업이 편한지 비교 |
| **이용 접점이 바뀌어도 이어지는 경험** | 카드 재발급·지점 변경·다음 과정 이용 시 같은 프로필과 기록 재사용 | 생체정보는 재연결 수단. 지속 식별자·보관·연동·접근 권한이 함께 필요하며, 기존 회원번호보다 나아지는 점 확인 |

**편의성이 더 나아질 수 있다는 가설은 유효하다.** 다만 촬영·재시도·기록 선택까지 포함한 실제 과정으로 확인해야 한다. 반대로 매번 촬영하는 방식이 느리더라도, 표식 미소지 상황의 보조 수단이나 생체 등록의 의미까지 함께 부정할 이유는 없다.

Petify는 기존 동물 기록을 지정해 대조하는 **1:1 확인**과, 사업자의 등록 동물 집단에서 후보를 찾는 **1:N 검색**을 구분한다. ‘어느 프로필인지 모르는 상황에서 찾아준다’는 제안은 검색과 프로필 연결이 필요하다. 다른 회사의 기록까지 자동 검색하거나 생체정보만으로 비공개 기록 접근을 허용하는 기능으로 확대 해석하지 않는다. [Petify 식별 API](https://docs.petnow.io/petify/docs/server-api/identification)

## 3. 판매 제안 초안: 상품·돈의 흐름·판정 조건

### 3.1 제안 A: 생체정보와 연결되는 펫 ID 옵션

**소비자에게 보여줄 제안 초안:** “이름과 사진을 담은 ID에 우리 반려동물의 생체 등록을 더하세요. 등록된 반려동물은 태그가 없는 상황에서도 이 서비스 안에서 같은 프로필을 다시 찾을 수 있습니다.”

| 항목 | 구체화한 초안 |
|---|---|
| 적용 예시 | **MyPetDMV 같은 기존 유료 ID 판매사.** 실제 도입 의향은 미확인. 신규 독립 앱보다 판매사의 기존 구매·등록 흐름에 추가하는 방식 |
| 기존 상품 | 카드·태그·무료 QR 프로필. 현재 MyPetDMV는 카드와 태그 3개 묶음을 $17.95에 판매하고 앱·구독료가 없다고 안내. 생체 기능이 생기기 전부터 프로필 조회는 존재. [공식 상품](https://www.mypetdmv.com/) |
| 달라지는 경험 | **구매 → 생체 등록 → 기존 프로필 연결 → 표식 없이 해당 서비스 내 재검색.** 일반 QR·계정 조회는 병행. 재검색 결과를 비공개 정보의 접근 권한과 분리 |
| 보호자 결제 | 기본형과 **생체 옵션형**을 같은 구매 화면에서 비교. 추가 요금에는 이용 범위·유지 기간 명시. 일회 결제나 연간 갱신 중 어떤 방식이 맞는지는 가격·비용 검증 후 결정 |
| 판매사와 펫나우의 거래 | 판매사가 옵션 이용 동물의 등록 유지 비용을 부담. 공개 요금제 또는 별도 공급 조건 검토. 생체정보를 계속 유지하는 비용을 일회 옵션 매출이 감당하는 기간 산정 |
| 핵심 검증 | 생체 등록의 의미·재조회 편의가 **추가 결제와 실제 등록 완료**로 이어지는가. 옵션으로 기본 상품 구매가 감소하거나 지원·환불 부담이 커지지는 않는가 |
| 다음 투자 조건 | 기술 흐름이 작동하고, 비용을 반영한 가격에서 구매 행동이 관찰되며, 판매사가 기간·단가·운영 책임을 정한 유료 시험에 참여할 의사가 있을 것 |

**지금 만들 판매안은 ‘평생 등록’이 아닌 제공 기간이 정해진 옵션이다.** 태그가 없어도 조회되는 경험을 실제로 제공할 수 있는지 먼저 확인한다. 장기 유지·사업자 변경 시의 기록 이전은 별도 정책이며 생체 기술만으로 보장되지 않는다.

### 3.2 제안 B: 회원 프로필을 이어 쓰는 생체 등록 포함 상품

**사업자에게 보여줄 제안 초안:** “회원 카드나 태그가 없어도 등록된 반려동물의 회원 프로필을 다시 연결할 수 있게 합니다. 기존 회원 서비스에 생체 등록을 포함하고, 재방문 때의 조회 과정과 고객 경험이 실제로 개선되는지 확인합니다.”

| 항목 | 구체화한 초안 |
|---|---|
| 첫 적용 장면 | **같은 사업자 안에서 재방문한 반려동물의 프로필을 찾는 과정.** DOG PPL·Skiptown은 반복 이용 모델의 참고 사례. 현재 해당 업체에 이 문제가 있다는 뜻은 아님 |
| 기존 방식과 비교 | 회원 앱·계정·직원 조회와 비교하여, 생체 등록 시 새로 생기는 부담과 재방문 시 줄어드는 작업을 함께 기록 |
| 제공 범위 | 최초 등록과 기존 프로필 연결, 재방문 검색, 실패 시 기존 조회 방식. 프로필에 이미 있는 정보 활용부터 검토. 직원의 접객 수준이 자동 향상된다고 주장하지 않음 |
| 돈의 흐름 | 보호자는 기존 회비 지불. 사업자가 **고객 경험·갱신·실제 제공 비용** 중 사전에 선택한 결과의 대가로 펫나우 비용 부담. 별도 생체 옵션 결제가 없어도 성립 가능한 거래 구조 |
| 계약 검증 | 전체 회원 대상 도입에 앞서, 대상 동물 수·이용 기간·비용·판정 지표를 정한 유료 시험. 실제 공급 요금과 추가 연동·지원 비용은 구분 |
| 다음 투자 조건 | 구체적인 사용 장면에서 개선이 관찰되고, 사업자가 그 개선을 위해 비용을 지불할 근거를 제시할 것. 호감·등록 건수만으로 확대하지 않음 |

**DMWYD 같은 성취 인증 서비스도 제외하지 않는다.** ‘단계별 성취가 실제 우리 반려동물과 연결되어 남는다’는 의미, 다음 과정에서 기록을 다시 찾는 편의는 별도 제안 가능하다. 다만 기존 등록번호·무료 기록보다 달라지는 경험이 먼저 필요하다. 그 장면이 확인되면 A의 유료 옵션 또는 B의 상품 기본 포함으로 검증한다. 생체 대조가 트릭 수행 능력이나 기록 내용의 진실성을 증명하지는 않는다.

### 3.3 가격보다 먼저 확인할 비용 단위

Petify 공개 요금은 등록 유지 동물당 월 **Core $0.50, Plus $0.75**다. Plus에는 등록 집단 내 1:N 검색이 포함된다. 새로 등록한 동물뿐 아니라 이전부터 등록을 유지하는 동물도 월 과금 대상이다. 아래 계산은 **공개 요금·등록 유지·요금 불변을 가정한 예시**이며 개별 공급 계약 견적이 아니다. [공식 요금·FAQ](https://www.petnow.io/en/pricing)

| 계산 예시 | 의미 |
|---|---|
| Plus 12개월 유지: $0.75 × 12 = **동물당 $9** | 표식 없이 프로필을 찾는 옵션의 공급료 기준 예시. 판매사 연동·지원·결제 비용은 별도 |
| Plus 36개월 유지: $0.75 × 36 = **동물당 $27** | 일회 판매 상품에 장기간 서비스를 포함하려면 유지 기간·옵션 가격·별도 공급 조건을 함께 정해야 함 |

**판매사 판단식:** 옵션의 추가 순매출 또는 검증된 서비스 개선의 이익 − 펫나우 공급료 − 추가 연동·운영·지원 비용. 절감된 시간이 실제 비용 절감으로 이어지는지도 구분한다.

**펫나우 판단식:** 공급 계약 매출 − 해당 고객을 위한 처리·저장·지원·추가 개발 비용. 판매사의 옵션 매출과 펫나우 매출을 같은 숫자로 취급하지 않으며, 프로젝트 전체 수익성 검토에서는 공통 비용을 추가 반영한다.

## 4. 조직을 찾은 다음 행동: 제안에서 유료 계약까지

### 4.1 다음 작업과 각 단계의 종료 조건

| 단계 | 실행할 행동·산출물 | 확보할 증거 → 다음 판단 |
|---|---|---|
| **① 판매안 구체화** | A·B별 상품·돈의 흐름을 1쪽으로 정리. **이번 문서 3.1·3.2에 초안 작성 완료** | 어느 장면이 달라지고 누가 비용을 내는지 설명 가능 → 화면·기술 확인 진행 |
| **② 펫나우 내부에서 실제 흐름 확인** | A의 구매→등록→표식 없는 프로필 재검색 화면과 짧은 작동 예제 준비. B는 현재 조회 과정과 제안 과정 비교. 등록 유지·삭제·권한·실패 처리·공급 비용 확인 | 제안이 실제 제공 가능한 범위인지, 부담을 감당할 수 있는지 → 외부 검증할 제안 하나 선택 |
| **③ 가격이 있는 직접 제안 검증** | A는 기본형·생체 옵션형의 구체적인 혜택·가격·이용 기간 제시. B는 사업자에게 대상·기간·공급 비용·판정 지표가 있는 시험안 제시 | 보호자의 선택·등록 행동과 사업자의 비용 부담 의사 → 유료 시험에 투입할지 판단 |
| **④ 제한된 유료 시험** | 적합한 판매사와 대상·운영 책임·비용을 정하고 실제 구매·등록·재이용 관찰. 구현 전 관심과 실제 구매는 분리 기록 | 양측 공헌이익·사용 성공·취소·지원 부담 → 수정·중단 또는 본 공급 계약 |
| **⑤ 반복 매출 확인** | 동일 제안을 다음 기간 갱신하거나 다른 판매사에 적용 | 첫 유료 계약 이후에도 유지 가능한가 → 본 개발·영업 확대 |

**당장의 다음 행동은 ②다.** 기업 수십 곳을 추가 조사하거나 기존 리드를 일괄 접촉하기 전에, 펫나우팀과 A의 짧은 사용 흐름과 공급 조건을 맞춘다. 그 결과를 바탕으로 가격을 포함한 판매안 하나를 선택한다. 지금 단계에서 완성 앱·범용 평생 기록망을 개발할 필요는 없다.

### 4.2 첫 구매 검증에서 실제로 보여줄 것

- **A 화면:** 같은 ID의 기본형과 생체 옵션형 비교, 실제 추가 금액·제공 기간, 등록 과정 미리보기, ‘이 옵션으로 구매’ 선택. 미출시 상태이면 구매로 가장하지 않고 출시 전 선택임을 표시. 실제 유료 시험은 제공·취소 조건을 명시한 후 진행.
- **비교 설계:** 기본 상품 / 생체 연결의 의미를 설명한 옵션 / 같은 옵션의 의미와 재조회 편의를 함께 설명한 안을 비교. 디자인·다른 혜택·가격을 통제할 수 있는 범위에서 **메시지별 선택 반응** 확인. 실제 편의의 기여는 ②·④의 사용 과업에서 기존 방식과 비교. 소규모 반응은 문구·장면 수정에 사용하며 시장 전환율로 일반화하지 않음.
- **B 시험안:** 실제 조회가 필요한 접점 하나, 현재 방식과의 과업 완료·소요 시간·재시도 비교, 사업자가 비용을 낼 결과 하나. 갱신 효과는 관찰 기간이 충분할 때 확인하고 초기 사용성 결과로 대신 주장하지 않음.
- **유입 방식:** 자료 신청을 선행시키지 않고, 해당 상품·서비스를 살 가능성이 있는 오디언스에게 **혜택·가격·사용 장면이 있는 랜딩**으로 바로 연결. 광고 집행이나 외부 제안 발송은 이번 조사에서 실행하지 않음.

### 4.3 리서치를 더 하는 경우와 멈추는 경우

| 판단 | 후속 행동 |
|---|---|
| QR보다 편한 장면은 없지만 생체 등록의 의미에 추가 결제 | A의 감정적 가치 소구 유지. 편의성 우위를 과장하지 않고 등록 부담과 이익 검증 |

기존 리드는 **제안을 검증할 맥락과 연결 여부**를 판단하는 자료로 활용한다. 별도 집중 검토·너처링은 업종 전체가 아닌 개별 리드 단위로 선정한다. 선정 이유는 ‘이 리드가 어느 판매 제안의 어떤 불확실성을 풀 수 있는가’로 기록하며 잠재 사업 가치는 참고만 한다. 너처링의 상세 일정·자료 분기는 지금 확정하지 않는다.

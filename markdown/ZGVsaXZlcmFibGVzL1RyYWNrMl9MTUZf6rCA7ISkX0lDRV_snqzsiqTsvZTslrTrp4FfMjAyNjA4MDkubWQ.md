# Track 2 LMF 가설 ICE 재스코어링

> 기준일: 2026년 8월 9일  
> 적용 대상: 미국 내 운영 민간 비영리 쉘터·레스큐  
> 결론: 이번 LMF 광고는 H-B `임보 업데이트 독촉 해방`과 H-A `입양 준비 상태 판단`의 두 가지 페인포인트로 진행한다. 소재 C(H-D `인테이크 입력 속도`)는 근거의 일반화와 차별화 범위가 제한돼 제외했으며, 대체 후보였던 H-E `전체 현황 가시성`은 H-A와 가치약속·데모가 중복돼 별도 소재로 채택하지 않았다.

## 1. 재스코어링 배경

- **초기 조건:** 추가 인터뷰 없이 지나 인터뷰와 데스크 리서치 등 확보된 자료로 스코어링을 진행했다. 자료 범위의 제약은 시작 전부터 인지하고 있었다.
- **초기 목적:** 당시 확보된 근거 안에서 LMF로 우선 검증할 문제 가설을 선정하는 것이 목적이었다.
- **후속 변화:** 광고와 데모를 구체화하면서 제품 컨셉, 가치제안, 경쟁사 대비 차별점, 최소 제품 흐름까지 함께 정의할 필요가 생겼다.
- **재평가 목적:** 초기 문제 근거는 유지하되, 메시지 명료성·차별화 가능성·데모 증명 가능성을 추가로 반영해 우선순위를 정교화했다.

재검토 과정에서 구체화된 조건은 다음과 같다.

- **Shelterluv:** `37 fields`는 특정 화면의 관찰값으로 시장 공통값이 아님
- **지나 인터뷰:** 사진 업로드 불편과 인테이크 필드 수는 별도 문제
- **Petstablished:** 기본 정보 등록 후 상세 정보 보완 기능을 이미 제공
- **Pawlytics:** 학습·사용 편의 강점 확인
- **펫나우:** 제품 컨셉, 입력 범위, 차별화 방식, 가치제안 구체화 단계

| LMF 준비 과정에서 필요해진 작업 | 기존 확정 여부 |
| --- | --- |
| 타깃 고객의 핵심 문제 선정 | 미확정 |
| 경쟁 제품 대비 차별점 정의 | 미확정 |
| 제품이 제공할 핵심 해결 경험 정의 | 미확정 |
| 고객에게 약속할 결과와 범위 결정 | 미확정 |
| 소재별 가치제안 정의 | 미확정 |
| 가치제안을 증명할 최소 제품 흐름 설계 | 미확정 |
| 광고 카피와 데모 화면 연결 | 신규 수행 |

따라서 이번 ICE의 Ease는 광고 제작 난도만 뜻하지 않는다. 현재 제품이 미확정 기능이나 외부 연동에 기대지 않고 가치약속을 구현하고 데모에서 증명할 수 있는지까지 포함한다.

### 1.1 재스코어링 기준

기존의 Impact·Confidence·Ease 평가 틀은 유지하되, Confidence에는 근거의 독립성과 현재 ICP로의 일반화 가능성을, Ease에는 경쟁 제품 대비 차별화와 확정 기능을 통한 데모 증명 가능성을 추가해 더 보수적으로 평가했다.

| 항목 | 이번 평가 기준 |
| --- | --- |
| Impact | 현재 ICP에서의 발생 빈도, 업무·입양 결과에 미치는 영향 |
| Confidence | 지나 인터뷰, 로컬 쉘터 업무 리서치, 주요 경쟁사 리뷰·워크스루가 같은 문제를 지지하는 정도 |
| Ease | 기존 CRM과 병행 가능성, 확정 제품 기능으로 구현 가능한 범위, 데모에서 가치약속을 증명할 수 있는 정도 |

ICE는 `Impact × Confidence × Ease`로 계산하며 각 항목은 1~10점이다. 점수는 가설의 우선순위를 비교하는 도구이며, 시장에서 확인된 사실이나 구매 의향을 의미하지 않는다.

## 2. 경쟁사 비교 프레임

### 2.1 제품별 비교

Petstablished와 Shelterluv를 직접 경쟁사로, Pawlytics를 상대적 UX 기준점으로 비교했으며, 공공기관형 제품인 Chameleon/CMS는 현재 ICP의 ICE 근거에서 제외했다.

| 제품 | 확인된 강점 | 펫나우의 차별화 기회 |
| --- | --- | --- |
| Petstablished | 기본 정보 등록 후 상세 정보 보완 가능 | 분산된 정보를 상태·다음 행동 중심으로 연결 |
| Shelterluv | 인테이크부터 입양·결제·게시까지 폭넓게 지원 | 핵심 과업별 입력·화면 이동 최소화 |
| Pawlytics | 학습과 사용 편의 우위 | 모바일·상태 변경·역할 인계의 업무 완결성 강화 |

## 3. 재스코어링에 따른 소재 구성 결정

### 3.1 페인포인트 2개로 진행

| 검토 단계 | 대상 | 판단 근거 | 결과 |
| --- | --- | --- | --- |
| 초기 소재 선정 | 소재 A(H-A), 소재 B(H-B), 소재 C(H-D) | 당시 확보된 지나 인터뷰와 데스크 리서치를 기준으로 상위 문제 가설 선정 | 3개 소재 구성 |
| 소재 C 재검토 | H-D 인테이크 입력 속도 | Shelterluv의 37개 항목은 제품별 관찰값이며, Petstablished의 점진적 입력과 Pawlytics의 사용 편의 확인. 펫나우의 차별화된 입력 경험도 현재 구체화 단계 | ICE 240→120점, 소재 제외 |
| 대체 후보 검토 | H-E 전체 현황 가시성 | H-D 하락으로 점수상 차순위 후보로 부상 | 대체 후보 포함 |
| H-A·H-E 중복 검토 | H-E 전체 현황 가시성 | H-A는 준비 상태 `판단`, H-E는 전체 현황 `조회`로 과업은 다르지만 동일한 상태 데이터·대시보드를 사용하고 광고 가치약속도 중복 | H-E를 H-A의 제품 화면 요구사항으로 흡수, 독립 소재 제외 |
| 최종 구성 | 소재 A(H-A), 소재 B(H-B) | 현재 근거로 서로 다른 페인포인트와 가치약속을 명확하게 제시할 수 있는 두 가설 | **2개 페인포인트로 진행** |

- **소재 A:** 어떤 동물이 입양 준비를 마쳤는지 별도 확인 없이 판단
- **소재 B:** 임보자에게 반복 연락하지 않고 필요한 업데이트 수집
- **소재 C 제외:** 인테이크 부담의 문제 중요도는 유지하되 시장 보편성과 차별화 범위에 보수적 기준 적용
- **H-E 제외:** 독립 페인포인트가 아니라 소재 A의 해결 경험을 구성하는 현황 대시보드로 반영

## 5. 해석 한계

- 고객 인터뷰는 지나 1명이며 KK9R의 Petstablished·크로스보더 운영 맥락이 포함됨
- Shelterluv와 Pawlytics 워크스루는 특정 계정 설정과 테스트 과업의 결과임
- Petstablished는 실제 운영 계정에서 테스트 레코드를 생성했으나 전체 T1 완료시간은 측정하지 않음
- ICE 점수는 현재 확보 근거를 비교하기 위한 내부 우선순위이며 시장 규모·발생률·지불의향을 나타내지 않음
- 광고 반응은 문제와 가치약속의 상대적 반응을 보여주며, 구매 의향은 후속 데모 콜과 실제 행동으로 별도 확인해야 함

# Track 2 LMF 가설 ICE 재스코어링

> 기준일: 2026년 8월 9일  
> 적용 대상: 미국 내 운영 민간 비영리 쉘터·레스큐  
> 결론: 이번 LMF 광고는 H-B `임보 업데이트 독촉 해방`과 H-A `입양 준비 상태 판단`의 두 가지 페인포인트로 진행한다. 소재 C(H-D `인테이크 입력 속도`)는 근거의 일반화와 차별화 범위가 제한돼 제외했으며, 대체 후보였던 H-E `전체 현황 가시성`은 H-A와 가치약속·데모가 중복돼 별도 소재로 채택하지 않았다.

## 1. 재스코어링 배경

- 초기 ICE 스코어링은 지나 인터뷰와 데스크 리서치 등 당시 확보된 자료를 활용해 진행했으며, 한정된 자료 안에서 시장 반응을 우선 확인할 문제 가설을 선정하는 데 초점을 맞춤
- 이후 실제 광고와 랜딩페이지를 제작하고 데모까지 연결하는 과정에서, 고객의 문제를 매력적으로 제시하는 것에 더해(카피 개발), Petify for Shelters의 피쳐 단위의 명확한 경쟁우위와 문제 해결 방식, 어디까지 결과를 약속할 것인지를 구체적으로 정의할 필요성에 당면
- 기존 자료만으로는 문제의 존재를 설명할 수 있었지만, **모든 가설을 구체적인 솔루션 약속과 제품 경험으로 전환하는 데에는 한계** 발생
- 이에 LMF 준비와 함께 제품 컨셉, 가치제안, 차별화 방식, 약속 범위, 최소 제품 흐름을 구체화함 
- 광고 제작에서 출발했지만 **유의미한 VP 제시와 해당 약속 증명을 위해, 사실상 제품 설계 수준의 정의**까지 작업 범위가 확장

| LMF 준비 과정에서 함께 구체화한 항목 | 이번 단계에서의 적용 |
| --- | --- |
| 타깃 고객의 핵심 문제 | 고객·시장·경쟁사 근거를 대조해 우선 검증 문제 재확인 |
| 경쟁 제품 대비 차별점 | 주요 경쟁사의 기존 기능과 남은 업무 공백 비교 |
| 제품의 핵심 해결 경험 | 고객 과업이 제품 안에서 어떻게 달라지는지 정의 |
| 고객에게 약속할 결과와 범위 | 광고와 랜딩페이지에서 표현 가능한 약속 수준 설정 |
| 소재별 가치제안 | 각 페인포인트와 해결 경험을 하나의 메시지로 연결 |
| 최소 제품 흐름 | 페인포인트가 해결되는 화면과 상호작용 구성 |
| 광고·랜딩페이지·데모 연결 | 광고의 약속이 랜딩페이지와 데모에서 동일하게 이어지도록 정렬 |

따라서 이번 재스코어링에서는 초기 문제 근거를 유지하면서 
**메시지 명료성** / **경쟁사 대비 차별화 가능성** / **UI·UX 해결 경험으로의 구체화 가능성**까지 반영해 선정 가설부터 재검토 진행

## 2. 광고 소재를 3개에서 2개로 축소

- 재스코어링 결과 **소재 A(입양 준비 상태 한단)와 B(임보 업데이트 독촉 해방)**는 서로 다른 페인포인트와 가치약속을 **유지**했다. 
- 반면 **소재 C**는 인테이크 부담 고충이 **시장에서 보편적인지 여부**와 및 **펫나우의 차별화 여부**를 현재 근거만으로 명확히 제시하기 어려웠다. 
- **대체 후보**로 검토한 H-E(전체 현황 가시성)는 **소재 A와** 과업은 다르지만 광고 **가치약속이 중복**됐다. 
- 이에 별도 소재를 추가하지 않고 **소재 A와 B의 두 가지 페인포인트에 집중**하기로 했다.

### 2.1 소재별 최종 판단

| 소재 | 가설 | 판단 | 최종 결정 |
| --- | --- | --- | --- |
| 소재 A | H-A 입양 준비 상태 판단 | 별도 확인 없이 준비 여부를 판단한다는 독립 가치약속 유지 | **진행** |
| 소재 B | H-B 임보 업데이트 독촉 해방 | 반복 연락 없이 업데이트를 수집한다는 독립 가치약속 유지 | **진행** |
| 소재 C | H-D 인테이크 입력 속도 | 시장 보편성과 차별화 범위를 보수적으로 반영해 ICE 240→120점 조정 | **제외** |
| 대체 후보 | H-E 전체 현황 가시성 | H-A와 동일한 상태 데이터·대시보드를 사용하고 광고 가치약속도 중복 | **H-A에 흡수** |

### 2.2 제품별 비교

Petstablished와 Shelterluv를 직접 경쟁사로, Pawlytics를 상대적 UX 기준점으로 비교했으며, 공공기관형 제품인 Chameleon/CMS는 현재 ICP의 ICE 근거에서 제외했다.

| 제품 | 확인된 강점 | 펫나우가 차별화할 수 있는 경험 |
| --- | --- | --- |
| Petstablished | 기본 정보 등록 후 상세 정보 보완 가능 | 동물별 현재 상태, 막힌 일, 다음 할 일을 한 화면에서 확인 |
| Shelterluv | 인테이크부터 입양·결제·게시까지 폭넓게 지원 | 자주 하는 업무를 필요한 정보만 입력해 적은 화면 이동으로 완료 |
| Pawlytics | 학습과 사용 편의 우위 | 모바일에서도 상태 변경과 담당자 인계를 중단 없이 완료 |

## 3. 해석 한계

- 고객 인터뷰는 지나 1명이며 KK9R의 Petstablished·크로스보더 운영 맥락이 포함됨
- Shelterluv와 Pawlytics 워크스루는 특정 계정 설정과 테스트 과업의 결과임
- Petstablished는 실제 운영 계정에서 테스트 레코드를 생성했으나 전체 T1 완료시간은 측정하지 않음
- ICE 점수는 현재 확보 근거를 비교하기 위한 내부 우선순위이며 시장 규모·발생률·지불의향을 나타내지 않음
- 광고 반응은 문제와 가치약속의 상대적 반응을 보여주며, 구매 의향은 후속 데모 콜과 실제 행동으로 별도 확인해야 함

## 별첨. ICE 재스코어링 표

### 재스코어링 기준

기존의 Impact·Confidence·Ease 평가 틀은 유지하되, Confidence에는 근거의 독립성과 현재 ICP로의 일반화 가능성을, Ease에는 경쟁 제품 대비 차별화와 UI·UX 해결 흐름으로의 구체화 가능성을 추가해 더 보수적으로 평가했다.

| 항목 | As-is | To-be |
| --- | --- | --- |
| Impact | 문제의 발생 빈도와 업무·입양 결과에 미치는 영향 평가 | 기존 기준 유지 |
| Confidence | 인터뷰·리서치·경쟁사 자료가 문제를 지지하는 정도 평가 | 근거 간 독립성, 제품별 관찰의 시장 일반화 가능성, 현재 ICP와의 적합성까지 평가 |
| Ease | 제품 구현 가능성과 기존 CRM 병행 가능성 평가 | 페인포인트를 일관된 UI·UX 흐름으로 해결할 수 있는지, 미확정 연동·운영 조건에 의존하는지까지 평가 |

ICE는 `Impact × Confidence × Ease`로 계산하며 각 항목은 1~10점이다. 점수는 가설의 우선순위를 비교하는 도구이며, 시장에서 확인된 사실이나 구매 의향을 의미하지 않는다.

# Track 2 LMF 가설 ICE 재스코어링

> 기준일: 2026년 8월 9일  
> 적용 대상: 미국 내 운영 민간 비영리 쉘터·레스큐  
> 결론: 경쟁 범위와 근거를 현재 ICP에 맞춰 다시 적용한 결과, 소재 C의 `인테이크 입력 속도` 가설은 ICE 240점에서 120점으로 하락했다. ICE 점수 기준 상위 3개 가설은 임보 업데이트 수집, 입양 준비 상태 판단, 전체 현황 가시성이다.

## ICE 스코어링을 다시 했다

2026년 8월 5일 소재 선정 당시에는 `임보 업데이트 독촉`, `입양 준비 상태 판단`, `인테이크 입력 속도`를 광고 소재 B·A·C로 선정했다. 당시에는 추가 인터뷰 없이 지나 인터뷰와 데스크 리서치 등 확보된 자료를 기준으로 우선순위를 설정했다. 이후 카피와 데모를 구체화하는 단계에서 제품 컨셉과 가치제안까지 함께 정의할 필요가 생겼고, 소재 C를 표현할 수 있는 근거와 해결 방식의 범위를 다음과 같이 더 명확히 확인했다.

- `37 fields`는 Shelterluv 무료 체험 계정의 특정 Stray Intake 화면에서 관찰한 값이며 시장 공통값이 아님
- 지나 인터뷰의 사진 업로드 불편과 인테이크 필드 수는 서로 다른 문제이므로 Confidence 산정 시 근거 구분 필요
- Petstablished는 기본 정보 입력 후 레코드를 먼저 생성하고 상세 정보를 나중에 보완하는 구조를 이미 제공
- Pawlytics는 리뷰에서 학습과 사용 편의가 강점으로 평가돼 `경쟁 제품은 모두 어렵다`는 주장에 대한 반례로 작용
- 펫나우의 범용 제품 컨셉, 최초 입력 필드, 차별화된 해결 방식과 가치제안은 아직 확정되지 않음

이번 재스코어링은 기존 판단의 오류를 수정하거나 소재 C만 감점하기 위한 작업이 아니다. 제한된 기존 자료로 수립한 초기 우선순위에 경쟁 구도, 메시지 구체화 가능성, 데모 구현 조건을 추가해 모든 가설을 같은 기준으로 정교화한 작업이다.

## 1. 재스코어링 배경

### 1.1 재검토가 필요해진 배경

초기 ICE 스코어링은 추가 인터뷰 없이 지나 인터뷰와 데스크 리서치 등 당시 확보된 자료만으로 진행한다는 제약을 사전에 인지한 상태에서 수행했다. 해당 단계의 목적은 제한된 근거 안에서 LMF로 우선 검증할 문제 가설을 선정하는 것이었다.

이후 광고 메시지와 데모를 구체화하는 과정에서 새로운 평가 조건이 추가됐다. 확정된 제품 컨셉과 가치제안이 없는 상태였기 때문에 문제 가설의 우선순위 선정뿐 아니라 경쟁 제품 대비 차별점, 고객에게 약속할 결과, 이를 증명할 최소 제품 흐름까지 함께 정의해야 했다. 이에 따라 초기 문제 근거의 유효성은 유지하되, 각 가설을 명료한 가치약속과 데모 경험으로 전환할 수 있는지를 반영해 ICE 점수를 재검토했다.

| LMF 준비 과정에서 필요해진 작업 | 기존 확정 여부 |
| --- | --- |
| 타깃 고객의 핵심 문제 선정 | 미확정 |
| 경쟁 제품 대비 차별점 정의 | 미확정 |
| 제품이 제공할 핵심 해결 경험 정의 | 미확정 |
| 고객에게 약속할 결과와 범위 결정 | 미확정 |
| 소재별 가치제안 정의 | 미확정 |
| 가치제안을 증명할 최소 제품 흐름 설계 | 미확정 |
| 광고 카피와 데모 화면 연결 | 신규 수행 |

따라서 이번 ICE의 Ease는 광고 제작 난도만 뜻하지 않는다. 현재 제품이 미확정 기능이나 외부 연동에 기대지 않고 가치약속을 구현하고 데모에서 증명할 수 있는지까지 포함한다.

### 1.2 재스코어링 기준

| 항목 | 이번 평가 기준 |
| --- | --- |
| Impact | 현재 ICP에서의 발생 빈도, 업무·입양 결과에 미치는 영향, 구매자가 비용을 지불할 가능성 |
| Confidence | 지나 인터뷰, 로컬 쉘터 업무 리서치, 주요 경쟁사 리뷰·워크스루가 같은 문제를 지지하는 정도 |
| Ease | 기존 CRM과 병행 가능성, 확정 제품 기능으로 구현 가능한 범위, 데모에서 가치약속을 증명할 수 있는 정도 |

ICE는 `Impact × Confidence × Ease`로 계산하며 각 항목은 1~10점이다. 점수는 가설의 우선순위를 비교하는 도구이며, 시장에서 확인된 사실이나 구매 의향을 의미하지 않는다.

## 2. 경쟁사 비교 프레임

### 2.1 직접 경쟁사와 기준점

| 구분 | 제품 | 이번 분석에서의 역할 |
| --- | --- | --- |
| 직접 경쟁사 | Petstablished | 지나와 KK9R이 실제 사용하는 메인 플레이어. 현재 ICP의 도입·교체 맥락과 가장 가까움 |
| 직접 경쟁사 | Shelterluv | 미국 쉘터·레스큐 시장의 메인 플레이어. 인테이크, 입양, 결제, 외부 게시 기능 범위가 넓음 |
| 상대적 UX 기준점 | Pawlytics | 리뷰상 학습과 사용 편의 평가가 좋음. 더 나은 UX만으로 해결되지 않는 업무 연결 한계를 확인하는 반례 |
| 별도 B2G 트랙 | Chameleon/CMS | 면허, 현장 출동, 위반, 수납, 감사와 공공 보고를 포함하는 공공기관형 제품. 현재 ICP·ICE 근거에서 제외 |

Chameleon의 학습 난도와 내부 IT 의존 근거는 삭제하지 않고 B2G·공공기관 트랙의 참고자료로 보존한다. 다만 해당 복잡성을 민간 소형·중소형 레스큐의 공통 문제로 일반화하지 않는다.

| 이번 분석의 의미 | 점진적 입력 자체는 펫나우 차별점이 아님 | 37개 항목은 구체적 관찰값이지만 시장 대표값이 아님 | `더 쉽다`는 가치만으로는 차별화하기 어려움 |

### 2.3 비교에서 도출한 기준

- 경쟁 제품에 없는 기능보다 기존 데이터를 현재 과업과 다음 행동으로 연결하는 경험을 우선 평가
- 특정 제품의 극단값을 시장 공통 페인으로 일반화하지 않음
- 쉬운 UI와 실제 업무 완결성을 구분
- 제품 전체 교체나 미확정 외부 연동이 필요한 가설은 Ease를 낮게 평가
- Chameleon에서 강하게 나타난 학습 난도를 현재 ICP의 공통 인테이크 문제로 사용하지 않음

## 3. 다시 한 ICE 스코어링 결론

### 3.1 우선순위 변화

| 구분 | 기존 판단 | 재스코어링 결과 |
| --- | --- | --- |
| 1순위 | H-B 임보 업데이트 독촉 해방 | 유지, 336점 |
| 2순위 | H-A 입양 준비 상태 판단, H-D 인테이크 입력 속도 공동 | H-A만 유지, 240점 |
| 3순위 | 공동 2순위의 H-D | H-E 전체 현황 가시성, 192점 |
| 소재 C | H-D 240점 | 추가 평가 조건 반영 후 H-D 120점, 5위 |

소재 C의 문제 중요도에 대한 판단은 유지했다. 다만 추가 인터뷰 없이 확보된 자료만으로는 인테이크 부담의 시장 보편성을 충분히 확인하기 어렵고, 펫나우의 차별화된 해결 방식도 아직 확정되지 않아 Confidence와 Ease에 보수적인 기준을 적용했다.

### 3.2 상위 3개 가설

1. **H-B 임보 업데이트 독촉 해방, 336점**  
   기존 CRM과 병행 가능한 진입점이며 임보자 입력과 운영자 확인의 연결 공백이 주요 경쟁사에서 남아 있음.

2. **H-A 입양 준비 상태 판단, 240점**  
   지나 인터뷰의 가장 강한 결과 언어와 연결되며 주요 경쟁사 모두 차단 사유·담당자·기한을 중심으로 다음 행동을 보여주는 화면이 약함. 로컬 공통성은 계속 검증 필요.

3. **H-E 전체 현황 가시성, 192점**  
   위치·상태·담당자 불일치와 기능별 정보 분산이 주요 경쟁사 비교에서 확인됨. 다만 H-A와 문제·화면 범위가 겹치므로 광고 포트폴리오 구성 시 별도 판단 필요.

### 3.3 ICE 순위와 광고 소재 선택의 구분

ICE 점수만 적용하면 광고 후보는 H-B, H-A, H-E 순이다. 그러나 H-A와 H-E는 같은 운영자·구매자를 대상으로 준비 상태와 전체 현황이라는 인접한 문제를 다룬다.

| 선택 기준 | 세 번째 소재 |
| --- | --- |
| 근거와 구현 가능성 우선 | H-E 전체 현황 가시성 |
| 서로 다른 문제 축의 학습 폭 우선 | H-D 인테이크 입력 속도를 낮은 Confidence의 탐색 소재로 유지 |

따라서 이번 재스코어링의 결론은 소재 C의 즉시 폐기가 아니다. 초기 선정 당시보다 평가 조건이 구체화된 만큼 소재 C의 현재 우선순위를 조정하고, H-E로 교체할지 또는 학습 축을 넓히기 위해 소재 C를 탐색 소재로 유지할지를 별도 캠페인 결정으로 남긴다.

## 5. 해석 한계

- 고객 인터뷰는 지나 1명이며 KK9R의 Petstablished·크로스보더 운영 맥락이 포함됨
- Shelterluv와 Pawlytics 워크스루는 특정 계정 설정과 테스트 과업의 결과임
- Petstablished는 실제 운영 계정에서 테스트 레코드를 생성했으나 전체 T1 완료시간은 측정하지 않음
- ICE 점수는 현재 확보 근거를 비교하기 위한 내부 우선순위이며 시장 규모·발생률·지불의향을 나타내지 않음
- 광고 반응은 문제와 가치약속의 상대적 반응을 보여주며, 구매 의향은 후속 데모 콜과 실제 행동으로 별도 확인해야 함

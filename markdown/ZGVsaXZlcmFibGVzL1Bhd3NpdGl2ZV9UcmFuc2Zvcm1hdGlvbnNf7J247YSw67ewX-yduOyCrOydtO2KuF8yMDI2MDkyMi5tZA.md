# Pawsitive Transformations 인터뷰 인사이트

> **정기 체크인 자동화의 적합성은 높지만, 월 $99를 지속 부담할 수 없어 무료 파일럿도 거절했다.** 재접촉 조건은 소규모 조직이 감당할 가격 구조가 마련되는 것이다. Lauren은 모든 응답을 승인하는 절차가 부담스럽다고 했고, 한배 새끼고양이의 정보를 링크 하나에서 입력하기를 원했다.

## 2. 현재 업무 방식

| 현재 업무 | 확인된 문제 |
| --- | --- |
| 정기 체크인을 문자·이메일로 발송 | 이번 주 발송 여부와 미응답 후속을 Lauren이 기억해서 실행 |
| 평소 대화와 정기 확인 병행 | 목요일에 별도 대화를 했다는 이유로 토요일 체중·건강·회복 상태 확인을 빠뜨리는 사례 |
| 한 임보자가 한배 새끼고양이 여러 마리 관리 | 개체별 링크를 여러 개 받으면 다른 고양이 정보를 잘못 입력할 위험 |

## 3. 검증 대상

소재 B는 정기 임보 업데이트 수집과 미응답 후속을 자동화하는 가설이다. Lauren의 반복 업무와 직접 맞지만, 검토 단계와 가격은 도입을 막는 별도 조건이다.

| 검증 대상 | 결과 |
| --- | --- |
| 체크인 실행과 미응답 확인이 반복 통증인가 | 문자·이메일 발송을 기억해야 하며, 목요일 대화 후 토요일 정기 건강 확인을 빠뜨리는 사례 설명 |
| 기존 CRM 교체가 필요한가 | 자체 CRM에 만족하며 자동화 기능만 연결하는 방식에 긍정 |
| 모든 응답을 직원이 검토하는 것이 가치인가 | 전건 승인 자체가 추가 업무라며 거부 |
| 무료 파일럿이면 참여하는가 | 이후 월 $99를 감당하지 못해 업무를 다시 바꿔야 한다는 이유로 무료 파일럿도 거절 |

> “I don't want to have to approve.”

Lauren, 모든 임보자 응답을 직원이 승인하는 단계에 대한 반응(정리본 §6). 검토 절차가 조직에 따라 추가 업무가 되는 사례다.

> “I am interested, but I'm also going to pass on the pilot program”

Lauren, 월 $99부터라는 안내 뒤 파일럿 참여 여부에 대한 답변(정리본 §19). 제품 관심을 현재 파일럿 참여 의향으로 기록하면 상태를 반대로 해석하게 된다.

## 4. 데모 반응

| 항목 | 반응 |
| --- | --- |
| 첫 인상 | 자체 CRM 개발과 알파·베타 테스트 경험을 설명하며 구체적인 기능과 가격을 질문 |
| 현행 대비 | 정기 자동 발송과 미응답 알림은 현재 기억에 의존한 업무를 줄인다고 평가 |
| 당장 전환 | 월 $99부터라는 안내 후 무료 3개월 파일럿도 명시적으로 거절 |
| 전환을 막은 갭 | 지속 사용 가격과 전건 승인 부담. 자체 CRM 연동 범위도 확인되지 않았다. 개체별 링크 우려는 한배 일괄 입력 기능 설명 후 해소됐으며 실제 동작은 검증하지 않았다. |
| 지불 의향 | 현재 $99/월은 감당할 수 없다고 답변. 개체별·소규모 조직별·비영리 요금에는 관심이 있으나 실제 지불 상한은 확인되지 않음 |
| 마무리 | 가격 구조가 바뀐다면 파일럿·베타 테스트와 상세 피드백에 다시 참여할 의향. 현재 참여 거절은 유지 |

## 5. 발언 뒤에 있는 것

- **통증 강도와 자동화 적합성은 높다.** [해석·L2] 절차는 이미 있지만 발송·미응답 확인이 사람의 기억에 의존한다. 평소 대화 이력과 필수 항목을 포함한 정기 체크인 완료를 분리해서 관리해야 한다.
- **승인 절차를 모든 고객의 기본 이익으로 설명할 수 없다.** [해석·L2] Lauren은 전건 승인이 추가 업무라고 판단했다. 정상 응답은 자동 반영하고 이상 응답만 검토하는 방식은 제품 가설이며 고객이 세부 규칙까지 요청한 것은 아니다.
- **무료 파일럿도 이후 가격이 맞아야 시작된다.** [해석·L2] Noah's Paws·Maybel's Legacy의 가격 저항에 더해, 지속 사용 불가를 이유로 무료 시험 자체를 거절한 사례다. 무료 기간 연장이 참여를 이끌 것이라는 근거는 없다.
- **다른 소규모 조직의 구매 불가로 일반화하지 않는다.** [해석·L2] 확인된 것은 이 조직의 현재 $99/월 수용 불가다. 대안 요금의 구매 의향·청구 기간·지불 상한은 별도 검증 대상이다.
- **한배 일괄 입력은 데이터 오류 방지 조건이다.** [해석·L2] Johnny의 기능 설명을 듣고 Lauren의 우려가 해소됐지만, 설명 수용은 실제 동작 검증이 아니다. 고양이 임보 조직에는 여러 개체 입력을 직접 시연해야 한다.

## 6. 언급된 기능 요청

| 기능 요청 | 발언 맥락 |
| --- | --- |
| 정기 체크인·미응답 알림 자동화 | 체중·건강·수술 회복 등 정기 확인을 기억해서 수행하는 부담 설명 |
| 전건 승인 단계 제거 | 모든 응답을 승인하고 싶지 않다고 직접 답변 |
| 한 링크에서 한배 전체 업데이트 | 개체별 링크 혼동과 잘못된 동물 정보 입력 위험을 지적 |
| 자체 CRM에 자동화 기능 연결 | CRM을 바꾸기보다 필요한 기능을 구독해 붙이는 방식 선호 |
| 개체별·규모별·비영리 요금 | $0.50/개체를 예시로 언급. 청구 기간·과금 대상·최소 금액·실제 지불 상한은 설명되지 않음 |

## 7. 남은 것

1. **현재 가격 기준 파일럿은 진행하지 않는다.** 지속 가능한 가격 구조가 실제 마련됐을 때 재검토한다. 무료 기간을 늘리면 참여할 것이라는 근거는 없다.
2. **가격을 검증할 때 과금 기준을 함께 확인한다.** 활성 동물·임보 가정·월 구독 중 어떤 단위가 적합한지, 감당 가능한 총액과 청구 기간을 확인한다.
3. **가격 조건이 해결되면 최소 기능을 검증한다.** 자체 CRM 연동, 정기 체크인, 한배 일괄 입력, 미응답 알림을 중심으로 하고 검토 단계는 선택 가능 여부를 확인한다.

검증 지표 후보는 **정기 확인 누락 수, Lauren의 재연락 시간, 잘못된 개체에 입력한 건수, 응답 검토에 추가된 시간**이다. 이 범위는 분석 제안이며 Lauren과 합의한 파일럿이 아니다.

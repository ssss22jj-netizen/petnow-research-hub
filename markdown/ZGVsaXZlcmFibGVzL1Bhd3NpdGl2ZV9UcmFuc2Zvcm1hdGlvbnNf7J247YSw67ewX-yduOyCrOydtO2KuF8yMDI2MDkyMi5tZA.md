# Pawsitive Transformations 인터뷰 인사이트

> **임보 동물의 건강 상태를 정기적으로 확인하는 체크인 자동화는 Lauren의 업무에 잘 맞지만, Lauren은 월 $99를 계속 부담할 수 없어 무료 파일럿도 거절했다.** 소규모 조직이 감당할 가격 구조가 마련됐을 때 다시 연락하는 것이 적절하다. Lauren은 모든 응답을 승인하는 절차가 부담스럽다고 했고, 한배 새끼고양이의 정보를 링크 하나에서 입력하기를 원했다.

| 항목 | 내용 |

| 응답자 | Lauren, Founder. 임보자와의 소통 및 조직 운영을 직접 담당하며, 지인 개발자와 자체 CRM을 구축했다. |

## 2. 현재 업무 방식

| 현재 업무 | 확인된 문제 |
| --- | --- |
| 정기 체크인을 문자·이메일로 발송 | Lauren이 이번 주에 요청을 보냈는지 기억해야 하며, 응답하지 않은 임보자에게 다시 연락하는 일도 직접 챙긴다. |
| 평소 대화와 정기 확인 병행 | 목요일에 임보자와 다른 내용으로 대화한 뒤, 토요일에 따로 해야 하는 체중·건강·회복 상태 확인을 빠뜨리는 사례가 있다. |
| 한 임보자가 한배 새끼고양이 여러 마리 관리 | 임보자가 고양이마다 별도 링크를 받으면 어느 고양이의 링크인지 혼동해, 다른 고양이의 정보를 잘못 입력할 위험이 있다. |
| 자체 CRM 유지 | 필요한 기능은 대부분 이미 갖췄다. 자동 문자 기능은 개발 비용이 들고 다른 기능보다 개발 우선순위가 낮아 아직 만들지 않았다. |

## 3. 검증 대상

소재 B는 임보자의 정기 응답을 수집하고 응답하지 않은 임보자에게 다시 연락하는 일을 자동화할 수 있다는 가설을 검증한다. Lauren이 반복해서 하는 업무에 잘 맞지만, 모든 응답을 승인해야 하는 절차와 지속 사용 가격이 별도로 도입을 막고 있다.

| 검증 대상 | 결과 |
| --- | --- |
| 체크인 발송과 미응답 확인이 반복 부담인가 | Lauren은 문자·이메일 발송을 기억해야 하며, 목요일에 임보자와 대화한 뒤 토요일의 정기 건강 확인을 빠뜨린 사례를 설명했다. |
| 기존 CRM 교체가 필요한가 | 자체 CRM에 만족하며, 자동화 기능만 연결해 쓰는 방식에 긍정적으로 반응했다. |
| 모든 응답을 직원이 검토하는 것이 가치인가 | Lauren은 모든 응답을 승인해야 하는 절차 자체가 추가 업무라며 거부했다. |
| 무료 파일럿이면 참여하는가 | Lauren은 무료 기간이 끝난 뒤 월 $99를 감당하지 못하면 업무 방식을 다시 바꿔야 한다는 이유로, 무료 파일럿도 거절했다. |

> “I don't want to have to approve.”

모든 임보자 응답을 직원이 승인해야 한다는 설명에 Lauren이 보인 반응이다(정리본 §6). 조직에 따라서는 응답 검토 절차가 업무 부담을 더할 수 있음을 보여준다.

> “I am interested, but I'm also going to pass on the pilot program”

월 $99부터라는 안내를 들은 뒤, 파일럿에 참여할지 묻자 Lauren이 답한 내용이다(정리본 §19). Lauren은 제품에 관심은 있지만 현재 파일럿에는 참여하지 않겠다고 답했으므로, 관심 표명을 참여 의향으로 기록해서는 안 된다.

## 4. 데모 반응

| 항목 | 반응 |
| --- | --- |
| 첫 인상 | 자체 CRM 개발과 알파·베타 테스트 경험을 설명하며 구체적인 기능과 가격을 질문했다. |
| 현행 대비 | 정기 요청을 자동으로 보내고 미응답자에게 알림을 보내면, 자신이 기억해서 챙겨야 하는 업무를 줄일 수 있다고 평가했다. |
| 당장 전환 | 월 $99부터라는 안내를 들은 뒤 무료 3개월 파일럿도 명시적으로 거절했다. |
| 도입 전 확인할 조건 | 계속 사용하기에는 가격이 부담스럽고, 모든 응답을 승인해야 하는 절차도 추가 업무라고 봤다. 자체 CRM과 어떤 정보를 연동할 수 있는지도 확인되지 않았다. 고양이별 링크를 혼동할 우려는 한배 새끼고양이의 정보를 한 번에 입력할 수 있다는 설명을 듣고 해소됐지만, 실제 동작을 검증한 것은 아니다. |
| 지불 의향 | 현재 $99/월은 감당할 수 없다고 답했다. 개체별·소규모 조직별·비영리 요금에는 관심을 보였지만, 실제로 얼마까지 지불할 수 있는지는 확인하지 못했다. |
| 마무리 | 가격 구조가 바뀐다면 파일럿·베타 테스트에 다시 참여하고 상세한 피드백을 제공할 의향을 보였다. 현재 조건에서는 참여하지 않겠다는 답변은 유지했다. |

## 5. 발언 뒤에 있는 것

- **현재 업무의 부담이 크고 자동화 기능도 잘 맞는다.** [해석·L2] 정기 확인 절차는 이미 있지만, 요청을 보내고 미응답자를 확인하는 일을 Lauren이 기억해서 실행해야 한다. 임보자와 평소에 대화했는지와 필수 항목까지 정기적으로 확인했는지를 나누어 관리해야 한다.
- **모든 응답의 승인이 모든 고객에게 이로운 절차인 것은 아니다.** [해석·L2] Lauren은 응답을 하나씩 모두 승인해야 하는 일이 추가 업무라고 판단했다. 문제가 없는 응답은 자동으로 기록하고 이상이 있는 응답만 검토하는 방식은 이 문서에서 제안하는 제품 가설이다. Lauren이 이 세부 규칙까지 요청한 것은 아니다.
- **Lauren은 무료 파일럿 이후에도 감당할 수 있는 가격을 원한다.** [해석·L2] Noah's Paws·Maybel's Legacy도 가격 부담을 보였으며, 이번에는 유료로 계속 사용할 수 없다는 이유로 무료 시험 자체를 거절했다. 무료 기간을 늘리면 Lauren이 참여할 것이라는 근거는 없다.
- **다른 소규모 조직도 구매할 수 없다고 일반화하지 않는다.** [해석·L2] 확인된 것은 Pawsitive Transformations가 현재 $99/월을 부담할 수 없다는 점이다. 다른 요금 방식이라면 구매할 의향이 있는지, 어떤 청구 기간이 적절한지, 얼마까지 지불할 수 있는지는 별도로 확인해야 한다.
- **한배 새끼고양이 정보를 한 번에 입력해야 다른 고양이의 정보와 혼동할 위험을 줄일 수 있다.** [해석·L2] Johnny의 기능 설명을 듣고 Lauren의 우려는 해소됐지만, 설명을 받아들인 것과 기능이 실제로 동작하는지 검증한 것은 다르다. 고양이 임보 조직에는 여러 고양이의 정보를 입력하는 과정을 직접 시연해야 한다.

## 6. 언급된 기능 요청

| 기능 요청 | 발언 맥락 |
| --- | --- |
| 정기 체크인·미응답 알림 자동화 | Lauren은 체중·건강·수술 회복 상태 등을 정기적으로 확인하는 일을 기억해서 수행해야 하는 부담을 설명했다. |
| 모든 응답의 승인 단계 제거 | 모든 응답을 승인하고 싶지 않다고 직접 답했다. |
| 한 링크에서 한배 전체 업데이트 | 고양이별로 링크를 받으면 어느 고양이의 링크인지 혼동해 잘못된 동물 정보를 입력할 수 있다고 지적했다. |
| 자체 CRM에 자동화 기능 연결 | Lauren은 CRM을 바꾸기보다 필요한 기능을 구독해 자체 CRM과 연결하는 방식을 선호했다. |
| 개체별·규모별·비영리 요금 | Lauren은 $0.50/개체를 예시로 언급했다. 청구 기간·과금 대상·최소 금액과 실제로 지불할 수 있는 최대 금액은 설명하지 않았다. |

## 7. 남은 것

1. **현재 가격 조건으로는 파일럿을 진행하지 않는다.** 이 조직이 계속 부담할 수 있는 가격 구조가 실제로 마련됐을 때 참여 여부를 다시 검토한다. 무료 기간을 늘리면 참여할 것이라는 근거는 없다.
2. **가격을 검증할 때 과금 기준을 함께 확인한다.** 활성 동물 수나 임보 가정 수에 따라 요금을 정할지, 월 구독료를 받을지 확인한다. 감당할 수 있는 총액과 청구 기간도 함께 확인한다.
3. **가격 조건이 해결되면 필요한 최소 기능을 검증한다.** 자체 CRM 연동, 정기 체크인, 한배 새끼고양이 정보의 일괄 입력, 미응답 알림을 중심으로 검증한다. 모든 응답을 검토해야 하는 단계는 사용자가 선택할 수 있는지도 확인한다.

업무가 개선됐는지 확인할 지표 후보로 **정해진 정기 확인을 빠뜨린 횟수, Lauren이 미응답자에게 다시 연락하는 데 쓴 시간, 다른 고양이의 기록에 정보를 잘못 입력한 건수, 응답 검토 절차 때문에 추가로 쓴 시간**을 제안한다. 위의 기능과 지표로 검증하자는 내용은 이 문서의 분석 제안이며, Lauren과 파일럿을 진행하기로 합의한 내용은 아니다.

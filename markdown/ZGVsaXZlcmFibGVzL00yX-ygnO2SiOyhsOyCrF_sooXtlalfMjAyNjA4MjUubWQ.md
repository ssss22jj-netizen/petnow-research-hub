# M2 제품 조사 종합

- 작성일: 2026.08.25
- 성격: M2에서 진행한 개별 제품 조사의 종합 인덱스. 결론은 여기서, 근거·세부 판독은 제품별 세부 문서에서 확인
- 대상 범위: M2 시점(8월 중순 이후) 신규로 진행한 조사만 포함. M1의 경쟁 4사(Shelterluv·Petstablished·Pawlytics·Chameleon) 리뷰·기능 비교는 `경쟁4사_딥리서치_20260725.md` 계열 참조

## 0. 결론

- M2에서 새로 조사한 제품은 **Chameleon/CMS(+ 후속 24PetShelter)**와 **Petszel** 2건
- 둘 다 Petify for Shelters와 **정면 경쟁이 아니라 인접 제품**으로 판정됨. 다만 겹치는 이유가 서로 다름
  - Chameleon/24PetShelter — 같은 시장(쉘터 운영 SW)이지만 주무대 구간이 다름(원장/거래 vs 준비 파이프라인). 상세: [포지셔닝 축 비교](../analysis/포지셔닝_경쟁제품_축비교_20260820.md)
  - Petszel — 아예 다른 시간축(입양 후)의 무료 레이어. 겹치는 지점은 구매자·연동 표면·작동 메커니즘(예약 발송 → 예외만 알림)
- 공통으로 확인된 것: **임보(foster) 영역은 두 경쟁 축 모두 미점유.** Chameleon 계열은 켄넬 격자의 부속 취급, Petszel은 지원문서 전수에 임보 관련 항목 자체가 없음. 소재 B(임보 체크인)가 두 조사 모두에서 빈 자리로 확인된 셈

## 2. Chameleon/CMS + 24PetShelter

- **한 줄 결론**: 원장(Chameleon)과 거래(24PetShelter) 축의 제품. 둘 다 "보호 중(in-care) 동물의 진행 상태를 판정하는 층"이 없음 — Petify for Shelters의 주무대와 정확히 겹치지 않고 인접함
- Chameleon은 20년째 UI 골격이 동일한 Windows 데스크톱 제품, 파일 업로드는 사용자 직접 방식이 아니라 벤더 대행·자동 신디케이션·리포트 내보내기 세 갈래뿐
- 24PetShelter(2026.04 출시)는 같은 벤더의 후속 제품이나 임보 관리·온라인 리스팅이 아직 미탑재
- 자세한 화면 판독·조작 절차·감사 사례·UX 진단은 `analysis/Chameleon_UIUX_분석_20260820.md` 참조
- 자사 포지셔닝과의 축 비교는 `analysis/포지셔닝_경쟁제품_축비교_20260820.md` 참조

## 3. Petszel

- **한 줄 결론**: Petify for Shelters와 기능이 겹치지 않음. 겹치는 것은 구매자·연동 표면·과금 앵커, 그리고 "예약 발송 설문 → 예외만 담당자 알림"이라는 작동 메커니즘. 현재는 직접 경쟁이 아니나 임보 영역으로 인접 확장 시 정면으로 겹치는 후보
- 커버 구간이 입양 **후**(성사 시점~1년)로, Petify의 입양 **전**(보호 중) 구간과 시간축이 분리됨
- 쉘터·입양자 전원 무료 — 수익원은 입양자 구독(TeleAdvice)·브랜드 파트너(Hill's)·프로바이더 연결 3계통 추정
- 4대 쉘터 관리 시스템(PetPoint·ShelterLuv·ShelterBuddy·Chameleon)에 API 직결 완료. Petify는 아직 미구축이라는 점이 실행 함의로 남음
- 위협은 기능 잠식보다 **가격 앵커링**(쉘터가 "이 범주는 무료"로 학습) 쪽이 큼
- 자세한 사업 모델·규모·제품 구성·위협 판정 근거는 `Petszel_경쟁조사_20260825.md` 참조

## 4. 종합 판단

| 축 | Chameleon/24PetShelter | Petszel |
| --- | --- | --- |
| 겹치는 시간축 | 입소~보호 중~출구 전 구간 | 입양 후 |
| 경쟁 성격 | 같은 시장, 다른 주무대(원장/거래 vs 준비 파이프라인) | 다른 시장(쉘터 관리 SW 위의 레이어), 같은 구매자 |
| 임보 커버 | 켄넬 격자의 부속 취급, 실질적 공백 | 지원문서에 임보 항목 없음, 공백 |
| 가격 압력 | 견적형(Chameleon) / 입양당 과금(24PetShelter) | 전원 무료 — "이 범주는 무료"라는 인식 형성 위험 |
| 데모콜 활용 | 산타바바라 등 Chameleon 사용 조직 앞에서 주무대 대조 | "Petszel 사용 여부"를 스크리닝 질문으로 추가 — 사용 중이면 도입 저항 낮은 세그먼트 |

- **공통 시사점**: 임보(foster) 축이 두 조사 모두에서 미점유로 확인됐다는 것이 지금까지 M2 제품 조사의 가장 일관된 결과임. 다만 Petszel 쪽은 자사 발표 외 검증 자료가 없어, 대외 문서에서 "경쟁사 미커버"를 단정하지 않음

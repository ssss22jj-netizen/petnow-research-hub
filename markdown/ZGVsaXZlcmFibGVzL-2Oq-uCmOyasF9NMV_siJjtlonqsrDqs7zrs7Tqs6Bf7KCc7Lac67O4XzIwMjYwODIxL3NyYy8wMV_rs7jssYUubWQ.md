## 2. 수행 배경 및 목표

### 2.1 배경

- 펫나우는 미국 뉴욕 소재 비영리 구조단체 Korean K9 Rescue를 대상으로 맞춤형 운영관리 도구 파일럿을 운영해 왔음
- 해당 파일럿에서 확인된 제품 가치를 미국 현지 구조단체 일반을 대상으로 하는 독립 SaaS 제품으로 확장할 수 있는지가 본 과업의 출발점임
- 미국 내 동물 구조단체·보호소는 약 14,000곳 규모이며, 카테고리 선도 제품의 침투율이 1% 미만으로 다수 조직이 스프레드시트·종이 등 비전문 도구로 운영 중인 것으로 조사됨

### 2.2 M1 목표

| 구분 | 내용 |
| --- | --- |
| 최종 목표 | 유료 전환이 발생하는 킬러 유즈케이스(핵심 사용 시나리오)의 발견 |
| 검증 질문 | 어떤 조직의 어떤 반복 업무를 해결해야 구매 전환이 발생하는가 |
| 판단 기준 | 시장에 문제 인식이 실재하는지를 정량 지표로 확인 |
| 범위 제한 | M1은 문제 인식 단계 검증까지이며, 지불 의향 검증은 M2 과업으로 분리 |

## 4. 과업 범위 및 수행 방법

M1 과업은 두 개 트랙을 병행하는 구조로 설계함.

| 트랙 | 목적 | 수행 방법 |
| --- | --- | --- |
| Track 1 · 네트워크 인터뷰 | 실제 운영자의 업무 구조와 구매 의사결정 조건 파악 | 기존 파일럿 고객 네트워크를 통한 소개 인터뷰, 화면 공유 기반 업무 관찰 |
| Track 2 · 시장 반응 검증 실험 | 시장에 문제 인식이 실재하는지 정량 확인 | 문제 소구점별 광고 소재를 동시 집행해 반응률 비교, 랜딩페이지로 리드 확보 |

- 두 트랙은 상호 보완 관계임. 인터뷰 섭외에 소요되는 기간을 시장 반응 데이터 확보 기간으로 활용하는 구조임
- Track 2는 광고 반응률만으로 결론을 내지 않으며, 확보한 리드를 대상으로 한 후속 인터뷰까지를 하나의 검증 단위로 설계함

## 6. 주요 수행 결과

### 6.1 미국 동물보호 시장 및 경쟁 구조 분석

| 항목 | 수행 내용 |
| --- | --- |
| 시장 구조 조사 | 미국 구조단체·보호소의 구조부터 입양까지 전 업무 흐름을 조직 유형별로 문서화 |
| 경쟁 4사 분석 | Shelterluv·Pawlytics·Petstablished·Chameleon의 고객군·수익모델·기능 구조 비교 |
| 사용자 리뷰 질적 분석 | 공개 리뷰를 주제별로 코딩해 반복 강점·불만 패턴 도출 |
| 경쟁 제품 실사용 검증 | 실계정을 확보해 동일 과업을 직접 수행하고 화면 증거를 확보. 리뷰에서 확인된 불편이 현재 제품에 실재하는지 대조 |

- 주요 확인 사항
    - 경쟁 제품의 문제는 기능 부족보다 복잡성 및 모바일 미대응에 있음
    - 일부 경쟁사는 마이크로칩 판매 등 부가 수익으로 소프트웨어를 저가 제공하고 있어, 구독료 단순 비교로는 경쟁 구조를 오판할 수 있음
    - 집행 기간 중 경쟁 제품군(PetPoint·Chameleon)의 신규 기능 개발 종료가 공표되어, 기존 사용자의 대체 도구 검토가 발생하는 국면임을 확인

### 6.4 시장 반응 검증 실험 (Track 2)

#### 6.4.1 실험 설계

| 항목 | 내용 |
| --- | --- |
| 검증 대상 | 소재 A(입양 준비 상태 판단의 어려움) · 소재 B(임시보호자 업데이트 수집 부담) |
| 대상 고객 | 미국 내 민간 구조단체 / 연간 입양 50~300건 / 상근 1~5명 / 임시보호자 20~80명 |
| 채널 | Facebook (LinkedIn은 사전 실측 결과 예상 표본 부족으로 제외) |
| 집행 기간 | 2026.08.13 ~ 08.19 (7일) |
| 판정 지표 | 랜딩 링크 클릭률, 신청 제출률, 신청 1건당 비용 (집행 전 사전 합의) |
| 판정 방식 | 목표치·상위 구간을 집행 전에 수치로 확정한 뒤, 실측치를 그 기준에 대조 |

- 실험 인프라로 랜딩페이지 3종(소재 A·B용 2종, 미팅 예약용 1종), 이벤트 계측 체계, 리드 수집·알림 자동화를 직접 구축함
- 광고 차단 환경에서 계측이 누락되는 문제를 확인해 서버 측 계측을 추가 구현하고, 중복 집계 방지 구조까지 검증 완료함

## 10. 용어 설명

| 용어 | 설명 |
| --- | --- |
| PMF (Product-Market Fit) | 제품이 특정 시장의 실제 수요와 맞물린 상태. 이를 확인하는 과정을 PMF 검증이라 함 |
| ICP (Ideal Customer Profile) | 제품이 목표로 하는 고객 조직의 조건 (규모·유형·운영 특성 등) |
| 페르소나 | 목표 고객 조직 내에서 제품을 사용하거나 구매를 결정하는 담당자 유형 |
| 소구점 | 광고에서 제시하는 문제 인식의 각도. 소재별로 서로 다른 문제를 제시해 반응을 비교함 |
| 리드 | 광고를 통해 유입되어 연락처와 조직 정보를 남긴 잠재 고객 |
| 랜딩 링크 클릭률 | 광고 노출 대비 랜딩페이지 링크를 클릭한 비율. 본 실험의 주 판정 지표 |
| 신청 제출률 | 랜딩페이지 방문자 중 신청서를 제출한 비율 |
| 프리토타입 | 실제 개발 전에 제품 경험을 검증하기 위해 만드는 클릭 가능한 모형 |
| PRD | 제품 요구사항 정의서 (Product Requirements Document) |
| 임시보호(Foster) | 구조 동물을 입양 전까지 일반 가정에서 돌보는 미국 구조단체의 보편적 운영 방식 |

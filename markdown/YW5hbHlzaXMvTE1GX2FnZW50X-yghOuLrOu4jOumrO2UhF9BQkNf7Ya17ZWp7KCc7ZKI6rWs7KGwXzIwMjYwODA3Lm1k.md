# LMF Agent 전달 브리프: A·B·C 통합 제품 구조

> 작성일: 2026-08-07

> 의사결정 상태: 카야의 잠정 판단이며 PMF TF·펫나우팀의 합의·확정 사항이 아님  
> 활용 범위: LMF Agent의 카피·랜딩페이지 기획 검토를 위한 입력 자료. 구체적인 카피와 실행안 판단은 LMF Agent가 수행

## 1. 이번 논의의 결론

A·B·C는 서로 다른 제품 후보가 아니라 하나의 제품 흐름을 설명하는 세 가지 진입 소구점으로 정리 가능함.

`간편 등록(C) → 현장·임보 업데이트 수집(B) → 입양 준비 상태 판단(A) → 홈페이지·외부 입양 플랫폼 게시(C)`

따라서 Track 2는 세 제품의 PMF를 비교하는 실험보다 하나의 제품에서 어떤 문제 언어와 대표 기능이 시장에 가장 강하게 소구되는지 확인하는 LMF 실험으로 해석 가능함.

### 논의 경과

1. C를 빠른 Intake 기능으로만 제시할 경우 Petstablished에도 같은 동물을 등록해야 하므로 중복 입력 위험이 가장 크다는 문제 제기
2. A·B에도 일부 필드 중복 가능성이 있으나 A는 분산 정보의 준비 상태 판단, B는 Airtable·Slack 기반 임보 업데이트 수집이 중심이라는 차이 확인
3. Gina 인터뷰에서 Petstablished의 즉시 Intake와 API 기반 외부 게시 역할 재확인
4. C에서 기존 CRM 연동을 전제하지 않고 `간편 Intake→서류·준비정보 관리→게시`를 자체 완결하는 독립형 CRM 콘셉트 검토
5. A의 준비 상태 판단과 B의 임보 업데이트 수집 기능을 C의 등록·게시 흐름 사이에 결합 가능하다는 판단
6. A·B·C를 서로 다른 제품이 아니라 하나의 제품에서 시장에 먼저 제시할 진입 소구점으로 재정리

## 2. 제품 관계에 관한 확인 사실

### 2.1 Petstablished의 현재 역할

Gina 인터뷰에서 확인된 KK9R 뉴욕 조직의 Petstablished 사용 방식은 다음과 같음.

- 신규 동물 Intake 발생 시 Petstablished에 즉시 등록
- Joe가 동물 정보 입력 담당
- Petstablished를 매일 사용
- 홈페이지, Petfinder, Adopt a Pet 등 외부 채널 게시에 API 활용
- 임보자·자원봉사자·입양자 정보와 입양 업무 흐름 관리

> “When we intake a dog, we input it right into Petstablished immediately.”  
> Gina, 22:34

> “We use it every day.”  
> Gina, 39:03

> “We need to get our dogs listed on the website and the third party websites.”  
> Gina, 39:23 이후

### 2.2 KK9R용 펫나우 CRM의 확인 범위

- 한국과 뉴욕 사이의 한·영 정보 연결
- 건강기록, 행동평가, 사진·영상, USDA·CDC 등 허가·서류 관리
- FTA(Foster-to-Adopt) 및 이동·입양 준비 상태 판단
- 자체 동물 목록과 상세 레코드 보유
- 홈페이지 공개 준비 상태 표시

### 2.3 미확인 사항

- 펫나우와 Petstablished의 자동 연동 여부
- 두 시스템의 동물 ID 연결 여부
- 필드별 최종 원장 시스템
- 펫나우의 외부 입양 플랫폼 게시 기능 구현 여부
- 정보 수정 시 양쪽 시스템의 동기화 또는 재입력 범위

## 3. Gina 인터뷰에서 확인된 게시의 중요성

Gina는 Petstablished에서 가장 중요한 기능으로 API를 먼저 언급함. 동물 정보가 KK9R 홈페이지와 Petfinder·Adopt a Pet에 빠르게 반영되는 것이 핵심 이유였음.

Pawlytics는 API 반영에 반나절에서 24시간이 걸렸고, 소셜미디어 홍보 시 홈페이지 정보가 갱신되지 않아 문의가 증가하는 문제가 있었다고 설명함. KK9R이 원하는 최종 결과도 기록량 증가가 아니라 준비된 동물의 이동·입양 촉진으로 표현함.

> “Ultimately we’re here to do adoptions… We need to move dogs.”  
> Gina, 20:54

따라서 C는 단순한 입력 속도 기능보다 `등록→입양 준비정보 관리→게시`가 연결된 업무 흐름으로 제시할 때 Gina의 요구 맥락과 더 잘 맞음.

## 4. A·B·C 통합 제품 흐름

| 단계 | 사용자 문제 | 제시 가능한 기능 | 연결 소재 |
| --- | --- | --- | --- |
| 동물 등록 | 필드가 많고 기본정보·사진 등록이 번거로움 | 필수 정보 중심 Intake, 사진 다중 업로드, 임시 저장 | C |
| 준비 항목 관리 | 건강·행동·미디어·서류가 여러 도구에 분산 | 동물별 준비 체크리스트, 필수 항목 설정 | A·C |
| 현장·임보 업데이트 요청 | 운영자가 반복 연락하고 여러 채널을 확인 | 계정 없는 모바일 링크, 요청·리마인드 | B |
| 업데이트 검토 | 제출 정보가 문자·이메일·폼에 흩어짐 | 신규 제출함, 변경 내용 비교, 승인·보완 요청 | B |
| 준비 상태 판단 | 준비 완료 동물과 누락 항목을 즉시 확인하기 어려움 | Ready·Blocked 상태, 차단 사유, 담당자·다음 행동 | A |
| 게시 준비 | 게시 직전 사진·설명·서류의 재확인 필요 | 게시 미리보기, 공개 가능 여부, 차단 사유 | A·C |
| 게시 | 홈페이지와 외부 채널에 반복 게시하거나 반영 상태 확인 | 홈페이지 공개, 외부 입양 플랫폼 전송 및 상태 확인 | C |

외부 입양 플랫폼 전송을 포함해 기개발된 KK9R용 펫나우 CRM의 범위 밖에 있는 기능도 동일한 제품 콘셉트의 프리토타입에 포함 가능함.

## 5. 소재별 의미와 중복 입력 위험

| 소재 | 기존 업무와의 관계 | 중복 입력 위험에 관한 현재 판단 |
| --- | --- | --- |
| A. 준비 상태 판단 | Slack·한국 현장·건강기록·사진 등에 흩어진 정보를 통합 | 일부 필드는 Petstablished와 겹칠 수 있으나 기존 도구에 없던 준비 상태 판단이 중심 |
| B. 임보자 업데이트 수집 | Airtable 임보 일지와 Slack 알림을 흡수할 가능성 | Airtable·Slack을 대체해 중복이 줄 수 있음. 최종 정보를 Petstablished에도 남겨야 하는지는 미확인 |
| C. 등록부터 게시까지의 업무 부담 | Petstablished의 신규 등록·외부 게시 영역과 직접 겹침 | 보조 기능으로 병행하면 중복 위험이 가장 큼. 연동을 전제하지 않을 경우 해당 구간을 자체 완결하는 독립형 CRM 콘셉트로 해석 필요 |

## 6. C 소재의 재정의

기존 C 가설은 `신규 동물 등록과 미디어 업로드의 번잡함`에 초점을 맞춤. 후속 논의에서는 C를 다음 범위로 확장함.

> 동물을 간편하게 등록하고, 입양에 필요한 정보와 서류를 완성해, 준비되는 즉시 홈페이지와 외부 입양 채널에 게시하는 흐름

이 정의에서 펫나우는 Petstablished에 정보를 전달하는 보조 입력기가 아니라 동물 등록·준비·게시 구간을 담당하는 독립형 CRM 콘셉트임. 신청자 심사·계약·결제까지 모두 포함하는 범용 CRM 전체 대체를 반드시 의미하지는 않음.

다만 외부 게시 이후 신청자·계약 업무를 Petstablished에서 계속 처리하려면 Petstablished 내부에도 동물 레코드가 필요한지 확인 필요함. 필요한 경우 중복 입력 문제가 다시 발생할 수 있음.

## 7. 하나의 프리토타입으로 검증 가능한 구조

| 광고 소재 | 프리토타입 시작 화면 | 공통 흐름으로의 연결 |
| --- | --- | --- |
| A | Ready·Blocked 목록과 누락 사유 | 동물 상세 → 업데이트 확인 → 게시 |
| B | 임보자 모바일 입력 및 운영자 검토 화면 | 업데이트 승인 → 준비 상태 변경 → 게시 |
| C | 신규 동물 Intake와 사진 등록 | 준비 체크리스트 → 상태 판단 → 게시 |

세 경로는 동일한 동물 레코드와 공통 화면을 사용하고 시작 지점만 달리할 수 있음. 소재별로 서로 다른 제품을 제작할 필요는 없음.

우세 소재는 별도 제품의 채택을 의미하지 않음. 동일 제품을 시장에 소개할 때 먼저 제시할 문제 언어와 대표 기능의 우선순위를 의미함.

# Gina 인터뷰 계획 (KK9R 대표)

- 대상: Gina (KK9R 대표, Shelter CRM의 첫 고객이자 제품 개발을 요청한 당사자)
- 형식: 화상 60분, 화면 공유 필수 (실제 업무 화면을 보며 진행)
- 참석: 마켓핏랩 (진행 1인, 기록 1인) + 펫나우 배석 가능
- 녹화: 사전 동의 후 녹화 (내부 리서치 용도로만 사용)

## 인터뷰 핵심 목표

| 확인 항목 | 인터뷰에서 확보할 증거 |
| --- | --- |
| 전체 업무 흐름 | 최근 입양 동물 1마리의 구조부터 사후관리까지 실제 순서·담당자·도구·다음 단계 전환 기준 확인 |
| 반복 병목 | 재입력, 최신 상태 확인, 임보자 독촉, 부서 간 인계의 빈도와 소요시간 |
| 제품 가치 | 펫나우 도입 전후 달라진 행동과 결과 |
| 일반화 한계 | KK9R의 크로스보더 특수 업무와 일반 레스큐의 공통 업무 구분 |
| 후속 연결 | 미국 로컬 쉘터 소개와 추가 화면 공유 인터뷰 확보 |

## 1. 인터뷰 목적

| 순위 | 목적 | 이 인터뷰가 끝나면 얻어야 하는 것 |
| --- | --- | --- |
| 1 | 실제 업무 흐름 파악 | 동물 1마리가 구조 → 입양까지 거치는 전체 단계와, 각 단계에서 쓰는 툴·사람 |
| 2 | 킬러 유즈케이스 후보 발굴 | 가장 자주 반복되고 가장 고통스러운 업무 상위 3개 |
| 3 | 지불의향 확인 | 현재 툴 비용 총액과 "얼마면, 무엇이 해결되면" 지불하는지 |
| 4 | 고객 언어 수집 | Gina가 문제를 표현하는 실제 단어들 (광고 카피 원료) |
| 5 | 로컬 쉘터 소개 확보 | 인터뷰 가능한 일반 로컬 쉘터 3~5곳의 소개 약속 |

## 2. 진행 원칙

- 미래 의향("~하면 쓰실 건가요?")이 아니라 과거 행동("최근에 실제로 어떻게 하셨나요?")을 묻는다
- 제품 기능 설명·자랑을 하지 않는다. 이 자리는 판매가 아니라 학습이 목적
- Gina의 표현을 바꾸지 말고 그대로 기록한다 (요약하면 광고 카피 원료로서의 가치가 사라짐)
- "불편하세요?"라고 묻지 않는다. 오래 적응한 불편은 불편으로 인식되지 않으므로, 실제 작업을 시연받으며 소요 시간과 단계 수를 관찰
- 데스크리서치의 업무 흐름을 먼저 제시하지 않는다. Gina의 실제 순서를 먼저 받은 뒤 누락된 단계만 확인
- 모든 질문을 소화하려 하지 않는다. 전체 흐름을 확인한 뒤 증거가 강한 병목 1~2개를 깊게 추적

## 3. 섹션별 질문 (60분)

### A. 배경과 결정적 사건 (5분)

- 펫나우에 소프트웨어 개발을 먼저 요청하셨는데, 그 결정을 하게 만든 결정적인 사건이 있었나요?

### B. 전체 업무 흐름 검증 (15분)

- 최근 입양이 완료된 동물 한 마리를 기준으로, 처음 구조가 결정된 시점부터 입양 후 관리까지 어떤 일이 있었는지 순서대로 보여주실 수 있나요?

필요할 때만 확인:

- 각 단계의 담당자와 사용 도구
- 다음 단계로 넘어가는 기준과 다음 담당자가 이를 아는 방법
- 순서가 바뀌거나 생략·동시 진행되는 경우
- 번역·국제 이송 등 KK9R에만 해당하는 단계

기록자는 각 단계를 `확인·수정·통합·분기·해당 없음·KK9R 특수·추가 발견`으로 분류한다.

### C. 병목 사례 심층 시연 (20분, 핵심)

B 섹션에서 실제 마찰이 드러난 구간 1~2개를 선택한다. 우선 후보는 `동물 등록→임보 배치`와 `임보자 기록→운영자 확인`.

- 가장 최근 사례를 실제 화면·메시지로 보여주실 수 있나요?
- 같은 정보를 다시 입력하거나 확인 연락한 지점은 어디인가요?
- 실제 위치·담당자·처리 상태와 시스템 기록이 달랐던 적이 있나요?
- 잘못되거나 중단된 기록을 어떻게 발견하고 수정했나요?
- 최근 7일 또는 30일 동안 몇 번 발생했고, 한 번에 얼마나 걸렸나요?

> **놓치면 안 되는 관점:** 화면이 불편한지보다, 현장 정보가 운영 기록과 다음 업무에 반영되기까지 발생하는 재입력·확인 연락·누락을 확인한다.

### D. 도구 병행·제품 가치·구매 행동 (10분)

- Petstablished를 아직 유지하는 이유와, 최종 판단 기준으로 삼는 기록은 무엇인가요?
- 펫나우와 기존 도구 사이에 다시 입력하는 정보는 무엇인가요?
- 펫나우 제품이 내일 사라진다면 어떤 방식으로 돌아가나요?
- 가장 최근에 유료 소프트웨어를 도입한 이유와 승인 과정은 어땠나요?
- 4주 유료 파일럿을 검토하려면 어떤 결과와 누구의 승인이 필요한가요?

월 $99 질문은 시간이 남을 때만 가격 기준 탐색 용도로 사용하며, 지불의향 증거로 단독 해석하지 않는다.

### E. 후속 인터뷰 연결 (10분)

- 운영이 체계적이고 새 소프트웨어에 열려 있는 로컬 쉘터는 어디인가요?
- 그중 3~5곳을 직접 소개해주실 수 있나요? (인터뷰 목적임을 명시)
- 실제 임보자 또는 입양자 2~3명을 인터뷰할 수 있을까요?
- 쉘터 운영자들이 정보를 주고받는 커뮤니티(Facebook 그룹, 협회 등)는 어디인가요?

## 4. 산출물

- 업무 흐름 검증표: 데스크리서치 단계별 확인·수정·분기·KK9R 특수 여부
- Tool Stack Map: 업무 단계별 사용 툴과 정보 이동 경로 정리
- 핵심 병목 증거: 최근 사례, 발생 횟수, 소요시간, 재입력·확인 연락·복구 방식
- 고객 언어 뱅크: Gina의 표현 그대로 수집한 문제 서술 목록 (광고 카피에 사용)
- 소개 리스트: 로컬 쉘터 3~5곳과 실제 임보자·입양자 2~3명

---

## 5. 해석 시 유의점

- KK9R은 크로스보더(한국-미국) 구조단체로, 번역·문서·이송 니즈는 일반 로컬 쉘터에 없을 수 있음
- 따라서 발견한 마찰 포인트마다 "이것은 크로스보더 특수 문제인가, 모든 쉘터의 공통 문제인가"를 구분해 기록
- Gina는 제품 개발을 요청한 당사자로 우호적 편향 가능성이 있음. 만족 표현보다 실제 사용 행동(어떤 기능을 얼마나 쓰는지)에 더 무게를 둔다

## 별첨. 인터뷰어용 단계별 필수 질문

> 전체 질문을 순서대로 읽지 않음. Gina의 자유로운 업무 설명에서 빠진 단계를 확인하거나, 병목이 나타난 구간을 더 깊게 볼 때만 사용.

| 업무 단계 | 반드시 확인할 질문 |
| --- | --- |
| 구조 결정·접수 | 최근 동물은 어떤 정보와 경로로 처음 들어왔고, 누가 구조 진행을 결정했나요? |
| 입소·동물 등록 | 처음 등록할 때 반드시 필요한 정보와 나중에 보완하는 정보는 무엇인가요? |
| 법적·보호 상태 | 보호 상태나 소유권 문제가 해결됐다고 판단하는 기준은 무엇이며 어디에 기록하나요? |
| 의료·행동 관리 | 치료·투약·행동 정보는 누가 입력하고, 이상이나 미완료 상태는 누가 어떻게 확인하나요? |
| 임보 배치·관리 | 임보처가 정해지면 동물 상태·위치·임보자·담당자 정보를 각각 어디에서 변경하나요? |
| 입양 준비·심사 | 입양 가능한 상태가 됐다고 누가 판단하며, 신청 검토 중 막힌 업무는 어떻게 관리하나요? |
| 계약·결제·인계 | 계약·결제·실제 인계가 완료됐다는 사실이 동물 상태와 담당자에게 어떻게 반영되나요? |
| 사후관리 | 입양 후 문제나 반환 요청은 누가 받고, 기존 동물 기록과 어떻게 연결하나요? |

### 병목이 나타났을 때만 사용하는 공통 탐침

1. 가장 최근 사례를 화면이나 메시지로 보여주실 수 있나요?
2. 누가 어떤 도구에 기록하고, 다음 담당자는 완료 사실을 어떻게 아나요?
3. 같은 정보를 다시 입력하거나 확인 연락한 횟수와 소요시간은 얼마인가요?
4. 기록이 실제 상황과 달랐거나 작업이 중단됐을 때 어떻게 발견하고 복구했나요?
5. 이 과정은 KK9R의 크로스보더 업무에만 해당하나요, 일반 로컬 레스큐에도 있을까요?

### 인터뷰 종료 전 필수 확보 항목

- 실제 업무 순서와 주요 분기
- 수치로 확인한 병목 사례 1개 이상
- 최종 기준으로 사용하는 시스템과 이중 입력 항목
- 임보자 또는 입양자 후속 인터뷰 연결
- 미국 로컬 쉘터 3~5곳 소개 가능 여부

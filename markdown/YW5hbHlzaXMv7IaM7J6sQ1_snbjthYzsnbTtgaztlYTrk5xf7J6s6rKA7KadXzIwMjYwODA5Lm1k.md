# Track 2 LMF ICE 재스코어링 추가 검증 근거

> 결론: 추가 검증 결과, H-D `인테이크 입력 속도`는 문제의 시장 일반화와 경쟁사 대비 차별화 근거가 제한돼 광고 소재에서 제외했다. 대체 후보 H-E `전체 현황 가시성`은 H-A `입양 준비 상태 판단`과 가치약속·제품 흐름이 중복돼 H-A에 흡수했다. 이에 이번 LMF 광고는 H-A와 H-B `임보 업데이트 독촉 해방`에 집중한다.

## 1. 추가 검증 범위와 판단

이번 문서는 ICE 재스코어링 과정에서 새로 확인한 근거와 판단을 한곳에 정리한 자료다. 기존 인터뷰·경쟁사 분석 문서는 원문으로 유지하고, 이번 재검토에서 추가한 내용만 통합했다.

| 검증 범위 | 확인 내용 | 재스코어링 반영 |
| --- | --- | --- |
| 소재 C의 수치 근거 | Shelterluv 테스트 화면의 약 37개 항목은 확인했으나 전체 필수 항목이나 시장 공통값은 아님 | H-D Confidence 하향 |
| 소재 C의 차별화 가능성 | Petstablished는 초기 정보 입력 후 레코드 생성이 가능하고, Pawlytics는 더 짧은 인테이크 과업과 상대적으로 높은 사용 편의 평가 확인 | H-D Confidence·Ease 하향 |
| H-A와 H-E의 구분 | 확인하려는 과업은 다르지만 동일한 상태 데이터와 대시보드를 사용하며 광고 가치약속도 중복 | H-E를 H-A에 흡수 |
| 경쟁사 비교 범위 | Petstablished·Shelterluv는 직접 경쟁사, Pawlytics는 상대적 UX 기준점으로 설정. 공공기관 중심의 Chameleon/CMS는 현재 ICP 비교에서 제외 | 현재 ICP 기준으로 근거 재정렬 |

## 2. 소재 C 인테이크 근거 재검증

### 2.1 `37 fields`의 의미

| 검증 질문 | 판정 | 근거 |
| --- | --- | --- |
| Shelterluv 테스트 흐름에 약 37개 입력 항목이 있었는가 | 확인 | Stray Intake 단일 폼에서 약 37개 항목, 8분 44초, 16회 화면 전환 관찰 |
| 37개 전체가 필수였는가 | 아님 | 화면의 필수 표시(`*`)는 일부 항목에만 존재. 발견지 상세, 색상·무늬, 체중, 속성, 영상, 면허, 메모 등에는 필수 표시가 없었음 |
| 37개가 미국 공통 규제 때문에 필요한가 | 근거 없음 | 미국 전역에 적용되는 37개 필드 규정은 확인하지 못함. Shelter Animals Count 참여는 자발적이며 조직·지원기관별 요구는 다를 수 있음 |
| 보고와 지원금에 구조화 데이터가 필요한가 | 일부 확인 | Shelter Animals Count는 인테이크·아웃컴 데이터 표준을 제공하며 Shelterluv API 제출은 일부 지원금 데이터 요건 충족에 활용됨 |
| 모든 정보를 최초 인테이크에서 확정해야 하는가 | 아님 | Shelter Animals Count SOP는 중성화 상태와 생년월일 등을 최초 입력 후 갱신하도록 안내하며, 조건에 따라 `Unknown` 또는 공란을 허용 |
| Shelterluv의 긴 폼이 모든 조직에 동일한가 | 단정 불가 | Shelterluv는 Intake & Outcome Forms를 구성할 수 있다고 안내. 테스트 계정의 화면을 모든 고객의 고정 폼으로 일반화할 수 없음 |

Shelterluv의 약 37개 항목은 `레코드를 만들기 위한 법적 최소 정보`가 아니라 `테스트한 Stray Intake 화면에 노출된 전체 입력 항목`으로 해석해야 한다. 또한 동적 항목이 변경되는 과정에서 기존 입력값이 초기화돼 8회 이상 재입력한 현상은 해당 테스트에서 확인했지만, 모든 계정과 조건에서 반복되는 현상으로 일반화할 수 없다.

### 2.2 경쟁사 대비 차별화 검토

| 제품 | 확인 내용 | 소재 C에 미치는 영향 |
| --- | --- | --- |
| Shelterluv | 테스트한 Stray Intake 화면은 약 37개 항목으로 길지만 폼 구성은 조직별로 달라질 수 있음 | `37 fields`를 시장 공통 페인포인트로 표현하기 어려움 |
| Petstablished | 신규 등록 첫 화면에서 `Next`를 실행하면 레코드가 즉시 생성되고 전체 편집 화면으로 이동 | `기본 정보로 먼저 레코드를 연다`는 해결 방식만으로 차별화하기 어려움 |
| Pawlytics | 정식 계정 T1 신규 동물 등록·임보자 배치를 약 24개 입력, 3분 58초에 완료. 리뷰에서는 `학습이 쉽다`, `정보가 한곳에 있다`는 평가 확인 | 모든 경쟁 제품의 인테이크가 어렵거나 느리다는 주장에 대한 반례로 작용 |

인테이크 부담 자체는 LMF에서 검증할 수 있는 문제 가설이지만, 현재 근거만으로는 펫나우가 경쟁사보다 어떤 방식으로 더 쉽게 해결하는지 독립적인 가치약속을 제시하기 어렵다. 특히 프리토타입의 최초 입력 항목 수와 후속 보완 흐름은 실제 제품 스펙이 아니라 추가 설계가 필요한 제품 가설이다.

### 2.3 사용할 수 있는 근거와 제외한 표현

| 구분 | 내용 |
| --- | --- |
| 확인된 문제 근거 | 특정 Shelterluv 테스트 화면의 약 37개 항목, 8분 44초 소요, 조건 변경 과정의 입력값 초기화와 8회 이상 재입력 |
| 제한적으로 가능한 해결 방향 | 현재 아는 정보로 레코드를 먼저 생성하고, 확인되는 정보를 이후에 보완하는 흐름 |
| 사용할 수 없는 주장 | 미국 모든 쉘터가 37개 항목 입력, 37개 전체가 필수, 최초 인테이크 한 번으로 기록 완성, 이후 추가 작업 불필요 |
| 최종 판단 | 인테이크 문제의 존재보다 차별화된 해결 방식의 근거가 부족해 이번 광고 소재에서 제외 |

## 3. H-A와 H-E 중복 검토

| 가설 | 사용자가 확인하려는 질문 | 필요한 제품 경험 | 판단 |
| --- | --- | --- | --- |
| H-A 입양 준비 상태 판단 | 어떤 동물이 입양 준비를 마쳤는가 | 동물별 준비 상태, 차단 사유, 다음 행동 확인 | 독립 광고 소재로 유지 |
| H-E 전체 현황 가시성 | 전체 동물의 진행 상황과 막힌 업무는 무엇인가 | 상태별 목록, 차단 사유, 담당자, 다음 행동 확인 | H-A와 동일한 데이터·대시보드가 필요하고 광고 약속도 중복돼 H-A에 흡수 |

H-E는 운영 현황을 넓게 조회하는 과업이고 H-A는 입양 준비 여부를 판단하는 과업이라는 차이가 있다. 다만 두 가설 모두 `현재 상태와 막힌 이유를 한 화면에서 확인한다`는 가치약속과 제품 흐름으로 수렴하므로 별도 광고 소재로 분리하지 않았다. H-E의 전체 목록·필터 요구사항은 H-A를 증명하는 제품 화면에 반영한다.

## 4. 경쟁사 비교 프레임

| 구분 | 제품 | 적용 이유 |
| --- | --- | --- |
| 직접 경쟁사 | Petstablished, Shelterluv | 민간 비영리 쉘터·레스큐의 동물·임보·입양 운영을 폭넓게 지원하며 현재 ICP와 겹침 |
| 상대적 UX 기준점 | Pawlytics | 현재 ICP와 겹치면서 사용 편의 평가와 정식 계정 과업 결과가 비교 기준으로 활용 가능 |
| 현재 비교 제외 | Chameleon/CMS | 지방정부 동물통제·면허·현장 출동 중심의 B2G 제품으로 현재 LMF의 민간 비영리 ICP와 구매·운영 맥락이 다름 |

고객 인터뷰는 지나 1명이며 KK9R의 Petstablished·크로스보더 운영 맥락이 포함돼 있다. 경쟁사 워크스루도 특정 계정 설정과 테스트 과업의 결과이므로 시장 발생률이나 전체 고객 경험으로 일반화할 수 없다. 이번 결과는 현재 확보한 근거로 광고 가설의 상대적 우선순위를 조정한 판단이며, 문제의 보편성과 구매 의향은 광고 반응과 후속 데모 콜에서 별도로 확인해야 한다.

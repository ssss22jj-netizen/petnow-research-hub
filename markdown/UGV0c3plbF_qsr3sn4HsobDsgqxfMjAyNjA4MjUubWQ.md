# Petszel 경쟁 조사

- 기준일: 2026.08.25
- 대상: Petszel LLC (petszel.com)
- 목적: Petify for Shelters M2 경쟁 환경 보강 — 기존 `경쟁4사_딥리서치_20260725.md`(Shelterluv·Petstablished·Pawlytics·Chameleon) 미포함 사업자 파악
- 근거: 공식 지원문서 전수(shelter/pet-parent 60여 문서), 보도자료 3건, 업계 매체 3건, 기업정보 DB 2종. 제품 직접 사용은 미실시(쉘터 계정 필요)

---

## 한 줄 결론

**Petszel은 Petify for Shelters와 기능이 겹치지 않는다. 겹치는 것은 구매자·연동 표면·과금 앵커, 그리고 "예약 발송 설문 → 예외만 담당자 알림"이라는 작동 메커니즘이다.** 현 시점 직접 경쟁이 아니라, 임보 영역으로 인접 확장 시 정면으로 겹치는 후보다.

## 2. 사업 모델 — "쉘터에 안 받는" 구조

- 쉘터·레스큐·입양자 **전원 무료**. 계정 생성·입양 패킷·설문·대시보드·프로바이더 등록 모두 과금 없음(공식 FAQ 명시)
- 수익원 3계통 추정

| 계통 | 내용 | 근거 수준 |
|---|---|---|
| ① 입양자 구독 | TeleAdvice(24/7 수의 테크니션 상담) 입양 후 30일 무료 → 이후 월 구독 전환 | `[검증됨·L0]` 공식 FAQ. 단가는 미공개 |
| ② 브랜드 파트너 | Hill's Food, Shelter & Love 프로그램의 월간 입양 보고 자동화를 Petszel이 대행 | `[검증됨·L0]` 존재 사실 / `[추론·L2]` 대가 지급 구조는 미공개 |
| ③ 프로바이더 연결 | 지역 병원·훈련사·미용 등록 + 오퍼(무료 초진·훈련 50% 등) 노출, 보험·케어비용 카테고리 운영 | `[추론·L2]` 현재는 쉘터가 무상 등록하는 구조. 수익화 인벤토리로 볼 여지 |

> **함의**: 쉘터에 과금하지 않는 이유는 자선이 아니라 과금 대상이 다른 데 있기 때문이다. "이런 종류의 도구는 무료"라는 인식이 시장에 깔린다.

## 4. 제품 구성

| 기능 | 내용 |
|---|---|
| 연동 | PetPoint·ShelterLuv·ShelterBuddy·Chameleon API 직결. 쉘터 수기 입력 없음. 다중 캠퍼스·시스템 교체 시나리오까지 문서화 |
| 디지털 입양 패킷 | 의료기록·백신·보호 중 기록·행동 노트를 종이 대신 웹앱으로 전달 |
| 화이트라벨 | 온보딩 시 쉘터 로고 업로드 → 입양자에게 쉘터 브랜드로 노출 |
| 자동 설문 8회 | Day1 / Week1 / Month1 / 2 / 3 / 4 / 6 / Year1. 이메일·SMS 발송, 미응답 자동 리마인드 |
| 선별 알림 | 대부분의 응답은 대시보드에만 적재. 행동·의료·일반 지원 요청 등 **특정 응답만** 담당자에게 이메일. 제목에 유형+입양 지점 표기 → 수신함 필터로 팀별 라우팅 |
| 프로바이더 맵 | 쉘터가 지역 업체 등록 → 입양자 앱에 구글맵. 추천(❤️)·오퍼·둘 다·차단 4단계 상태 관리 |
| 오퍼 | 무료 초진·무료 훈련수업·훈련 50%·자유 입력. 3일~1년 노출 기간 설정 |
| TeleAdvice | 24/7 수의 테크니션(쉘터 메디슨 교육 이수), 영상·채팅·전화. 쉘터 SOP에 맞춰 "우리 팀으로 회신" / "지역 파트너로 전달" 라우팅 설정. VCA Healthy Start 등 외부 프로그램 연계 |
| Hill's 자동 보고 | 월간 입양 실적 자동 제출. 무약정·무상·언제든 옵트아웃, 과거 데이터 소급 없음 |

## 5. Petify for Shelters와의 관계

### 겹치지 않는 것 (제품)

| 구분 | Petify for Shelters | Petszel |
|---|---|---|
| 시간축 | 입양 **전** — 보호 중 동물 상태·잔여 과업 | 입양 **후** — 입양자 적응 |
| 소재 A 영역 | 동물 1마리의 건강·행동·사진·서류를 한 화면에, 다음 할 일 가시화 | 해당 없음 |
| 소재 B 영역 | 임보자 정기 체크인 링크, 예외만 담당자에게 | 해당 없음 |
| 진실 원장 | 동물 레코드 자체를 보유 지향 | 쉘터 관리 시스템 위에 얹히는 레이어 |
| 임보 취급 | 핵심 | 지원문서 전수에 임보 관련 항목 없음 `[추론·L2 — 공개 문서 부재 기준. 비공개 로드맵은 확인 불가]` |

### 겹치는 것 (전장)

1. **구매자 동일** — 쉘터 운영·입양 담당자. 데모콜에서 "이미 무료로 비슷한 걸 쓰고 있다"는 반응이 나올 수 있는 자리
2. **연동 표면 동일** — 4대 쉘터 관리 시스템. Petszel은 이미 구축 완료, Petify는 미구축
3. **작동 메커니즘 동일** — 예약 발송 설문 → 정상 응답은 자동 적재 → 예외만 담당자 알림. Petify 소재 B의 임보 체크인과 구조가 같음
4. **가격 앵커 동일 지점** — 쉘터 대상 무료

## 6. 위협 판정

| 위협 | 판정 | 근거 |
|---|---|---|
| 기능 잠식(현재) | **낮음** | 커버 구간이 입양 전/후로 분리. 현 공개 제품에 임보·보호 중 운영 없음 |
| 인접 확장(임보 체크인) | **중간** | 설문·알림·SMS 엔진 보유. 발송 대상만 입양자→임보자로 바꾸면 형태는 성립. 단, 임보 데이터는 쉘터 관리 시스템에 없어 API 연동만으로는 못 채움 `[추론·L2]` |
| 가격 앵커링 | **중간~높음** | 쉘터가 "이 범주는 무료"로 학습. Petify 유료화 시 가치 설명 부담이 커짐 |
| 채널 선점 | **중간** | Hill's 프로그램(전국 규모 사료 기부 프로그램)의 보고 자동화를 통로로 쉘터를 대량 온보딩. 개별 아웃바운드 대비 접점 비용 우위 |

## 7. M2 실행 함의

- **무료 앵커 대응**: "왜 유료인가"가 아니라 "무엇의 원장인가"로 프레임을 분리한다. Petszel은 쉘터 관리 시스템 위의 레이어, Petify는 보호 중 기록 자체를 다루는 도구
- **소재 B(임보)의 위치**: 현재 미점유 영역이다. Petszel이 커버하지 않는다는 점은 대조 근거로 쓸 수 있으나, 자사 발표 외 검증 자료가 없으므로 대외 문서에서 경쟁사 미커버를 단정하지 않는다
- **연동 요건 밖 세그먼트**: 4대 쉘터 관리 시스템을 쓰지 않는 소규모 임보형 레스큐는 Petszel 온보딩 요건 밖. 기존 조사의 "CRM이 있어도 구글 시트는 살아있다" 결론과 같은 층위 `[추론·L2]`

## 1. 제품 현황

- 현재 Shelter CRM은 KK9R(크로스보더 구조단체) 요구 기반의 맞춤형 파일럿 단계
- KK9R에서는 제품 가치가 확인됨. 단, KK9R의 니즈는 크로스보더 운영(한국-미국 정보 공유, 번역, 문서 관리)이라는 특수성이 커서, 일반 미국 로컬 쉘터에도 구매를 일으킬 가치가 있는지는 검증되지 않음

---

## 2. 전략 목적 구조

- 동일 제품에 두 축의 목적 공존
    - 독립 SaaS
        - 구독료 자체가 돈이 되는 사업. 성공 = 유료 고객 수, ARR, 리텐션. "쉘터가 월 $99를 낼 만큼 가치가 있는가"가 핵심 질문.
    - 침투·데이터·B2G
        - 특정 지역 쉘터에 깔린 CRM이 지자체에 "현장이 이미 쓰고 있다"는 도입 근거가 되는 것. 성공 = 고객 수가 아니라 특정 지역의 쉘터 밀도와 정부 계약 전환.
        - 동물 개체 데이터(이력, 의료, 사진, 나중엔 비문)가 계속 갱신되며 쌓이는 자산. 성공 = 데이터의 양·질·최신성. 여기서 CRM은 목적이 아니라 데이터 수집 장치.
- 이 두 축이 트레이드오프 상황에서 서로 반대 결정을 내리게 만들기 때문에 어느 시점에서는 의사결정 필요

| 구분 | 독립 SaaS 축 | 침투·데이터·B2G 축 |
| --- | --- | --- |
| 성공 기준 | 유료 고객 수, ARR, 리텐션 | 현장 활성 사용 → 데이터 양·질 → 지역 쉘터 밀도(지자체 도입 근거) |
| 가격 정책 | 유료화 해야 검증됨 | 무료 침투 우선 |
| 온프레미스 요청 | 수용 (계약 확보) | 거절 (데이터 확보 불가) |
| 진입 지역 | 지불의향 우선 | 특정 카운티 밀도 집중 |
| 기능 우선순위 | 구매자(디렉터)가 좋아하는 | 현장 사용 빈도가 높은 |

**프로젝트의 역할 구분**

- 우선순위 서열 결정은 펫나우의 경영 전략 사안 — 인터뷰만으로 결정 불가, 사업 전반에서 지속 확인 필요
- 본 프로젝트 역할: 판단 재료 공급 (지불의향, 현장 사용 빈도, 데이터의 B2G 활용 가능성)
- 프로젝트 운영용 작업 기준만 합의 후 착수 (안: 1차 목표 = 유료 전환이 일어나는 킬러 유즈케이스 발견)

## 3. 접근 방식: 투트랙 디스커버리

- 목적: 고객 전환을 일으키는 킬러 유즈케이스 발견
- 킬러 유즈케이스: CRM 전체 교체를 설득하는 대신, 하나의 반복 업무를 압도적으로 잘 해결하여 시장에 진입하는 지점. 진입 후 인접 업무로 확장

| 구분 | Track 1: 네트워크 인터뷰 | Track 2: 리드 기반 디스커버리 |
| --- | --- | --- |
| 진행 방식 | KK9R Gina 심층 인터뷰 후 로컬 쉘터 3~5곳을 소개받아 인터뷰 | 링크드인·쉘터 커뮤니티에 광고 집행, 반응한 리드와 디스커버리 콜 |
| 얻는 정보 | 실제 업무 흐름과 사용 툴에 대한 심층 관찰 | 어떤 문제 메시지에 반응하는지에 대한 정량 신호 |
| 표본 특성 | 크로스보더·사립 쉘터 쪽으로 표본이 기울 수 있음 | 현재 불편을 실제로 느끼고 있는 쉘터 위주 |
| 해석 시 유의점 | 지인 소개 특성상 우호적 답변 가능성을 감안 | 판매가 아닌 탐색 목적의 콜로 운영. 초반 15분은 현재 업무 방식 청취 |

- 광고 메시지는 문제 가설별로 2~3종을 분리 제작 (예: 여러 툴 통합 / 모바일 현장 기록 / 임보자 관리)
- 어떤 문제 프레임에 반응이 오는지 확인함으로써 리드 확보와 메시지 검증을 동시에 수행

## 4. 실행 계획(M1)

**Step 1: 셋업 및 준비 (W1~W2)**

| 담당 | 할 일 |
| --- | --- |
| 펫나우 | 협업 환경 셋업: Slack Connect 초대, Confluence 권한, Figma·프로토타입 전달, 경쟁사 계정 공유 |
| 펫나우 | Gina 인터뷰 일정 확정, 로컬 쉘터 3~5곳 소개 요청 |
| 펫나우 | KK9R의 제품 사용 데이터 공유 (기능별 사용 빈도) - 실제 사용 중이시라면. 혹은 인터뷰에서 갈음 |
| 마켓핏랩 | 인터뷰 가이드 작성 (업무 흐름과 사용 툴 파악 중심) |
| 공동 | 프로젝트 작업 기준 합의: 1차 성공 기준, 전략 판단용으로 수집할 증거 항목 |

**Step 2: 인터뷰와 실험 준비 병행 (W3~W4)**

| 구분 | 담당 | 할 일 |
| --- | --- | --- |
| Track 1: 네트워크 인터뷰 | 공동 | Gina 인터뷰 진행. 인터뷰에서 나온 고객 표현을 광고 카피에 반영 |
| Track 1: 네트워크 인터뷰 | 공동 | 로컬 쉘터 인터뷰 진행. 내부 리뷰로 내용 정리 |
| Track 1: 네트워크 인터뷰 | 마켓핏랩 | 인터뷰 종합: 툴 사용 현황 맵, 업무 마찰 순위, 가설 백로그 초안 |
| Track 2: 리드 기반 디스커버리 | 마켓핏랩 | 경쟁 4사 분석: 기능, 수익모델, 모바일 지원 + 리뷰 분석 (반복되는 불만, 전환을 막는 장벽) |
| Track 2: 리드 기반 디스커버리 | 마켓핏랩 | 메시지 가설별 원페이지 랜딩 제작, 광고 집행 시작, 디스커버리 콜 리드 수집, 리드 품질 선별 |

**Step 3: 온사이트 리뷰 & 다음 계획 수립 (W4~W5)**

- 인터뷰 결과와 광고 반응 데이터 종합 공유
    - Step 2까지는 "어떤 문제에 반응하는가"를 검증
- 전략 판단 재료 정리: 인터뷰·광고 반응에서 확보한 증거가 전략 목적(독립 SaaS, B2G)에 각각 시사하는 바 공유
    - 우선순위 결정은 펫나우 담당, 프로젝트는 재료 공급
- 킬러 유즈케이스 우선순위 합의 후, 다음 단계인 솔루션 검증 실험 설계
    - 선정된 유즈케이스를 실제로 해결했을 때 쓰는가·돈을 내는가 확인. 프로토타입 데모, 파일럿 등

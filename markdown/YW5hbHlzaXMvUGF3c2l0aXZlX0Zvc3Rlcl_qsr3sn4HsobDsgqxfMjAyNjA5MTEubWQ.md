# Pawsitive Foster 경쟁 조사: CAP 이탈 사례와 Petify for Shelters 대비

- 작성일: 2026.09.11
- 성격: 경쟁 포지셔닝 및 후속 대응 제안 (펫나우 전달용)
- 작성 계기: 데모콜 리드 Citizens for Animal Protection(CAP, Jared Carroll)이 2026.09.09 Pawsitive Foster를 선택했다고 통보

## 1. 결론

- **CAP는 Pawsitive Foster 무료판을 시험 사용 중이며, 유료 계약은 아직 아님.** 자사와 2차 미팅을 조율하던 3주 사이(8/22~9/9) 경쟁 제품 사용을 시작함 [검증됨·L0].
- **이탈 요인은 두 가지. 자사에 없는 임보자 대상 기능 6가지와, 가입 즉시 쓸 수 있는 도입 방식.** Jared가 직접 지적한 기능(임보자용 임보 필요 동물 목록, 조건 맞춤 요청 발송, 앱 내 대화, 전체 공지, 픽업 예약, 임보 신청 승인)은 모두 Pawsitive에 있음. 자사 데모에는 임보 필요 동물 목록이 코디네이터 화면에만 있고 나머지 5가지는 없음. 자사가 강점으로 내세운 배치 이후 기능은 CAP의 선택 기준이 아니었음 [검증됨·L0 기능 / 추정·L2 비중].
- **두 제품은 같은 임보 업무를 다루되 앞서는 구간이 다름.** Pawsitive는 임보자 모집·배치·소통, Petify는 배치 이후의 업데이트 검토·입양 준비 판정·게시. 단 Petify 우위는 Pawsitive 공개 자료 기준이라 자사만의 기능으로 단정하지 않음 [의견·L4].
- **CAP 재문의 여지는 남아 있음.** 무료판에는 CAP가 가장 원한 공식 번호 문자 기능이 없고, 임보처 193곳 규모는 무료판 권장 기준(임보자 20명 미만)을 크게 넘어 유료 전환 판단이 따로 남음 [추정·L2].
- **제안 3가지(상세 4절).** ① 파일럿 진입 절차 단축: 2차 미팅 없이 실사용자에게 바로 제안 ② 임보자 모집·소통 기능 6가지의 제품 반영 여부를 펫나우가 결정 ③ CAP 재문의에 대비해 요구별 지원 가능 범위 정리.

## 3. 포지셔닝 비교

### 3.1 제품별 주요 업무와 경쟁 관계

- **주요 업무는 달라도 직접 경쟁임.** 같은 조직이 같은 문제(임보 소통)로 두 제품을 검토하고, 둘 다 기존 CRM 병행 도입 방식임. CAP처럼 소통 정리가 급한 조직은 모집·소통 기능과 도입 편의를 먼저 평가함 [의견·L4].

| --- | --- | --- | --- |
| Chameleon/CMS | 기관의 법정 의무 업무 전반 | · 면허·출동 기록<br>· 수납·감사 기록 | 감사와 규제 대응에 필요한 기록 확보 |

- **위협의 핵심은 회사 규모가 아니라 임보자 대상 기능 격차와 즉시 사용 가능한 도입 방식임.** CAP 1건으로 시장 전체를 일반화하지는 않음 [추정·L2].

| Pawsitive의 검토·입양 준비 기능 추가 가능성 | **중간** [추정·L2] | Enterprise 요금제에 AI가 동물 기록을 갱신하는 기능이 명시돼 있음("AI agents — animal record updates"). Pawsitive가 업데이트 검토나 입양 준비 판정 기능을 추가하면 자사 차별 후보와 겹치게 됨. 실제 추가 여부와 시점은 확인되지 않음 |
| 가격 비교 기준 | **중간** | 자사가 가격을 제시하면 쉘터가 Pawsitive 요금과 비교할 가능성이 있음. CAP는 규모, 직원 계정, 문자 요구를 고려해 Pro 연 $1,548에 문자 추가 비용을 더한 금액이나 Enterprise 견적과 비교할 가능성이 있음 [추정·L2] |
| 회사 규모에 따른 위협 | **낮음~불명** (작은 회사로 보임) | · 2024년 설립(사이트 메타데이터 기준)<br>· 고객 기관명과 고객 수 비공개<br>· 공개 후기 2건(작성자 모두 임보 봉사자이며 소속 기관명은 없음)<br>· 독립 리뷰는 찾지 못함<br>· Google Play 다운로드 10+ |

### 3.3 기능별 우열 요약

- **CAP가 지적한 기능은 모두 배치 이전 업무(Pawsitive 우위), 자사 우위는 배치 이후 업무.** 자사 강점이 CAP의 선택 기준이 아니었을 가능성 [추정·L2]. `*`는 Pawsitive 공개 자료에 언급이 없어 내린 판정이며 자사만의 기능으로 단정하지 않음.

우열: **Pawsitive**/**Petify** = 한쪽 우위, 동등 = 양쪽 제공, 미충족 = 양쪽 모두 CAP 요구 미충족. 근거·요금제 세부는 별첨.

| 기능 | 우열 | 비고 |
| --- | --- | --- |
| 임보 신청서 접수·승인 | **Pawsitive** | Jared 지적. 자사는 입양 신청 처리만 있음 |
| 임보 필요 동물 목록 (임보자 화면) | **Pawsitive** | Jared 지적. 자사는 코디네이터 화면에만 있음 |
| 조건에 맞는 임보자에게 요청 발송 | **Pawsitive** | Jared 지적. 자사는 조건 기록만 있고 발송 없음 |
| 임보자 소통 (앱 내 대화·전체 공지) | **Pawsitive** | Jared 지적. 자사는 이메일·문자 단방향 발송만 |

## 별첨. CAP 요구·기능·도입 조건 상세 비교

- **Pawsitive 무료판에는 문자 기능이 없으며, 유료로 전환하더라도 CAP가 원하는 공식 번호 기반 양방향 문자를 지원하는지는 별도 확인이 필요함.** CAP의 규모와 직원 간 협업 요구를 고려하면, CAP는 Pro 연 $1,548에 문자 추가 비용을 더한 금액이나 Enterprise 견적을 검토할 가능성이 있음. FAQ의 소규모 조직 안내는 권장 사항일 뿐이며, 무료판의 강제 사용 인원 제한으로 보면 안 됨 [추정·L2].
- **자사 데모도 CAP의 PDF·PetPoint 연동 요구와 양방향 문자 요구를 충족하지 못함.** Pawsitive가 이 요구들을 충족하는지는 확인되지 않았으므로, '두 제품 모두 해당 기능이 없다'고 해석할 수 없음. 임보자가 올린 내용을 공개하기 전에 담당자가 승인하는 절차는 자사 데모에서 확인된 차별 후보임 [의견·L4].

**비교 기준:** Pawsitive는 실제 운영 중인 제품의 공개 설명을, Petify는 데모 설계를 기준으로 비교함. 'Petify 차별 후보'는 자사 데모에는 있지만 Pawsitive 공개 자료에서는 제공 여부를 확인하지 못한 기능을 뜻함. Pawsitive 실제 제품에는 있을 수 있으므로 자사만의 기능으로 단정하지 않음. CAP가 직접 제시한 요구와 일반적인 기능 비교 항목은 구분해 적었으며, 무료·유료 구분은 요금제별 제한이 확인된 항목에만 표시함.

# Pawsitive Foster 경쟁 조사: CAP 이탈 사례와 Petify for Shelters 대비

- 작성일: 2026.09.11
- 성격: 경쟁 포지셔닝 및 후속 대응 제안 (펫나우 전달용)
- 작성 계기: 데모콜 리드 Citizens for Animal Protection(CAP, Jared Carroll)이 2026.09.09 Pawsitive Foster 선택 통보

## 1. 결론

- **Pawsitive Foster는 실제 리드와 경합한 임보 전문 경쟁 제품.** CAP가 자사 후속 미팅을 조율하던 중 Pawsitive 무료판 시험 사용을 시작한 사실 확인. 기존 Chameleon·24PetShelter·Petszel 조사만으로 판단한 ‘임보 전문 제품 부재’는 시장 전체에 적용 불가 [검증됨·L0].
- **Pawsitive는 모집·픽업 예약·소통과 즉시 사용 가능한 도입 방식에서 우위. Petify는 배치 이후 입양 업무에서 차별 후보 보유.** 임보자 목록·배정·업데이트 수집은 양쪽 모두 제공. 미응답 독촉·검토 반영·입양 준비 판정·공고 게시·입양 신청 처리 5개 기능은 자사 데모에서 제공. Pawsitive는 공개 자료에서 이 기능들의 제공 여부를 확인하지 못했으며, 실제 제품에는 있을 수 있으므로 자사만의 기능으로 단정 불가 [의견·L4].
- **CAP 선택에는 ‘지금 써볼 수 있는가’가 영향을 줬을 가능성.** 자사 2차 미팅이 약 3주간 성사되지 않은 사이 CAP는 경쟁 제품 사용 시작. 실제 결정 요인은 Jared 회신 전까지 가설로 유지 [추정·L2].
- **CAP는 유료 계약 전 단계이며, 무료판만으로 공식 번호 문자 요구 해결은 어려움.** 직원 계정·문자 기능과 운영 규모를 고려하면 Pro 연 $1,548(연 결제 기준) 및 문자 추가 비용, 또는 Enterprise 견적의 지출 가치를 별도로 판단할 가능성. 규모만으로 유료 전환 필수 판정은 불가 [추정·L2].
- **제안: CAP의 재문의 가능성을 열어두고 대응 범위 준비.** Pawsitive 무료판의 문자·직원 계정 제약이나 유료 비용이 CAP의 사용 목적에 맞지 않으면 자사를 다시 검토할 가능성. 재문의 시에는 시험 사용 중 해결되지 않은 업무를 먼저 확인하고, 자사가 지원 가능한 업무에 한해 파일럿 범위·시작 조건을 안내할 수 있도록 준비 [의견·L4].

- **도입 절차의 차이:** 자사는 Jared와 실사용자인 코디네이터의 후속 미팅 조율이 필요했던 반면, Pawsitive는 신용카드 없이 가입·기관 인증 후 무료판 사용 가능. 공식 안내상 인증은 하루 내 처리("approved within a day")되나, CAP의 실제 소요 시간과 코디네이터에게 자사 데모를 보여줬는지는 미확인. 미팅 대기가 사용 시작을 늦췄을 가능성 [추정·L2].
- **무료판이 해결하는 문제와 남는 요구:** Pawsitive는 "Stop coordinating fosters from your text messages"를 내세우며 앱 메시지로 대화 기록을 조직에 모으는 방식. Jared가 질의한 전용 번호·양방향 문자와는 다른 방식으로, 무료판에는 문자 기능이 없음. 임보자도 앱 또는 웹에서 가입해야 하므로 CAP 시험 사용에서는 임보자의 참여 여부가 중요 [의견·L4].
- **선택 이유는 아직 미확정:** 즉시 사용 가능성 외에 모집·픽업 예약 기능이 우선이었거나 코디네이터가 Pawsitive를 이미 알고 있었을 가능성도 존재. 9/9 발송한 결정 요인 질문의 회신으로 확인 필요 [추정·L2].

## 3. 포지셔닝 비교

### 3.1 제품별 주요 업무와 경쟁 관계

- **같은 조직이 임보 소통 문제를 해결하려고 검토하는 제품이므로 직접 경쟁 발생.** CAP가 두 제품을 검토한 사례 확인. Pawsitive는 기존 CRM 병행 사용을 명시하고, 자사도 CRM 교체 부담을 줄이는 도입 방향을 검토 중 [의견·L4].
- **제품의 주요 업무가 달라도 구매 시 평가받는 기준은 중첩.** CAP처럼 임보 소통 정리가 우선인 조직에서는 모집·소통 기능과 도입 편의가 입양 준비 기능보다 먼저 평가될 가능성 [의견·L4].

### 3.2 CAP 요구·기능·도입 조건 통합 비교

- **무료판에는 문자가 없으며, 유료 전환 시에도 CAP가 원하는 공식 번호·양방향 문자 지원은 별도 확인 필요.** CAP 규모와 직원 협업 요구를 고려하면 Pro 연 $1,548에 문자 추가 비용을 더하거나 Enterprise 견적을 검토할 가능성. FAQ의 소규모 조직 안내는 강제 사용 제한과 구분 [추정·L2].
- **자사도 PDF·PetPoint 연동·양방향 문자 요구 미충족.** Pawsitive는 해당 요구 충족 여부가 미확인이므로 ‘양쪽 모두 기능 없음’으로 해석 불가. 공개 전 승인 절차는 자사 데모에서 확인된 차별 후보 [의견·L4].
- **Petify의 차별 후보 5개는 배치 이후 입양까지의 업무에 집중.** 미응답 독촉·업데이트 검토 반영·입양 준비 판정·공고 게시·입양 신청 처리가 해당. 업데이트 수집 자체는 양쪽에 있으며, 자사의 계정 없는 링크 제출은 제출 편의 측면의 별도 강점 [의견·L4].

**비교 기준:** Pawsitive는 운영 제품의 공개 설명, Petify는 데모 설계 기준. ‘Petify 차별 후보’는 자사 데모에는 있지만 Pawsitive 공개 자료에서는 제공 여부를 확인하지 못한 기능을 뜻함. Pawsitive 실제 제품에는 있을 수 있으므로 자사만의 기능으로 단정하지 않음. CAP가 직접 제시한 요구와 일반 기능 비교를 구분하고, 요금제 제한이 확인된 항목만 무료·유료 구분 표시.

### 3.3 위협 판정

- **현재 확인된 핵심 위협은 회사 규모보다 사용을 시작하기 쉬운 도입 방식.** CAP는 자사 후속 미팅 조율 중 Pawsitive 시험 사용을 시작했으며, 이 차이가 선택에 영향을 줬을 가능성. CAP 1건만으로 시장 전체의 구매 기준을 일반화할 수는 없음 [추정·L2].

## 4. 실행 제안

- **우선 제안: 실사용자가 파일럿을 시작하기까지 필요한 절차 단축.** 별도 2차 미팅 전에도 참여를 제안할 수 있도록 제공 기능·계정·초기 데이터·지원 담당 등 시작 조건을 먼저 정의. 제안 시점 단축과 실제 사용 준비 완료는 구분 필요.
- **CAP 재문의에 대비해 요구별 제공 가능 범위와 파일럿 시작 조건 정리.** 재문의 시 Pawsitive에서 해결되지 않은 업무와 유료 전환 판단 이유를 확인한 뒤 대응. 업데이트 검토·공개 전 승인 등이 필요하면 실제 제공 준비를 확인해 해당 업무의 파일럿을 제안하고, 공식 번호·양방향 문자·PDF·PetPoint 연동이 핵심이면 현재 미지원 범위를 명시. 경쟁 제품의 제약만으로 CAP의 재문의나 자사 전환을 예상하지 않음 [의견·L4].

아래는 실행 확정 사항이 아닌 제안이며, 실익·비용·우선순위는 분석자 판단 [의견·L4]. 실익은 리드 이탈 방지·매출 기회 기여도, 비용은 추가 시간·개발 부담 기준. 실행 여부는 마켓핏랩·펫나우 협의로 결정.

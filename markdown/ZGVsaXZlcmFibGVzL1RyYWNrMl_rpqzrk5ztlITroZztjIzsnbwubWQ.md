## 5. 이 문서를 읽는 법

| 표기 | 뜻 |
| --- | --- |
| — | 해당 문항에 응답이 없음. 2단계 예약 폼까지 진행하지 않으면 조직 유형·직급·규모·도구가 비어 있다 |
| 미조사 | 폼 응답 외에 아무것도 확인하지 않은 상태 |
| 심층조사 | 콜 준비용 사전조사 문서가 별도로 있음 |
| 굵은 도구명 | 이미 유료 전용 도구를 쓰고 있는 조직 |

**출처 없는 값은 넣지 않는다.** 외부 조사 항목은 공개자료 URL을 확인한 것만 적고, 확인하지 못한 항목은 비우거나 미확인으로 남긴다. 추정은 추정으로 표시한다.

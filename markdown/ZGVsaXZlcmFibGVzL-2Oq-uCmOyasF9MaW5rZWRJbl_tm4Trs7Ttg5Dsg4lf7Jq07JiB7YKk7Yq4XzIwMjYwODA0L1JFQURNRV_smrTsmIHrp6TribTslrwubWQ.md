# 펫나우 LinkedIn 인터뷰 후보 탐색·검증 운영 매뉴얼

> 검색 도구로 후보를 발견하고 로그인된 LinkedIn 프로필에서 경력을 직접 확인하는 방식으로 운영 시, 20개 조직에서 고객 공유 후보 20명·1순위 14명을 약 55분에 확보했으며 출처 재감사 대상의 고용형태·주(state) 판정이 모두 일치함.

## 1. 운영 목적

미국 동물보호소·레스큐 조직에서 인터뷰 가치가 높은 현직 실무자와 의사결정자 확보를 위한 운영 절차임. 후보 수보다 LinkedIn 연락 가능성, 현직 여부, 고용형태, 운영 관련성, 근거 신뢰도를 우선함.

### 적용 범위

| 포함 | 제외 |
| --- | --- |
| 미국 동물보호소·레스큐 현직자 | 미국 외 후보 |
| 운영·입양·임보·입소·수송·재무·시설·조직 총괄 | 마케팅·모금 단일 직무 |
| 개인 LinkedIn URL 확보 후보 | 조직 페이지만 확보된 후보 |
| 풀타임·시간제·봉사·미확인 구분 | 직함 기반 풀타임 추정 |

6. ChatGPT 데스크톱 앱의 `Settings > Computer Use > Google Chrome > Manage`에서 `linkedin.com` 차단 여부 확인

공식 안내: [OpenAI Chrome extension](https://learn.chatgpt.com/docs/chrome-extension.md)

## 4. 후보 발견

### 4.1 검색 방식

검색 도구에서 조직당 아래 검색문을 1회 실행함.

```text
site:linkedin.com/in "[조직명]" (operations OR program OR adoption OR foster OR intake OR transport OR finance OR executive)
```

결과가 부족한 경우에만 역할군을 운영·재무 2개로 나누어 1회 추가함. Chrome의 Google 검색 화면을 반복 자동화하지 않음.

### 4.2 발견 후보 저장 조건

- 개인 LinkedIn URL 확인
- 이름 확인
- 현재 조직 또는 현재 역할 단서 확인
- 미국 소재 단서 확인
- 조직당 최대 3명

조직 소속만 보이고 구체적인 현재 직함이 없는 후보는 발견 풀에만 저장함.

## 5. LinkedIn 직접검증

후보별 개인 프로필을 직접 열어 다음 영역을 확인함.

| 영역 | 기록값 | 판정 기준 |
| --- | --- | --- |
| 상단 | 확인 / 미확인 | 이름·헤드라인·지역·현재 조직 |
| 소개 | 확인 / 섹션 없음 확인 / 미확인 | 소개 내용 또는 섹션 부재 직접 확인 |
| 경력 전체 | 확인 / 미확인 | 현재 직책·기간·고용형태 확인 |
| 봉사 경력 | 확인 / 섹션 없음 확인 / 미확인 | 일반 경력과 분리 |
| 추천사 | 확인 / 섹션 없음 확인 / 미확인 | 추천사 내용 또는 부재 확인 |
| 최근 활동 | 확인 / 활동 없음 확인 / 미확인 | 최근 게시물·댓글·반응 |

검색 결과 스니펫만으로 `프로필 직접검증=완료`를 부여하지 않음. 경력 전체를 확인하지 못한 후보는 고객 공유 목록에 포함하지 않음.

## 6. 고용형태 판정

| 표준 코드 | 표시용 판정 | 직접 근거 |
| --- | --- | --- |
| `FT-LI` | 풀타임 직접 확인 | LinkedIn `Full-time`·`정규직` |
| `FT-OFFICIAL` | 풀타임 직접 확인 | 공식 원문 `full-time employee` 등 |
| `PAID-HOURS-UNK` | 유급·시간 미확인 | Form 990 보수 또는 공식 유급 근거 |
| `PT` | 시간제 직접 확인 | LinkedIn·공식 원문의 `Part-time` |
| `VOL` | 봉사 직접 확인 | LinkedIn 봉사 경력·공식 volunteer |
| `UNK` | 미확인 | 직함만 확인, 직접 표기 없음 |

`Director`, `Manager`, `Coordinator` 등 직함만으로 풀타임을 추정하지 않음.

## 7. 외부 원문 검증

후보당 `후보 이름 + 조직명` 검색을 1회 수행함.

### 출처 우선순위

1. 조직 공식 팀 페이지
2. 조직·공공기관 보도자료
3. Form 990·정부 공개자료
4. 공식 행사·모금 페이지
5. 신뢰할 수 있는 제3자 자료

외부 페이지 본문에서 후보 이름을 직접 확인한 경우에만 근거 URL로 채택함. 중간 이름·자격 표기 생략은 동일 인물로 인정함. 이름이 없으면 `검색 완료·근거 없음`으로 기록함.

여러 URL은 같은 셀에서 줄바꿈함. 검색 결과 URL과 이름이 없는 조직 홈페이지는 근거 URL로 채택하지 않음.

## 8. 지역 입력

| 컬럼 | 입력 기준 | 예시 |
| --- | --- | --- |
| 주·도 | 미국 주 정식 영문명 | New York |
| 도시 | 도시·자치구 | Brooklyn |
| 도시권 | 광역권·복수 근무지 | New York City |

Brooklyn·Manhattan·Columbus 등 도시를 `주·도` 컬럼에 입력하지 않음.

## 9. 발송 우선순위

### 1순위

아래 조건을 모두 충족한 후보임.

- 개인 LinkedIn URL 및 미국 현직 확인
- 고용형태 `FT-LI` 또는 `FT-OFFICIAL`
- 운영·구매·예산·입양·임보·입소·수송 운영 책임 확인
- LinkedIn 경력 전체 확인
- 최근 활동 확인 또는 공식 외부 개인 근거 확보

### 기타 우선순위

| 우선순위 | 조건 |
| --- | --- |
| 2순위 | 미국 현직·업무 관련성 확인, 시간제 또는 고용형태 미확인 |
| 3순위 | 미국 현직 봉사자 또는 직접 연락 가능성이 낮은 후보 |
| 보류 | 현재성·지역·역할 관련성 미확인 |
| 제외 | 개인 URL 미확보, 미국 외, 과거 역할, 관련성 낮음 |

## 10. 계정 보호

- Chrome Google 검색 화면 반복 자동화 금지

- CAPTCHA 풀이·우회, 쿠키 추출, 비공개 API 사용 금지
- 메시지·친구 추가·팔로우·좋아요 자동 실행 금지

## 12. 독립 표본검증

매 실행마다 전체 전수조사를 반복하지 않음. 신규 결과에서 아래 표본을 추출하여 기존 결과를 보지 않은 별도 세션이 재감사함.

| 표본 | 수량 | 검증 내용 |
| --- | ---: | --- |
| 1순위 | 5명 | 풀타임·현직·역할·최근 활동 또는 외부 근거 |
| 2·3순위 | 3명 | 미확인·시간제·봉사 판정의 보수성 |
| 외부 URL 보유 | 2명 | 원문 이름 확인 |

### 합격 기준

- 고용형태 의미 일치율 90% 이상
- 주(state) 일치율 95% 이상
- 1순위 출처 재감사 정밀도 90% 이상
- 채택 외부 URL 이름 확인률 100%

불일치 시 기준 시트를 정답으로 가정하지 않고 LinkedIn 프로필과 공식 원문으로 재감사함.

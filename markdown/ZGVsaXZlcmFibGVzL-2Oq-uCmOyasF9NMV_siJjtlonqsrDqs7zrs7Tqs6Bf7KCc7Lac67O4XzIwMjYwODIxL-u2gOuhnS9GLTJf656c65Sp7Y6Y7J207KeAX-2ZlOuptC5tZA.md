# 랜딩페이지 화면

| 항목 | 내용 |
| --- | --- |
| 배포 주소 | `petify-for-shelters.pages.dev` |
| 촬영 기준 | 광고 집행 기간의 최종 배포 상태를 그대로 재현 |
| 촬영 환경 | 모바일 화면 기준 (폭 390pt). 광고 유입의 대다수가 모바일임 |
| 표시 방식 | 페이지 상단부터 하단까지를 6개 구간으로 나누어 순서대로 배열 |

- 소재별로 별도 랜딩페이지를 운영하여, 광고에서 제시한 문제와 랜딩페이지가 제시하는 해결 방식을 일치시킴

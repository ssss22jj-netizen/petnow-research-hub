# 펫나우 Chrome 연결형 LinkedIn 독립검증 환경 v3

> 결론: 기존 Chrome 프로필의 LinkedIn 로그인 상태는 재사용하고, 후보 생성·판단을 수행하는 Codex 세션에는 과거 후보 목록·판정·결과 파일을 제공하지 않는 클린룸 재현 절차임.

## 1. ChatGPT Chrome 확장 설치

1. ChatGPT 데스크톱 앱 실행
2. `Plugins Directory`에서 `Chrome` 설치
3. 안내에 따라 [ChatGPT Chrome 확장](https://chromewebstore.google.com/detail/chatgpt/hehggadaopoacecdllhhajmbjkdcmajg) 설치
4. Chrome 권한 요청 승인
5. 확장을 설치한 Chrome 프로필에서 ChatGPT 사이드 패널 실행
6. 사이드 패널이 로드되는지 확인
7. ChatGPT 데스크톱 앱의 `Settings > Computer Use > Google Chrome > Manage`에서 `linkedin.com` 차단 여부 확인

Chrome 확장 설치·권한 변경은 사용자가 직접 수행함. Chromium 계열의 다른 브라우저는 사용하지 않음.

## 2. 기존 Chrome을 사용한 클린룸 구성

| 구분 | 사용 | 차단 |
| --- | --- | --- |
| Chrome 프로필 | 기존 사용자 프로필 | 신규 비로그인 프로필 |
| 로그인 상태 | 기존 LinkedIn 세션 | ID·비밀번호 전달, 쿠키 열람 |
| 작업 창 | LinkedIn 전용 새 Chrome 창 | 후보 시트가 열린 창·탭 |
| 입력 자료 | 본 폴더의 절차·조직·검색식·빈 템플릿 | 기존 후보 CSV·Google Sheet·검증 보고서·PROJECT_STATE |
| 판단 주체 | `fork_turns="none"`의 새 Codex 세션 | 기존 대화 이력을 상속한 세션 |

실행 전 기존 후보 시트, 검증 보고서, 후보 이름이 보이는 탭을 닫음. 같은 Chrome 프로필에서 새 창을 열고 `https://www.linkedin.com/feed/`만 연 상태로 시작함. 브라우저는 동일하되 판단 정보의 유출 경로를 차단하는 구성임.

## 3. 실행 전 강제 사전점검

아래 조건을 모두 충족하지 않으면 후보 탐색을 시작하지 않음.

| 점검 항목 | 합격 기준 | 실패 처리 |
| --- | --- | --- |
| Chrome 연결 | 브라우저 유형이 `extension` | 실행 중단 |
| LinkedIn 로그인 | `/feed/`가 `/uas/login`으로 이동하지 않음 | 사용자 로그인 후 재점검 |
| 프로필 접근 | LinkedIn 개인 프로필에서 이름·헤드라인 표시 | 실행 중단 |
| 경력 접근 | 경력 섹션 또는 `모두 표시` 진입 가능 | 상세검증 불가 처리 |
| 클린룸 | 후보 시트·과거 결과 탭이 열려 있지 않음 | 해당 탭을 닫고 새 세션 시작 |

사전점검 결과를 `preflight_log.md`에 기록함. 로그인 실패 상태에서 공개 검색으로 대체하지 않음.

## 4. 독립 세션의 정보 차단

- 새 세션은 과거 대화 전체를 상속하지 않음
- 새 세션이 읽을 수 있는 프로젝트 파일을 본 v3 폴더로 제한
- 기존 후보 이름, LinkedIn URL, 우선순위, 특징, 고용형태 판정, 비교 결과를 전달하지 않음
- Chrome 방문 기록 API를 호출하지 않음
- 열린 탭 전체를 탐색하지 않고 사용자가 준비한 LinkedIn 전용 탭만 사용
- 결과 확정 전 기준 시트와 대조하지 않음
- 기준 시트 비교는 독립 세션 종료 후 별도 평가 세션에서 수행

조직 레지스트리와 검색식은 재현 가능한 조사 설계이므로 제공 가능함. 기존 후보 및 기존 판정은 정답 누출이므로 제공하지 않음.

## 5. 프로필 직접검증 기준

후보별로 LinkedIn 개인 프로필을 직접 열고 다음 영역을 확인함.

1. 상단: 이름, 헤드라인, 지역, 현재 조직
2. 소개: 담당 업무와 의사결정 범위
3. 경력 `모두 표시`: 현재 직책, 기간, 고용형태, 조직
4. 봉사 경력: 일반 경력과 분리
5. 추천사: 직무·협업 범위를 뒷받침하는 내용 유무
6. 최근 게시물·댓글·반응: 최근 활동과 현직 관련성
7. 공식 외부 근거: 본문에서 후보 이름이 확인되는 URL만 채택

프로필에서 실제로 확인하지 않은 영역은 `미확인`으로 기록함. 검색 결과 스니펫만으로 `프로필 직접검증=완료`를 부여하지 않음.

## 6. 봇 탐지·계정 보호 운영

- 프로필을 짧은 시간에 대량으로 연속 개방하지 않음
- 검색 결과를 무한 스크롤하거나 자동 반복 수집하지 않음
- 조직별 소수 후보를 발견한 뒤 사람 단위 상세검증으로 전환
- CAPTCHA, 보안 확인, 사용 제한 메시지가 나타나면 즉시 중단하고 사용자에게 인계
- CAPTCHA 우회, 쿠키 추출, 비공개 API 호출, 접속 제한 회피 금지
- 메시지 발송·친구 추가는 조사 범위에서 제외

## 7. 완료 판정

고객 공유 후보는 다음 조건을 모두 충족해야 함.

- 개인 LinkedIn URL 직접 개방
- 이름·현재 역할·지역 직접 확인
- 경력 또는 봉사 경력에서 고용형태 판정 근거 확인
- 확인한 LinkedIn 영역과 확인 시각 기록
- 외부 URL은 본문에서 후보 이름 확인
- 근거가 없는 추정은 `미확인` 처리

로그인 검증을 거치지 않은 후보는 발견 풀에는 남길 수 있으나 고객 공유 후보로 승격하지 않음.

## 8. 재현성 평가

독립 실행이 끝난 뒤 평가 세션에서만 기준 시트를 열고 다음 지표를 계산함.

| 지표 | 산식 |
| --- | --- |
| 프로필 중복률 | 독립 실행과 기준 시트의 동일 LinkedIn URL 수 / 독립 실행 후보 수 |
| 기준 후보 재현율 | 동일 LinkedIn URL 수 / 기준 시트 후보 수 |
| 고용형태 일치율 | 중복 후보의 동일 판정 수 / 판정 비교 가능 후보 수 |
| 지역 일치율 | 중복 후보의 동일 주·도시 수 / 지역 비교 가능 후보 수 |
| 1순위 정밀도 | 재감사에서 1순위 조건을 충족한 수 / 독립 실행 1순위 수 |
| 직접검증 완결률 | 필수 LinkedIn 영역을 확인한 후보 수 / 고객 공유 후보 수 |

후보 중복률은 참고 지표임. 핵심 품질 지표는 프로필 직접검증 완결률, 고용형태·지역 일치율, 1순위 정밀도임.

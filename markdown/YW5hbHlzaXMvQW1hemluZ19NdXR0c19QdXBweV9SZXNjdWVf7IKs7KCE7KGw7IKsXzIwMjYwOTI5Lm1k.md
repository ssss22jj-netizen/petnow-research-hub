## 미팅에서 바로 쓸 핵심 5줄

1. **폼의 "Over 300" 은 최상단 구간 선택이고, 실제는 연 450~520건으로 본다 — 폼 응답의 약 1.5~1.7배다** — 990 의 프로그램 수입이 2023년 $256,800 / 2024년 $270,904 이고, 사이트가 공표한 입양비가 **강아지 전부 $595, 성견 $515~615** 다. 나누면 **2023년 약 432~499건, 2024년 약 455~526건**이 나온다. 조직 About 페이지는 한 술 더 떠 **"saved over 7,000 dogs and pups in just ten years"**(연 700건)를 내건다. **콜의 첫 앵커를 "300 이상"에 두지 말고 "연 500건 가까이"에 둔다.** 다만 산식이므로 "제 계산으로는 연 500건 근처로 보이는데 맞나요" 로 확인받는 형태로 꺼낸다.

2. **이 규모를 쉘터 관리 소프트웨어 없이 돌린다 — 폼의 `Google sheets` 는 겸손이 아니라 사실이다** — 사이트 HTML 을 훑으면 나오는 것은 **WordPress + Breakdance(빌더) + Gravity Forms + WooCommerce + WooCommerce Payments + The Events Calendar + WP Rocket + Smush Pro** 뿐이다. **ShelterLuv·Petstablished·Pawlytics·Chameleon·RescueGroups 흔적이 한 줄도 없다.** 유급 직원도 0명이다(990: 임원 보수 0, 급여 0). **우리 가설(분산 케어 추적이 스프레드시트로 샌다)이 방어 없이 그대로 성립하는, 드물게 깨끗한 리드다.**

3. **가장 단단한 실측 증거는 사진이다 — 포스터의 근황이 시스템이 아니라 Facebook 에 산다** — 홈페이지 `available-dogs` 페이지에 걸린 개 사진들의 **업로드 파일명이 전부 Facebook CDN 명명 규칙**(`782298199_3399575676890379_..._n`)이다. 곧 **포스터가 Facebook 에 올린 사진을 사람이 내려받아 워드프레스에 다시 올린다.** 게다가 같은 페이지가 **"All pups are currently IN-HOUSE! Check out our official Facebook Page"**, **"most up to date with available pups"** 라고 스스로 적어, **공식 재고 현황이 홈페이지가 아니라 Facebook 이라는 것을 자백한다.** 콜에서 기능 설명 대신 이 경로를 그대로 읊는다.

4. **돈 이야기를 우리가 먼저 꺼내면 진다 — 순자산이 마이너스다** — 2023년 말 기준 **총자산 $9,646 / 부채 $82,567 / 순자산 −$72,921**. 2019년 +$14,729 에서 2020년 −$12,154 → 2021년 −$31,432 → 2022년 −$67,553 → 2023년 −$72,921 로 **4년 연속 깊어졌다.** 연 수입은 $266k~$346k 인데 남는 돈이 없다(부채 대부분은 동물병원 미지급금으로 추정 — 직접 확인 필요). **월 구독료를 먼저 말하지 말고, 비용을 "주당 몇 시간" 으로 묻는다.**

5. **결재선이 한 사람이고, 이미 유료 소프트웨어를 사는 조직이다** — Stacy Medina-Avery 가 **President 겸 Treasurer** 다(990). 이사회는 Secretary(Terry Alloway) 포함 사실상 2~3인이고 전원 무보수다. **결정과 지출이 같은 손에 있다.** 그리고 Gravity Forms·Breakdance·WP Rocket·Smush Pro 는 전부 유료 라이선스다 — **"소프트웨어에 돈을 안 쓰는 조직" 이 아니라 "쉘터 소프트웨어만 안 산 조직" 이다.** 이 구분이 이 콜의 성패를 가른다.

## 8. 워크플로 힌트 (수기 업무 추정 단서)

- **사진이 Facebook 을 경유해 손으로 옮겨진다** — 홈페이지 게재 이미지 파일명이 전부 Facebook CDN 규칙이다. 곧 **포스터가 Facebook 에 올림 → 누군가 내려받음 → 워드프레스에 업로드** 의 3단계가 매 마리마다 돈다. 연 450~520건이면 **주당 10마리 안팎**이 이 경로를 통과한다. **확인 필요 — "홈페이지에 올라간 사진이 Facebook 에서 온 파일이던데, 포스터가 올린 걸 직접 받아서 올리시는 거예요?"**
- **신청서는 한 폼에 섞여 쌓이고, 그 다음이 비어 있다** — Gravity Forms 단일 폼(`gform_2`)에 입양·포스터가 드롭다운으로 갈린다. FAQ 는 **"assigned to a processor"** 라고 배정 단계를 명시하는데, **배정·진행 상태를 담는 곳이 도구 안에 없다.** 폼의 `Google sheets` 가 여기 쓰일 개연이 가장 크다(추론). **확인 필요 — "폼에 적으신 구글 시트에 정확히 뭐가 적혀 있어요? 신청자 명부인가요, 개 목록인가요, 포스터 명부인가요?"**
- **입양 후 기한이 개체마다 따로 돈다** — 잔여 DAPP 시리즈와 중성화를 기한 내에 끝내야 하고 **넘기면 처음부터 다시**다. 강아지를 배치 단위로 들여오므로 **한 이송에 들어온 여러 마리의 기한이 동시에 굴러간다.** 그런데 **증빙 제출처가 공개 자료 어디에도 없다.** **소재 A(입양 준비 상태 추적)에 반응한 지점이 여기일 개연이 크다.** 확인 필요 — "접종 남은 거랑 중성화 기한은 개별로 어디에 적어 두세요?"
- **입양자 사후 관리가 비공개 Facebook 그룹이다** — 가족이 근황을 올리고 자원봉사자가 본다. **기록이 아니라 타임라인**이라 특정 개의 상태를 되짚으려면 스크롤해야 한다(추론). 확인 필요.
- **파양 서류가 별도 메일함에 쌓인다** — 4DX 검사 증빙, SOAP 노트 포함 전체 진료기록, 트레이너 소견을 받아야 하고 대기가 **1주~3개월**이다. 이 접수함이 **대표 gmail 이 아니라 optimum.net 메일**이다. **서류 대기 목록이 메일함에만 있을 개연**(추론). 확인 필요.
- **주 2회 부스 + 계절 행사 = 개체 이동이 상시로 발생한다** — 수·일마다 포스터들이 개를 데리고 오고 간다(자원봉사 역할에 "Puppy Ubers" 가 따로 있다). **누가 어느 개를 어느 행사에 데려오는지의 배차·출석 관리**가 어딘가에서 돌고 있을 것이다. 확인 필요 — "수요일·일요일에 어느 개가 나오는지는 어떻게 정하고 알리세요?"
- **재고의 진실 소스가 두 개다** — 홈페이지 게재 페이지와 Facebook. 조직 스스로 **Facebook 이 더 최신**이라고 안내한다. 곧 **두 곳을 사람이 맞춰 준다**는 뜻이다(추론). 확인 필요.
- **그랜트 항목이 2024년에 새로 생겼다($0 → $62k)** — 자원봉사 모집에 "Grant Writing" 도 있다. **그랜트 보고서에 넣을 실적 수치를 어디서 뽑는지**가 이 조직의 숨은 통증일 수 있다(추론). 확인 필요.
- **하지 말 것** — ①가격을 먼저 말하기 ②Facebook 을 대체 대상으로 말하기 ③"체계가 없다" 류 진단 ④적자·부채를 우리가 먼저 지적하기 ⑤불만 신고 집계 사이트 항목 언급 ⑥과거 이름 언급 ⑦번지 주소 언급.

## 미확인 요약 (콜에서 확인할 것)

1. **[최우선] 실제 연 입양 건수와 기준 연도** — 폼은 "Over 300", 계산치는 연 450~520건, 조직 자기 공표는 10년 7,000마리(연 700건)다. **세 숫자가 다 다르다.** 어느 정의(인테이크/입양/이송)로 세는지, 그리고 **그 숫자를 어디서 뽑는지**.
2. **`Google sheets` 의 실체** — 시트가 몇 개이고 각각 무엇을 담는가(개 목록 / 포스터 명부 / 신청자 대기열 / 의료 일정 / 입양 후 기한). **누가 열고 누가 고치는가.**
3. **신청서 접수 이후의 파이프라인** — "processor" 가 몇 명이고 어떻게 배정되는가. 24~72시간 약속을 무엇으로 지키는가. Gravity Forms 엔트리에서 승인까지 상태가 어디에 남는가.
4. **사진·근황 수집 경로** — 포스터 → Facebook → 홈페이지 수기 이관이 맞는가. 주당 몇 건이고 누가 하는가. **Petfinder 게재는 자동인가 수기인가.**
5. **입양 후 백신·중성화 기한 추적** — 개체별 기한을 무엇으로 관리하는가. 증빙은 어느 채널로 받는가. **기한을 놓쳐 재시작한 사례가 실제로 있는가.**
6. **포스터 가정 수와 배치 현황** — 지금 몇 가정이 몇 마리를 보고 있는가. **"어느 개가 어느 집에" 를 여는 곳이 시트인가 기억인가.** 폼이 이번엔 포스터 수를 묻지 않았으므로 통째로 미확인이다.
7. **행사 운영** — 수·일 부스와 계절 행사에 나갈 개·포스터·자원봉사자를 어떻게 정하고 공지하는가.
8. **인력 실체** — 유급 0명은 확정. 실제로 매주 손을 쓰는 자원봉사자가 몇 명이고, **도구를 매일 열 사람이 몇 명인가.** Foster Coordinator 는 누구인가.
9. **재무 상황의 배경** — 부채 $82,567 의 성격(동물병원 미지급금 추정)과 2024년 신규 기부·그랜트 $62,051 의 출처. **우리가 먼저 묻지 않되, 본인이 꺼내면 받는다.**
10. **Petfinder·Adopt-a-Pet 등재 실태** — 본인들은 Petfinder 게재를 명시하나 조직 페이지를 찾지 못했다. **실제로 살아 있는 채널인가.**

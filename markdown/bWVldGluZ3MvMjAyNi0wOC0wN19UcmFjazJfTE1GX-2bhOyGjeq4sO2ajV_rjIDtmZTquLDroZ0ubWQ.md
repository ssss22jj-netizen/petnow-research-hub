## 한눈에 보는 후속 정리

8/5 미팅에서 공유/논의된 내용들 기반으로, 실제 실험 진행을 위해 구체적으로 검토/정의 필요한 부분 진행

특히, 제품 광고와 후속 인터뷰의 불일치로 인한 미스리딩·인터뷰 품질 저하 방지 고려(Johnny 우려 지점)

| 구분 | 8월 5일 이후 카야 진행 내용 |
| --- | --- |
| 캠페인 목적 | 리드 수집 이후 액션을 인터뷰와 데모 사이에서 검토: 데모로 확정 |
| LMF 방향성 명료화 | 구현 완료된 기능 판매가 아닌, 제시한 문제와 해결 방식에 대한 관심·데모 예약·가격 반응을 확인하는 페이크도어·프리토타입(Pretotype) 테스트|
| 제품 맥락 정리 | LP에서 제시할 약속, 경쟁 우위 구체화를 위해 펫나우·Petstablished 관계 재정리. 펫나우 CRM은 자체 동물 레코드로 크로스보더 정보와 준비 상태를 관리함. Petstablished는 KK9R 뉴욕 조직의 즉시 Intake, 외부 게시, 입양 운영을 담당. Petstablished의 핵심 기능은 외부 게시(API)  |

| 리드 이후 액션| 실제 계정 제공 없이 인터뷰어가 클릭형 프리토타입을 시연하는 데모·피드백 세션 진행 |
| 프리토타입 운영 기준| 광고·랜딩페이지에서는 프리토타입으로 시연가능한 기능 적극 표시, 단 '제품 준비 시 얼리 액세스 연락' 등의 표현으로 제품 제공이 바로 가능한 것이 아님을 표현 |
| 운영 기준 수립| 소재당 예산 10%·50%·100% 소진 시점에 기술 상태, CTR 추이, 랜딩페이지 행동, 리드·데모 행동을 단계별 점검 |
| 최종 판정 정의| CTR과 리드 제출, 이후 행동 등 구체적 지표 정의, 후속 검증 기능 우선순위 판별 기준 정리 |



## 1. 캠페인 운영 목표 재검증, 구체화 (인터뷰 or 데모?)

8월 5일 미팅에서 논의한 랜딩 이후의 액션 구조를 한번 더 검토함.
인터뷰와 데모의 목적 차이
- 인터뷰: 고객 문제와 요건을 **새로 발견**하기 위한 방식
- 데모: 우리가 설정한 문제와 해결 방식에 대한 **시장 반응**을 확인

근데 이 두 목적은 이미 최초 방향성 설정 시 나누어 놓음 :
- [Track1] 네트워킹 인터뷰: 실제 업무 흐름과 사용 툴에 대한 심층 관찰(**문제 발견**)
- [Track2] 리드 기반 디스커버리: 어떤 문제 메시지에 반응하는지에 대한 정량 신호(**시장 반응**)

Track 2 LMF 캠페인에서는 하나의 제품에서 어떤 문제와 기능이 가장 강하게 소구되는지 확인하고, 새로운 문제 발견을 위한 인터뷰는 Track 1에서 별도로 진행하는 것이 적합하다고 재차 정리함.

트랙별 메시지·CTA·콜 형식을 구체화함.
현재 카야 작업 우선순위는 LMF, 커스텀 CRM트랙은 후순위

| 트랙 | 광고·랜딩페이지 | 리드 이후 |
| --- | --- | --- |
| LMF 캠페인 | 단일 제품의 A·B·C 진입 소구점 → 데모 예약 | 인터뷰어가 하나의 클릭형 프리토타입을 소재별 시작 화면에서 시연하는 데모·피드백 세션 |
| 커스텀 CRM 트랙 | 조직별 맞춤 CRM → 요건 설문 | 완성 제품 데모 없이 문제·요건을 확인하는 디스커버리 콜 |

## 2. 기 개발된 제품 맥락 재확인(LP 방향성 및 데모 적합성 판단)

| 제품 | 재확인한 범위 |
| --- | --- |
| Petstablished | 신청, 계약, 결제, 의료, 마이크로칩, 보고서, 외부 게시 등을 포함하는 범용 CRM |
| KK9R용 펫나우 CRM | 한·영 정보, 운송, 수입 문서, 홈페이지 공개 준비 등 KK9R의 크로스보더 업무 중심으로 기개발된 제품 |

- KK9R용 펫나우 CRM은 자체 동물 레코드를 보유하면서 한국과 뉴욕 사이의 건강·행동·미디어·허가 정보와 입양 준비 상태를 관리하는 구조
- Petstablished는 KK9R 뉴욕 조직에서 신규 동물 즉시 등록, 홈페이지·Petfinder·Adopt a Pet 게시, 신청자·임보자·입양자와 입양 업무 관리에 매일 사용
- 기능 범위는 Petstablished **전체를 대체하지 않지만** 데이터 구조는 **별도의 동물 레코드**를 보유하는 **병행 운영** 시스템에 가까움
- 두 시스템의 자동 연동, 동물 ID 연결, 필드별 최종 원장, 중복 입력 범위는 미확인
- Track 2에서는 제품 유형을 먼저 확정하기보다 **하나의 통합 제품 흐름**에서 **문제·기능별 시장 반응**을 비교

## 3. LMF 캠페인 설계 방향

| 검토 항목 | 카야 후속 작업 방향 |
| --- | --- |
| 검증 대상 | 현재 구현 여부가 아니라 문제 반응, 해결 방식 반응, 데모 예약, 조건부 가격 인식 |
| 소재 구성 | 하나의 제품 흐름을 유지하고 A·B·C별 문제제기형과 해결책형을 함께 구성 |
| 광고·랜딩페이지 | **A·B·C가 결합된 제품 경험을 제시하고, 광고 유입자를 해당 소재의 프리토타입 데모로 연결** |
| CTA 방향 | 즉시 제품 제공을 전제하는 무료 체험·즉시 사용 대신 **데모·얼리 액세스·피드백 세션**으로 전환 |
| CTA 예시 | `Book a demo & feedback session`, `Request early access`, `See the workflow`, `Preview the workflow` |
| 데모 | 하나의 피그마 **프리토타입**(**[링크](https://www.figma.com/design/YT41mZ3g78IJMlxVOjnNMu/Petnow-CRM-%C2%B7-LMF-Demo-Wireframes-%C2%B7-2026-08-06?node-id=0-1&t=igW01OBXFGy7vXim-1)**)을 사용하되 A는 준비 상태 화면, B는 임보 업데이트 화면, C는 신규 등록 화면에서 시연 시작 |
| 인터뷰 | 데모에 대한 반응 온도, 현재 업무, 후속 논의/파일럿/구매 의향 확인 |
| 세션 종료 | 제품 준비되면 early access 연락 드리겠다고 안내하며 인터뷰 종료 |

### 프리토타입 고객 안내 원칙

- 제품 가치와 A·B·C 기능은 적극적으로 제시
- CTA는 `Book a demo` 또는 `Request early access`와 같은 표현 사용 CTA 아래 한 줄과 신청 완료 화면에서 얼리 액세스 단계임을 자연스럽게 안내 (예: Preview the workflow and get notified when early access opens. )
- 광고·랜딩페이지에서 제시한 제품 경험을 프리토타입 데모에서 동일하게 시연
- 현재 즉시 제공할 수 있다고 오해하게 만드는 표현 금지 (예: Try it free, Connect Petify now)

## 4. 프리토타입 흐름 및 소구점 정리

### 4.1 프리토타입 흐름

| 단계 | 사용자 문제 | 프리토타입에서 제시할 기능 | 연결 소재 |
| --- | --- | --- | --- |
| 1. 동물 등록 | 필드가 많고 기본정보·사진 등록이 번거로움 | 필수 정보 중심 Intake, 사진 다중 업로드, 임시 저장 | C |
| 2. 준비 항목 관리 | 건강·행동·미디어·서류가 여러 도구에 분산 | 동물별 준비 체크리스트, 필수 항목 설정 | A·C |
| 3. 현장·임보 업데이트 요청 | 운영자가 임보자에게 반복 연락하고 여러 채널을 확인 | 계정 없이 사용하는 모바일 링크, 요청·리마인드 | B |
| 4. 업데이트 검토 | 제출 정보가 문자·이메일·폼에 흩어짐 | 신규 제출함, 변경 내용 비교, 승인·보완 요청 | B |
| 5. 준비 상태 판단 | 어떤 동물이 준비됐고 무엇이 부족한지 즉시 확인하기 어려움 | Ready·Blocked 상태, 누락 항목, 담당자·다음 행동 | A |
| 6. 게시 준비 | 게시 직전 사진·설명·서류의 재확인 필요 | 게시 미리보기, 공개 가능 여부, 차단 사유 | A·C |
| 7. 게시 | 홈페이지와 외부 입양 채널에 반복 게시하거나 반영 상태를 확인해야 함 | 홈페이지 공개, 외부 입양 플랫폼 전송 및 상태 확인 | C |


### 4.2 소재별 소구점

| 소재 | 문제 가설 | 해결책 | 주요 시연 화면 |
| --- | --- | --- | --- |
| A. 준비 상태 판단 | 어떤 동물이 입양 준비를 마쳤는지 판단하기 어려움 | 준비된 동물과 누락 항목을 즉시 확인 | Ready·Blocked 목록과 차단 사유 |
| B. 임보자 업데이트 수집 | 임보자 업데이트를 받기 위해 반복 연락하고 여러 채널을 확인해야 함 | 임보자의 간편 제출과 운영자의 수집·검토 | 임보자 모바일 입력 및 운영자 검토 화면 |
| C. 등록부터 게시까지의 업무 부담 | 신규 동물 등록, 미디어·서류 정리, 게시 준비와 채널별 게시 과정이 번거로움 | 간편 Intake부터 준비정보 관리와 게시까지 연결 | 신규 동물 등록 후 준비 체크리스트·게시 화면으로 연결 |


### 4.3 소재 반응 해석

- A·B·C별로 서로 다른 제품을 제시하지 않고 하나의 제품 흐름에서 광고·랜딩페이지의 진입 소구점만 변경
- 하나의 공통 동물 레코드와 화면을 사용하고 소재별 데모 시작 화면만 구분
- 소재별 반응 차이를 별도 제품 후보의 우열이 아니라 시장 진입 시 먼저 제시할 문제 언어와 대표 기능의 우선순위로 해석
- 광고 클릭은 문제·메시지 반응, 랜딩페이지 행동은 해결 방식 관심, 데모 이후 행동은 제품 가설 진전으로 구분

## 5. 광고 운영 및 최종 판정 기준

### 5.1 예산 소진 시점별 운영 판단

| 시점 | 확인 항목 | 조치 |
| --- | --- | --- |
| **예산 10% 소진**<br>소재당 1.5만 원 | 광고 링크, 모바일 로딩, 분석 이벤트, CTA와 리드 폼의 정상 작동 여부, 광고 클릭 발생 여부 및 랜딩페이지 스크롤 깊이 | 기술적 오류 우선 수정. 측정이 정상인데 클릭이나 스크롤 깊이가 현저히 낮은 경우 소재 교체 검토 |
| **예산 50% 소진**<br>소재당 7.5만 원 | 동일 채널 내 소재별 CTR 추이, 페이지 조회 이후 스크롤·CTA·리드 제출 발생 여부 | Meta·LinkedIn의 공개 CTR 벤치마크와 동일 채널 내 소재 간 차이를 함께 확인. 표본이 작으면 중단하지 않고 잠정 우세·열세만 기록 |
| **예산 100% 소진**<br>소재당 15만 원 | CTR, 랜딩페이지 전환, 리드 적합성, 데모 참석과 후속 행동 종합 | 문제·메시지 반응, 해결 방식 관심, 제품 가설 진전을 분리해 최종 기록 |

<small>※ CPM 참고: 2026년 1분기 미국 Meta 광고 평균 CPM은 Traffic·Engagement 캠페인 $10~15, 웹사이트 Lead Generation 캠페인 $26~40 수준임. 좁은 타깃의 리드 캠페인은 $40~55까지 상승 가능. 출처: [Affect Group, US Meta Ads CPM Insights Q1 2026](https://affectgroup.com/blog/meta-ads-cpm-in-the-united-states-benchmarks-for-facebook-and-instagram/)</small>

#### 지표 조합에 따른 중간 대응

| 결과 조합 | 판단 및 조치 |
| --- | --- |
| CTR 낮음 + 이후 행동도 낮음 | 광고 소재 교체 또는 중단 후보 |
| CTR 낮음 + 리드 전환 높음 | 대중적 반응은 약하지만 리드 품질이 높은 소재일 가능성. 유지 검토 |
| CTR 높음 + 스크롤 낮음 | 광고와 랜딩페이지 첫 화면의 메시지 불일치 점검 |
| 스크롤 높음 + CTA 낮음 | 문제 공감 이후 해결 방식·오퍼의 매력도 점검 |
| CTA 높음 + 리드 제출 낮음 | 폼 부담, 신뢰 정보와 제공 조건 점검 |
| 전 지표 보통 | 예산 100%까지 유지한 뒤 소재 간 상대 비교 |
| CTR·후속 행동 모두 높음 | 실질 우세 후보로 유지하고 데모·파일럿 행동 신호 확인 |

### 5.2 예산 100% 소진 후 정량 결과 스펙트럼

> `낮음·보통·높음`은 예산 100% 소진 후 각 소재의 정량 결과를 분류하기 위한 잠정 스펙트럼임. 단일 지표만으로 문제 가설을 채택·기각하지 않으며, 지표 조합과 리드 품질을 함께 적용함.

| 지표 | 낮음 | 보통 | 높음 | 기준 및 근거 |
| --- | ---: | ---: | ---: | --- |
| **Meta Traffic CTR** | 0.8% 미만 | 0.8~1.4% | 1.4% 이상 | 공개 평균: Business Services 1.38%, Industrial & Commercial 1.36%, Animals & Pets 1.64%. [WordStream, Facebook Ads Benchmarks 2025](https://www.wordstream.com/blog/facebook-ads-benchmarks-2025) |
| **LinkedIn CTR** | 0.4% 미만 | 0.4~0.8% | 0.8% 이상 | 공개 평균: B2B SaaS 분기별 0.82~0.96%. 70곳 이상, 3년간 광고비 2,800만 달러 표본. [HockeyStack, 2025 LinkedIn Ads Benchmark Report](https://www.hockeystack.com/lab-blog-posts/linkedin-ads-benchmarks) |
| **페이지 조회 → 리드 제출률** | 2% 미만 | 2~5% | 5% 이상 | 공개 중앙값: SaaS 전체 3.8%, paid social 2.9%, Facebook 3.5%. [Unbounce, SaaS Conversion Rate Benchmark](https://unbounce.com/conversion-benchmark-report/saas-conversion-rate/) |

<small>※ 링크 클릭 대비 랜딩페이지 조회율은 기술 상태 확인용 진단 지표로만 사용하며, 비교 가능한 공개 근거가 없어 별도 성공 구간을 설정하지 않음.</small>

### 5.3 소재별 가설 우선순위 판정

> 우선순위 숫자는 후속 검증·자원 배분 순서를 의미함. 한 소재에 여러 판정이 동시에 적용되면 더 높은 순위인 작은 숫자를 우선 적용함.

| 우선순위 | 판정 | 결과 조합 | 후속 의사결정 |
| ---: | --- | --- | --- |
| **1** | **제품 가설 진전** | 데모 이후 최소 1개 조직에서 유료 파일럿·후속 미팅·예산 담당자 연결 의사 확인 | 광고 반응을 넘어선 행동 신호로 기록하고 구현 가능성·제공 경로·파일럿 조건 검토 |
| **2** | **소재 우세** | 동일 채널 내 CTR이 다른 소재보다 1.5배 이상 높고 CTA 클릭·리드 제출도 상대적 우위 | 해당 문제·해결 방식을 데모·인터뷰의 우선 검증 대상으로 선정. (1.5배는 통계적 유의성이 아닌 내부 비교 규칙) |
| **3** | **소수 ICP의 강한 신호** | CTR은 낮지만 제출된 리드의 적합성이나 후속 행동이 높음 | 대중적 소재로는 후순위화하되 해당 ICP를 대상으로 인터뷰·직접 접촉 검증 |
| **4** | **문제 반응 우세·해결 방식 미확인** | CTR은 높지만 CTA 클릭·리드 제출은 낮음 | 문제 가설은 유지하고 해결 방식, 랜딩페이지 설명과 오퍼를 수정해 재검증 |
| **5** | **판정 유보** | 노출·페이지 조회 표본이 작거나 전체 소재 반응이 낮아 차이를 해석하기 어려움 | 소재 간 우열을 정하지 않고 타깃·채널·메시지 조건을 보완한 추가 검증 여부 결정 |
| **6** | **후순위 가설** | 예산 100% 소진 후 CTR·CTA·리드 제출이 모두 다른 소재보다 낮음 | 세 가설 내 우선순위를 낮춤. 시장 니즈 부재로 기각하지 않고 이번 메시지·타깃 조건에서 반응 미확인으로 기록 |

### 5.4 Track 1 인터뷰 결과의 Track 2 소재 반영

초기 M1 실행 계획에서 Track 1은 인터뷰를 통한 문제 발견, Track 2는 선정한 문제·해결 방식에 대한 시장 반응 확인으로 구분함. 두 트랙은 병행 운영하되, Track 1 인터뷰에서 기존 A·B·C에 포함되지 않은 새로운 페인포인트나 관점이 확인되면 Track 2 광고 소재 후보로 추가 검토함.

| Track 1 인터뷰 발견 | Track 2 반영 방식 |
| --- | --- |
| A·B·C와 구분되는 새로운 페인포인트 확인 | 신규 소재 후보로 추가하고 문제제기형·해결책형 구성 검토 |
| 기존 페인포인트에 대한 새로운 표현·맥락 확인 | 해당 소재의 카피·타깃·랜딩페이지 설명 보완 |
| 특정 조직에만 해당하는 특수 문제 확인 | 범용 소재로 즉시 추가하지 않고 ICP·조직 유형별 가설로 별도 기록 |
| 반복성·긴급성·현재 대안이 구체적으로 확인되지 않은 단일 의견 | 추가 인터뷰 근거 확보 전까지 소재 후보로 보류 |

> 신규 소재 추가 시 기존 A·B·C와 동일한 예산·기간을 기계적으로 적용하지 않고, 남은 예산과 비교 가능성을 고려해 별도 테스트 여부 결정.

# SPCA of Luzerne County 인터뷰 인사이트

> **직원 30명이 동물별 최신 상태와 다음 행동을 모바일에서 함께 확인하는 기능에 적합성이 높다.** PetPoint를 유지하면서 단체 채팅과 Carol의 수동 전달을 줄이는 방향이다. 후속 검토 회의에 관심이 있으나 파일럿 참여와 유료 도입은 미확정이다.

## 3. 검증 대상

소재 A는 동물별 상태와 다음 업무를 보여줘 운영 누락을 줄이는 가설이다. 이 콜에서는 모든 직원이 현장에서 같은 최신 상태를 보는 요구가 확인됐다.

| 검증 대상 | 결과 |
| --- | --- |
| 동물 최신 상태가 직원 사이에 일관되게 공유되는가 | 직원 30명 전원이 단체 채팅에 포함되지 않고 PetPoint 사용도 일관되지 않아 필요한 사람이 정보를 놓친다고 설명 |
| 현황판이 기존 업무를 줄이는가 | Carol이 직원 정보를 찾아 자원봉사자용 Facebook 채팅으로 다시 전달하는 단계가 존재 |
| 설치형 앱이 필수인가 | 모바일에서 잘 작동한다면 웹도 괜찮다고 직접 답변 |
| 임보자 정기 체크인이 핵심 요구인가 | 임보 운영은 거의 다뤄지지 않았고 직원 간 정보 공유가 중심 |

> “a more daily briefing of what's going on with each animal”

Carol, 가장 고치고 싶은 문제를 설명한 발언(정리본 §11). 동물별 일일 최신 상황을 빠르게 확인하는 요구다.

> “work on mobile would be fine. Anything accessible on the mobile would be what we're looking for.”

Carol, 설치형 앱이 필요한지 확인하는 질문에 대한 답변(정리본 §8). 요구사항은 모바일 접근성이며 별도 앱 개발까지 의미하지 않는다.

## 5. 발언 뒤에 있는 것

- **통증 강도는 강함으로 판단한다.** [해석·L2] Carol은 정보 수집과 재전달을 직접 담당하며 누락을 설명했다. 메시지 발송 수보다 동물 상태를 확인하는 경로와 재전달 시간을 줄이는 것이 제품 가치에 가깝다.
- **PetPoint를 유지하는 모바일 업무 화면에 적합성이 높다.** [해석·L2] 공식 기록의 교체 요구는 없고 현장 접근성·공통 현황이 핵심이다. 연동 중요도를 파일럿의 절대 조건으로 해석할 직접 응답은 아직 없다.
- **시설 확장은 도구 검토의 계기다.** [해석·L2] 약 18개월 후 2개 시설 운영을 예상해 단체 채팅의 한계를 우려한다. 시설별 화면·위치·담당 팀 구분은 후속 검증할 제품 가설이다.
- **후속 검토 의향과 구매 의향은 다르다.** [해석·L2] 수의사·운영 책임자 동석은 긍정적이지만 가격과 결정권자 승인 없이 유료 전환을 예측할 근거는 부족하다.

## 6. 언급된 기능 요청

| 기능 요청 | 발언 맥락 |
| --- | --- |
| 동물별 일일 최신 상황 확인 | 하루에 각 동물에게 무슨 일이 생겼는지 더 잘 공유하고 싶다고 설명 |
| 모든 관련 직원의 정보 접근 | 일부 직원이 단체 채팅에서 빠져 필요한 정보를 보지 못하는 문제 설명 |
| 모바일에서 현황 확인 | 현장에서 접근할 수 있다면 모바일 웹이어도 괜찮다고 답변 |
| 상태 필터·주의 필요·다음 단계 | 데모에서 해당 기능을 긍정적으로 평가 |
| 커스텀 필드·워크플로우 | 데모 설명에 긍정적으로 반응 |
| 여러 입양 사이트 게시 | 긍정 반응은 있었으나 현재 게시 업무의 구체적 통증은 설명하지 않음 |

## 7. 남은 것

1. **수의사·Operations Manager가 참여하는 검토 회의.** PetPoint는 유지하고 Petify는 모바일 업무 현황을 제공한다는 범위를 먼저 확인한다. 후속 회의 일시는 미확정이다.
2. **PetPoint 연동과 현장 사용 확인.** 동물·상태·위치 불러오기, 현장 변경의 공식 기록 반영 범위와 허용 가능한 수작업 수준을 확인한다.
3. **Director의 구매 판단 조건 확인.** 예산, 승인 절차, 파일럿 이후 지속 사용 조건을 확인한다.

성과 지표 후보는 **동물 현재 상태 확인에 거치는 사람·채널 수, 누락된 전달 건수, Carol의 재전달 시간**이다. `PetPoint → 모바일 현황판 → 직원 업데이트 → PetPoint 반영`은 검증할 범위의 제안이며 합의된 파일럿은 아니다.

## 부록

# Humane Society of Washington County Maryland (HSWC) 사전조사

- 작성일: 2026-08-19 / 목적: Colin Berry ED 콜 준비 / 공개 자료만 사용, 외부 접촉 없음
- 리드 폼 정보: **미확인** — 소재 A/B 및 기재 도구 확인 필요 (Google Sheet 참조)

## 미팅에서 바로 쓸 핵심 5줄

1. **비영리이고 의사결정이 단순하다** — 카운티와 계약한 501(c)(3). ED 재량으로 $200K 이하 계약 가능 범위가 넓음. 공공기관 조달 없이 Berry가 결정 가능한 구조
2. **포스터가 핵심 자산이자 통증 후보** — 여름 피크에 300+마리가 가정에 분산. 자원봉사 관리엔 BetterImpact, 쉘터 관리 소프트웨어는 미확인. 이 규모의 포스터 로테이션이 어디서 새는지가 1순위 질문
3. **연매출 $3.89M, 재정은 안정적** — 프로그램 서비스(카운티 계약 포함) 64% + 기부 28%. 소프트웨어 구독료 규모의 지출은 ED 선에서 의사결정 가능
4. **Berry는 마케팅·기금조달 출신** — 운영 효율보다 입양률·포스터 배치 건수 같은 성과 지표 언어가 먹힐 가능성이 크다. HSUS 전국 단체 경험자라 업계 트렌드에 밝음
5. **쉘터 관리 소프트웨어 미확인이 최대 변수** — Chameleon·ShelterLuv 등 경쟁 도구 사용 여부를 콜 초반에 확인해야 데모 각도가 달라진다

- **포스터 300+명 분산 관리**: BetterImpact는 자원봉사 관리 도구. 포스터 가정의 동물 배치·상태 추적이 별도 수기 or 스프레드시트로 샐 개연성 큼 (**정황 추론, 직접 확인 필요**)

1. 현재 쉘터 관리 소프트웨어 무엇인지 (없다면 무엇으로 기록 관리하는지)

4. 이사회 지출 승인 기준선 (소프트웨어 구독 결정 라인)

## 2. 검증 방법

- 실제 Chrome 브라우저 자동 제어로 라이브 URL을 직접 조작. 네트워크 요청·콘솔·페이지 오류를 전 구간 수집
- 검증 경로: 랜딩 로드 → 순차 스크롤 → 본문·플로팅 CTA 클릭 → 리드 폼 제출 → `/book/` 이동 → 캘린더 로드 → 슬롯 선택 → 추가 문항 응답 → 예약 확정
- QA 식별: `utm_source=qa_final`, 조직명 `[QA] …`, 이메일 `@example.com`
- **주의**: headless 브라우저에서는 Meta Pixel 요청이 발생하지 않음. 픽셀 판정은 일반(headed) Chrome 실측으로 확정함

## 3. 조치 필요 사항

### 3-1. [결함] 소재 구분값이 단계별로 대소문자 분리됨

- 현상: 동일 소재인데 `landing_variant` 값이 1단계 `A`, 2단계 `a`로 서로 다른 값으로 수집됨
- 실측: Mixpanel 최근 1일 기준 `Landing Viewed` = `A` 93·`B` 61 / `Booking Page Viewed` = `a` 11·`b` 2 / `Booking Completed` = `a` 1·`b` 1
- 원인: 랜딩은 `<body data-landing-variant="A">`로 대문자 고정, `/book/`은 URL `?v=` 값을 소문자 변환해 스탬프
- 영향: 소재별 예약 전환율 산출 시 값 2개를 수동 병합해야 함. Meta 이벤트 매개변수도 동일하게 분리됨
- 조치안: `/book/`의 스탬프를 대문자로 통일(1줄 수정). 랜딩 쪽을 소문자로 바꾸면 기존 데이터와 단절되므로 비권장
- 유의: 이미 수집된 데이터는 어느 쪽으로 통일해도 과거분이 분리된 채 남음

### 3-2. [주의] 2단계 진입·예약의 간헐적 실패

- 현상: 소재 B 기준 4회 시도 중 3회 실패 후 4회차 완료. 실패 지점이 매회 다름

| 회차 | 실패 지점 | 비고 |
| --- | --- | --- |
| 1회 | 슬롯 경합 | 직전 예약이 동일 슬롯 선점. **오류 안내·캘린더 갱신은 정상 동작** |
| 2회 | 캘린더 열린 날짜 0개 (45초 대기) | 직후 API 직접 호출은 정상 응답 |
| 3회 | 리드 제출 후 `/book/` 이동 미발생 (45초 대기) | 1단계 리드는 시트에 정상 저장됨 |
| 4회 | 없음 (정상 완료) | 8/18 예약 확정 |

- 영향: 광고 유입 리드가 2단계로 넘어가지 못하면 **예약 전환이 유실**됨. 다만 1단계 리드는 시트에 남으므로 후속 수동 대응은 가능
- 참고: Apps Script 엔드포인트 응답이 2.4~2.8초로 느리며, Cal.com API 왕복이 겹치면 지연이 누적됨
- 유의: 재현 조건 미확정. QA와 동시간대에 동일 폼·캘린더에 다른 제출이 진행되어 동시 접근이 겹쳤을 가능성 있음. **광고 집행 초기 실사용 리드에서 1단계 저장 대비 2단계 도달률을 관찰할 필요**

### 3-3. [경미] `/book/` 진입 시 Meta `PageView` 1건 중복

- 리드 제출 후 페이지 전환 구간에서 소재·경로 매개변수가 없는 `PageView` 1건이 추가 발생
- 영향: 소재 매개변수가 붙은 정상 `PageView`는 별도 발생하므로 분석 왜곡은 제한적

## 4. 정상 확인 상세

- **Mixpanel 섹션 이벤트**: `Landing 01 Hero`·`02 Problem`·`03 How It Works`·`04 Outcomes`·`05 Evidence`·`06 Lead Form` 6종 전부 순서대로 발생. `How It Works Step Viewed` 3단계 발생
- **플로팅 CTA**: 상단에서는 `pointer-events: none`으로 비활성, 스크롤 후 활성화되어 클릭 정상 동작
- **소재별 문항 분기**: 소재 A는 연간 처리 두수, 소재 B는 활성 임보자 수 문항이 표시됨을 확인
- **필수 문항 검증**: 조직 유형·직무 미입력 시 제출 차단
- **콘솔 오류·페이지 오류**: 전 시나리오 0건
- **시간대 처리**: 브라우저가 비미국 시간대일 때 `America/New_York` 기본 적용 확인

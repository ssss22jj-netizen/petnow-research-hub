# 펫나우 LinkedIn 독립검증 환경 v4

> 결론: v3의 Chrome 직접검증 절차를 유지하고, 고용형태·지역 표준화와 검색 로그·외부 검증 완결성을 QA에서 강제하는 재현 절차임.

## 1. 독립 실행 조건

- 과거 대화·기존 후보·기준 시트·비교 보고서 미열람
- 기존 사용자 Chrome extension 및 LinkedIn 로그인 세션 사용
- `extensionInstanceId`로 Chrome 인스턴스 식별. 세션별 browser id 고정 사용 금지
- `openTabs()`·방문 기록 미사용, 새 LinkedIn 탭으로 시작
- 로그인 피드와 개인 프로필 경력 접근 통과 후 조사 시작

## 2. 후보별 LinkedIn 직접검증

각 후보의 개인 프로필을 직접 열어 다음 상태를 기록함.

| 영역 | 허용 상태 |
| --- | --- |
| 상단 | 확인 / 미확인 |
| 소개 | 확인 / 섹션 없음 확인 / 미확인 |
| 경력 모두 표시 | 확인 / 미확인 |
| 봉사 경력 | 확인 / 섹션 없음 확인 / 미확인 |
| 추천사 | 확인 / 섹션 없음 확인 / 미확인 |
| 최근 활동 | 확인 / 활동 없음 확인 / 미확인 |

검색 결과 스니펫만으로 직접검증 완료를 부여하지 않음.

## 3. 고용형태 표준 코드

| 코드 | 의미 | 합격 근거 |
| --- | --- | --- |
| `FT-LI` | LinkedIn 풀타임 직접 확인 | 경력의 Full-time·정규직 표시 |
| `FT-OFFICIAL` | 공식 원문 풀타임 직접 확인 | 조직 원문의 full-time employee 등 |
| `PAID-HOURS-UNK` | 유급 직원·시간 미확인 | Form 990 보수 또는 공식 유급 근거 |
| `PT` | 시간제 직접 확인 | LinkedIn·공식 원문의 Part-time |
| `VOL` | 봉사자 직접 확인 | 봉사 경력 또는 공식 volunteer |
| `UNK` | 고용형태 미확인 | 직함만 확인, 직접 표기 없음 |

표시용 판정과 표준 코드를 분리함. `FT-LI`와 `FT-OFFICIAL`은 모두 풀타임으로 비교하되 근거 출처는 구분함. 직함으로 `FT-*`를 추정하지 않음.

## 4. 지역 표준화

- `주·도`: 미국 주의 정식 영문명만 입력
- `도시`: 도시명만 입력
- `도시권`: 광역권 또는 복수 근무지
- Brooklyn, Manhattan 등 도시·자치구를 `주·도`에 입력하지 않음
- 주·도와 도시가 바뀐 경우 QA 오류 처리

## 5. 탐색·외부 검증 완결성

- Tier A 20개 조직마다 Q001~Q005를 각각 별도 실행: 100개 로그 필수
- 후보별 LinkedIn 프로필 직접검증 로그 필수
- 고객 공유 후보별 Q007 이름+조직 외부 검색 로그 필수
- 고용형태가 `UNK`이면 Q008 및 공식 팀·Form 990 검색 로그 필수
- 외부 원문을 직접 열고 후보 이름이 본문에 있는 경우만 URL 채택
- 외부 원문 이름 근거가 없으면 `검색 완료·근거 없음`으로 기록

외부 근거 확보율은 조직의 공개 페이지 존재 여부에 좌우되므로 합격률로 강제하지 않음. 대신 외부 검색 수행률 100%와 채택 URL의 이름 확인률 100%를 강제함.

## 6. 1순위 기준

아래 조건을 모두 충족해야 1순위로 판정함.

- 개인 LinkedIn URL 및 미국 현직 확인
- 고용형태 코드 `FT-LI` 또는 `FT-OFFICIAL`
- 운영, 구매·예산, 입양·임보·수송 운영 책임 중 하나 직접 확인
- LinkedIn 경력 모두 표시 확인
- 최근 활동 확인 또는 공식 외부 개인 근거 확보

고용형태 `UNK`, `PT`, `VOL`은 1순위 부여 금지.

## 7. QA 합격 기준

| 항목 | 합격 기준 |
| --- | ---: |
| Tier A Q001~Q005 로그 | 100/100 |
| LinkedIn 프로필 직접검증 | 고객 공유 후보 100% |
| 외부 검색 수행 | 고객 공유 후보 100% |
| 채택 외부 URL 이름 확인 | 100% |
| 고용형태 코드 유효성 | 100% |
| 주·도 표준값 | 100% |
| QA | ERROR 0, 필수 WARN 0 |

## 8. 재현성 평가

독립 결과 확정 후 평가 세션에서만 기준 목록을 열어 비교함.

- 후보 겹침률: 참고 지표
- 공통 후보 고용형태 의미 일치율: 90% 이상
- 공통 후보 주(state) 일치율: 95% 이상
- 1순위 출처 재감사 정밀도: 90% 이상
- 불일치 항목은 기준 시트를 정답으로 가정하지 않고 LinkedIn·공식 원문으로 재감사

기준 시트 오류와 독립 실행 오류를 구분하여 기록함.

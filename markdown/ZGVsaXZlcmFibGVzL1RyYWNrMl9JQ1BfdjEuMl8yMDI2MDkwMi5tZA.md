# Track 2 ICP v1.2 — 리소스 배분 기준 개정

> 개정일 2026년 9월 2일 · 이전 판 [ICP v1.1](Track2_ICP_Persona_소재_정의_근거_20260805.md) (2026-08-05 제정, 2026-08-15 「도구 현황」 조건 제외)
>
> 적용 대상: 리드 판정 보드 · Demo f/u 현황판의 「ICP 리소스 등급」 열

## 한 줄 결론

판정 목적을 **광고 표적 정의에서 유료 파일럿 전환 리소스 배분으로 교체**하고, 가정에 근거한 배제 규칙 2종(규모 상한·공공 일괄 후순위)을 리드 43건 실측으로 폐기한다.

## 1. 개정 사유

### 1.1 목적 불일치

- v1.1은 **M1 광고 실험의 표적을 정의**하기 위해 제정됨. 2순위의 뜻도 「배제」가 아니라 「공통 가설을 오염시키므로 실험에서 분리」였음
- M1 종료 후 M2의 KPI는 **유료 파일럿 전환 여부**로 이동. 판정이 답해야 할 질문이 「광고를 누구에게 보낼 것인가」에서 **「리소스를 어디에 쓸 것인가」**로 바뀜
- 목적이 바뀐 기준을 그대로 두면 판정과 실행이 어긋남. 실제로 아래 1.2의 역상관이 발생

### 1.2 판정이 KPI와 역상관

| 항목 | 실측 |
| --- | --- |
| 데모 성사 12건 중 v1.1 「2순위」 | **8건 (67%)** |
| 그중 PoC 가능성 `높음` 판정 | 산타바바라 · LTBHS · CAP · Beatrice · PawSafe |

- 콜이 성사되고 PoC 신호가 확인된 리드의 3분의 2를 v1.1이 후순위로 분류
- 산타바바라 카운티가 대표 사례. **실질 최우선 대상이나 v1.1에서는 공공·대형 두 사유로 2순위**

### 1.3 배제 규칙의 전제가 실측과 불일치

**① 규모 상한 — 대형일수록 조달이 덜 막힌다**

| 실측 규모 | 건수 | 결정·조달 `낮음` |
| --- | ---: | --- |
| 높음 | 15 | **2건 (13%)** |
| 보통 | 8 | 2건 (25%) |
| 낮음 | 20 | **13건 (65%)** |

- v1.1의 전제는 「연간 300건 초과 대형은 IT 검토·위원회 승인으로 도입이 지연될 수 있음」
- 실측은 반대. 조달이 막히는 쪽은 소형이며 사유도 절차가 아니라 **현금 부재**(990-N 구간·정기 후원 채널 부재·무료 대체재 기준선)

**② 공공 일괄 후순위 — 공공 내 편차가 유형 간 차이보다 크다**

| # | 조직 | 결정·조달 | 판단 근거 |
| ---: | --- | --- | --- |
| 6 | 산타바바라 카운티 | **높음** | $200,000 이하 서비스 계약 Purchasing Manager 전결 |
| 42 | St. Charles County PAC | 보통 | 연 $15,000 미만·12개월 조건 시 IT 조달 예외 |
| 15 | Thomas J O'Connor | 낮음 | 시 조달 라인, 금액에 따라 시의회 의결 |
| 27 | Burlington County | 낮음 | NJ Local Public Contracts Law 적용 |

- 「공공 = 후순위」로 뭉뚱그리면 산타바바라를 잃음. 판정축은 조직 유형이 아니라 **전결 한도가 자사 가격대를 덮는가**여야 함

**③ 통증 축은 변별력 부재**

- 43건 중 통증 가설 `높음` 39건(91%), `낮음` 0건. 통증만으로는 우선순위 분리 불가
- 실제 분리 요인은 **지불 경로의 존재 여부**

## 2. v1.2 판정 기준

### 2.1 등급 정의

| 등급 | 뜻 | 조건 |
| --- | --- | --- |
| **집중** | 지금 리소스를 쓴다 | 통증 가설 · 결정·조달 · 실측 규모가 **모두 `높음`** |
| **수용** | 들어오면 받되 먼저 찾아가지 않는다 | 집중 조건 미달 |
| **제외** | 제품 대상이 아니다 | 입양 회전 조직이 아니거나 시설 밖 분산 케어가 없음 |
| 미조사(소식만) | 사전조사 대상 아님 | `Keep me posted` 신청 |

- **등급은 판정 4축의 합성값이다.** 4축이 근거, 등급이 결론이며 4축이 갱신되면 등급도 다시 계산한다
- 제외는 유형 관문이므로 4축보다 먼저 적용한다

**집중 조건에서 `보통`을 제외한다** (카야 판정, 2026-09-04)

- 사유 — `보통`이 **「중간 수준」과 「미확인」 두 가지 뜻으로 쓰이고 있다.** 조사가 덜 된 리드가 중간값으로 채워져 자동으로 집중에 올라갔다
- 발단 사례 — Muscatine Humane Society(#25). 실측 규모 `보통`의 근거가 자기보고 두 값(자체 소개 연 2,000마리 / 폼 응답 Over 300)의 자릿수 불일치였고 **교차 검증이 불가능한 상태**였다. 결정·조달 `보통`도 「단일 Director 체제」와 「이사회의 2025-05 시 계약 부결」이 상충하는 상태였다
- 개정 전 기준에서는 집중 18건 중 6건이 `보통` 축의 근거에 미확인·불일치 표기를 달고 있었다
- 결과 — 집중은 **결정·조달 `높음`이 확인된 조직**, 실질적으로 **전결 한도를 실제로 확인한 곳**만 해당한다

**제외는 최소화한다** (카야 판정, 2026-09-02)

- 제외 사유는 **제품 대상 자체가 아닌 경우**로 한정한다. 유형 관문 1종이며 현재 해당은 1건
- **지불 경로 부재는 제외 사유가 아니다.** 990-N 구간·현금 병목·무료 대체재 기준선은 전부 `수용` 안에서 다루고 무료 구간 접점을 유지한다
- 근거 — 유료 파일럿 전환 이전 국면에서는 접점을 끊는 비용이 유지 비용보다 크다. 지불 능력은 콜 한 번으로 뒤집히기도 하므로(전결 한도 확인·그랜트 경로·연간 예산 편성) 조사 시점의 재무 상태로 접점을 종료하지 않는다
- 반대급부 — 실질 배제가 1건뿐이므로 **리소스 절약 효과는 `집중`과 `수용`의 취급 강도 차이에서만 나온다.** 아래 2.2 를 규칙대로 지키는 것이 전제

### 2.2 등급별 행동

| 등급 | 행동 |
| --- | --- |
| 집중 | 데모·후속 세션 우선 배정, 사전조사 갱신, PoC 조건 구체화 |
| 수용 | 유입 시 데모는 제공하되 아웃바운드·후속 리소스는 배정하지 않음. 무료 구간 접점 유지 |
| 제외 | 접점 종료. 단 제외 사유를 사전조사 문서에 남긴다 |

### 2.3 v1.1에서 유지하는 것

- 미국 국내 운영 · 국제 이송 없음 (크로스보더는 공통 가설을 오염시킴)
- 「도구 현황」 조건 제외 (2026-08-15 개정분)
- 퍼소나 정의(Diane · Alex) 및 소재 A·B 선정 근거

## 3. v1.1 대비 변경 대조

| 항목 | v1.1 | v1.2 |

| 운영 규모 | 연 입양 50~300건이 1순위, 300건 초과는 2순위 | **상한 폐기.** 규모는 결정·조달과 함께 보되 단독 배제 사유 아님 |

> 집중 3건은 전부 전결 한도 또는 예산 권한이 실측으로 확인된 조직이다. 산타바바라는 $200,000 이하 서비스 계약 Purchasing Manager 전결, LTBHS 는 FY2024 흑자 $1.64M·총자산 $10.2M, HSWC 는 독립 501(c)(3) 로 카운티 조달 비해당이다.

**정합성 검증** — 데모 성사 12건 기준

- PoC 가능성 `높음` 6건 중 집중은 2건(산타바바라·LTBHS). 나머지 4건(CAP · Beatrice · Cactus Ranch · PawSafe)은 수용
- 수용으로 남은 4건은 **전부 결정·조달이 `보통` 이하이며 사유가 전결 한도 미확인**이다. 즉 PoC 관심은 확인됐으나 지불 경로가 확인되지 않은 구간이다
- 규칙은 이 둘을 분리한다. **PoC 관심은 승격 사유가 아니며, 전결 한도를 확인하면 승격한다**

## 5. 판정·갱신 절차

1. 사전조사(`tools/leads/deep.py`) 완료 후 4축을 매긴다
2. 4축에서 등급을 합성한다. 유형 관문 해당 시 4축보다 우선한다
3. **콜 종료 시 4축을 콜 결과로 갱신하고 등급을 재계산한다**
4. 정본은 `analysis/raw/leads.json` 의 `verdict`. 보드·시트는 그 렌더 결과다

> **본 개정 시 적용한 콜 결과 반영 2건**
> - #23 LifeLine — 통증 가설 `보통` → `높음` (4개 시스템 분산·부분 응답·미응답 공식 절차 확인). 등급이 수용 → **집중**으로 변경
> - #28 Maybel's Legacy — 결정·조달 `보통` → `낮음` (월 $99 지속 불가 명시, 실질 비교 기준 $0). 등급은 수용 유지

## 6. 미검증 및 후속

- **전결 한도 확인이 승격의 유일한 경로** — 2026-09-04 개정으로 집중 조건이 결정·조달 `높음`을 요구하므로, 전결 한도를 묻지 않으면 어떤 리드도 집중으로 올라오지 않는다. **콜 질문 항목에 고정 편성한다.** 현재 확인된 곳은 산타바바라($200K 전결)·St. Charles($15K/IT 예외) 2곳뿐이며, PoC 신호가 강한 CAP·Beatrice·PawSafe 는 미확인 상태다
- **소형 구간의 유료 전환 가능성** — Maybel's가 월 $99를 명시 거부했고 비교 기준이 $0. 소형 대상 가격 구간을 별도로 둘지는 미결
- **`수용` 24건의 실제 취급 강도** — 제외를 최소화한 설계이므로 리소스 절약이 전적으로 여기에 달려 있다. 「먼저 찾아가지 않는다」가 실제로 지켜지는지, 파일럿이 가동되면 소요 시간으로 확인한다
- **`수용` 재승격 조건의 분해** — 조달 `낮음`의 사유가 현금 부재인지 절차인지에 따라 경로가 다르다. 현금 부재는 무료 구간, 절차는 경로 탐색으로 갈린다

# 펫나우 LinkedIn 저부하 독립검증 환경 v5

> 결론: LinkedIn 로그인 프로필 직접검증은 유지하되, Google 반복 검색을 제거하고 LinkedIn 조직 검색과 공식 원문 검색을 분리하여 접속 제한 위험과 공수를 낮춘 절차임.

## 1. 독립성과 브라우저

- 과거 후보·기준 시트·이전 실행 결과 미열람
- 기존 사용자 Chrome extension의 LinkedIn 로그인 세션 사용
- Chrome은 `extensionInstanceId`로 선택
- 열린 탭·방문 기록 미조회, 새 탭으로 시작
- Google 검색 화면 자동 반복 금지

## 2. 저부하 후보 발견

Tier A 20개 조직을 순서대로 조사함.

1. LinkedIn 검색창에서 조직명 검색
2. 조직 페이지 또는 사람 검색에서 현재 소속 인물 확인
3. 역할 키워드는 한 검색문에 결합: operations, program, adoption, foster, intake, transport, finance, executive
4. 조직당 결과 화면 최대 2개, 후보 최대 3명
5. 이름·개인 URL·현재 직함이 보이는 후보만 발견 풀에 기록
6. 결과가 없으면 검색어를 반복 변형하지 않고 `미발견` 기록 후 다음 조직으로 이동

조직당 Q001~Q005 5개 Google 검색을 수행하지 않음. 대신 `LI-ORG` 1회와 필요 시 `LI-ROLE` 1회만 기록함.

## 3. 프로필 직접검증

각 최종 후보는 LinkedIn 개인 프로필과 경력 전체 보기를 직접 열어 다음을 확인함.

- 이름·헤드라인·현재 조직·지역
- 소개: 확인 / 섹션 없음 확인 / 미확인
- 경력 모두 표시: 현재 직책·기간·고용형태
- 봉사 경력: 확인 / 섹션 없음 확인 / 미확인
- 추천사: 확인 / 섹션 없음 확인 / 미확인
- 최근 활동: 확인 / 활동 없음 확인 / 미확인

경력 전체 보기 미확인 후보는 고객 공유 목록에 포함하지 않음.

## 4. 외부 원문 검증

- 후보별 검색은 검색 도구를 1회 사용하여 이름+조직으로 수행
- 우선 출처: 공식 팀 페이지, 보도자료, Form 990, 공공기관 페이지, 공식 행사·모금 페이지
- 검색 결과 페이지가 아니라 원문 URL을 직접 열어 후보 이름 확인
- 이름이 원문에 있으면 URL 채택
- 없으면 `검색 완료·근거 없음` 기록
- Google 검색 화면과 CAPTCHA 페이지 사용 금지

## 5. 표준화

고용형태 코드:

- `FT-LI`: LinkedIn Full-time·정규직
- `FT-OFFICIAL`: 공식 원문 full-time
- `PAID-HOURS-UNK`: 유급·시간 미확인
- `PT`: 시간제
- `VOL`: 봉사
- `UNK`: 미확인

지역:

- `주·도`: 미국 주 정식 영문명
- `도시`: 도시·자치구
- `도시권`: 광역권

## 6. 1순위

아래 조건을 모두 충족해야 1순위임.

- 미국 현직·개인 LinkedIn URL
- `FT-LI` 또는 `FT-OFFICIAL`
- 운영·구매·예산·입양·임보·수송 운영 책임
- 경력 전체 보기 확인
- 최근 활동 확인 또는 공식 외부 개인 근거

## 7. 계정 보호 중단 조건

- CAPTCHA, 비정상 트래픽, 보안 확인, 일시 제한 발생 시 즉시 중단
- CAPTCHA 풀이·우회·쿠키 추출·비공개 API 사용 금지
- 메시지·친구 추가·팔로우·좋아요 금지
- 동일 검색 반복 금지

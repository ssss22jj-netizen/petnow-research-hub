## 외부 근거 한계

- 공식 외부 근거로 채택한 URL은 Emily Trost Mazzone의 Muddy Paws Rescue 모금 페이지와 Luanne Czesak의 The Sato Project 공식 팀 페이지 2건
- 외부 페이지 본문에서 후보 이름을 직접 확인한 근거만 채택
- 검색 결과 스니펫과 이름이 본문에 나타나지 않는 외부 페이지는 근거로 채택하지 않음
- 나머지 18명은 외부 검색을 완료했으나 이름이 본문에 보이는 채택 가능 원문을 확보하지 못해 `외부 이름 근거 없음(검색 완료)`으로 표시
- Luanne Czesak은 공식 팀 페이지에서 이름·직함·`full-time employee` 문구를 직접 확인해 풀타임 판정과 1순위에 반영

## 미확인과 섹션 없음 처리

- 페이지에서 영역 부재를 확인한 경우 `섹션 없음 확인` 기록
- 해당 영역에 접근하거나 부재를 확정하지 못한 경우 `미확인` 기록
- 직함만으로 풀타임을 추정하지 않고 고용형태 미표시 후보는 2순위 처리

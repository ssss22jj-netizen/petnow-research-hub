## 2. 캠페인 운영 목표 재검증, 구체화 (인터뷰 or 데모?)

8월 5일 미팅에서 논의한 랜딩 이후의 액션 구조를 한번 더 검토함.
인터뷰와 데모의 목적 차이
- 인터뷰: 고객 문제와 요건을 **새로 발견**하기 위한 방식
- 데모: 우리가 설정한 문제와 해결 방식에 대한 **시장 반응**을 확인

근데 이 두 목적은 이미 최초 방향성 설정 시 나누어 놓음 :
- [Track1] 네트워킹 인터뷰: 실제 업무 흐름과 사용 툴에 대한 심층 관찰(**문제 발견**)
- [Track2] 리드 기반 디스커버리: 어떤 문제 메시지에 반응하는지에 대한 정량 신호(**시장 반응**)

LMF 캠페인(이라기 보단 PMF, 이후부턴 PMF로 표현)에서는 어떤 문제에 가장 반응하는지에 초점(데모 시연)을 맞추고, 인터뷰 리드 확보는 별도로 진행하는 것이 적합하다고 재차 결론. (사실상 Track1의 보조)

트랙별 메시지·CTA·콜 형식을 구체화함.
현재 카야 작업 우선순위는 LMF, 커스텀 CRM트랙은 후순위

| 트랙 | 광고·랜딩페이지 | 리드 이후 |
| --- | --- | --- |
| PMF 캠페인 | A·B·C 문제 소구점 → 데모 예약 | 인터뷰어가 클릭형 프리토타입을 시연하는 데모·피드백 세션 |
| 커스텀 CRM 트랙 | 조직별 맞춤 CRM → 요건 설문 | 완성 제품 데모 없이 문제·요건을 확인하는 디스커버리 콜 |

## 3. PMF 캠페인 설계 방향

| 검토 항목 | 카야 후속 작업 방향 |
| --- | --- |
| 검증 대상 | 현재 구현 여부가 아니라 문제 반응, 해결 방식 반응, 데모 예약, 조건부 가격 인식 |
| 소재 구성 | A·B·C별 문제제기형과 해결책형을 함께 구성 |

| CTA 방향 | 즉시 제품 제공을 전제하는 무료 체험·즉시 사용 대신 **데모·얼리 액세스·피드백 세션**으로 전환 |

| 인터뷰 | 기능 필요성, 현재 업무, 가격 인식, 파일럿 조건 확인 |
| 세션 종료 | 프리토타입과 실제 제공 범위를 알리고 후속 검토 조건 재확인하는 디브리핑 검토 |

## 5. 시장 반응 우선 검증과 표현 원칙

이번 실험의 1차 목적: 선정한 세 가지 문제·해결 방식 중 시장에서 가장 강한 반응을 얻는 소재를 확인

| 구분 | 적용 원칙 |
| --- | --- |
| 사전 소재 선정 | A·B·C 세 가지 소재를 동일한 시장 반응 검증 대상으로 운영. 프리토타입으로 표현 가능한 해결 방식은 현재 구현 여부와 무관하게 검증 가능 |
| 반응율 판단 | 광고 클릭률로 문제·메시지 반응을 비교하고, 랜딩페이지 행동과 리드 제출로 해결 방식에 대한 추가 관심을 확인 |
| 실제 관심도 판단 | 프리토타입을 통해 해결책의 가치 인식, 제품 관심도(구매 논의 의향) 확인 |
| 후속 검토 | 강한 반응이 확인된 소재 발생 시 기술 구현 가능성, 운영 방식, 기존 CRM과의 관계, 제공 경로와 사업성 검토 |
| 해석 한계 | 광고 클릭은 제품 구매 의향이 아니라 문제·메시지에 대한 관심 신호임. 실제 수요는 데모 이후 후속 미팅, 조건부 가격 반응과 파일럿 의향을 함께 확인해 판정 |

### 광고·데모 표현 기준

- 프리토타입으로 시연 가능한 해결 방식은 광고 소재로 검토 가능
- 무료 체험, 즉시 사용, 연동 완료 등 현재 제공 가능한 제품으로 오인할 수 있는 표현 제외
- 고객의 실제 CRM과 나란히 보여주는 등 해당 데모에서 이행할 수 없는 CTA 제외

## 6. 광고 운영 및 최종 판정 기준

### 6.1 예산 소진 시점별 운영 판단

| 시점 | 확인 항목 | 조치 |
| --- | --- | --- |
| **예산 10% 소진**<br>소재당 1.5만 원 | 광고 링크, 모바일 로딩, 분석 이벤트, CTA와 리드 폼의 정상 작동 여부, 광고 클릭 발생 여부 및 랜딩페이지 스크롤 깊이 | 기술적 오류 우선 수정. 측정이 정상인데 클릭이 0회이거나 스크롤 깊이가 현저히 낮은 경우 소재 교체 검토 |
| **예산 50% 소진**<br>소재당 7.5만 원 | 동일 채널 내 소재별 CTR 추이, 페이지 조회 이후 스크롤·CTA·리드 제출 발생 여부 | 외부 기준점과 소재 간 차이를 함께 확인. 표본이 작으면 중단하지 않고 잠정 우세·열세만 기록 |
| **예산 100% 소진**<br>소재당 15만 원 | CTR, 랜딩페이지 전환, 리드 적합성, 데모 참석과 후속 행동 종합 | 문제·메시지 반응, 해결 방식 관심, 제품 가설 진전을 분리해 최종 기록 |

<small>※ CPM 참고: 2026년 1분기 미국 Meta 광고 평균 CPM은 Traffic·Engagement 캠페인 $10~15, 웹사이트 Lead Generation 캠페인 $26~40 수준임. 좁은 타깃의 리드 캠페인은 $40~55까지 상승 가능. 출처: [Affect Group, US Meta Ads CPM Insights Q1 2026](https://affectgroup.com/blog/meta-ads-cpm-in-the-united-states-benchmarks-for-facebook-and-instagram/)</small>

#### 지표 조합에 따른 중간 대응

| 결과 조합 | 판단 및 조치 |
| --- | --- |
| CTR 낮음 + 이후 행동도 낮음 | 광고 소재 교체 또는 중단 후보 |
| CTR 낮음 + 리드 전환 높음 | 대중적 반응은 약하지만 리드 품질이 높은 소재일 가능성. 유지 검토 |
| CTR 높음 + 스크롤 낮음 | 광고와 랜딩페이지 첫 화면의 메시지 불일치 점검 |
| 스크롤 높음 + CTA 낮음 | 문제 공감 이후 해결 방식·오퍼의 매력도 점검 |
| CTA 높음 + 리드 제출 낮음 | 폼 부담, 신뢰 정보와 제공 조건 점검 |
| 전 지표 보통 | 예산 100%까지 유지한 뒤 소재 간 상대 비교 |
| CTR·후속 행동 모두 높음 | 실질 우세 후보로 유지하고 데모·파일럿 행동 신호 확인 |

### 6.2 예산 100% 소진 후 정량 결과 스펙트럼

> `낮음·보통·높음`은 예산 100% 소진 후 각 소재의 정량 결과를 분류하기 위한 잠정 스펙트럼임. 단일 지표만으로 문제 가설을 채택·기각하지 않으며, 지표 조합과 리드 품질을 함께 적용함.

| 지표 | 낮음 | 보통 | 높음 | 기준 및 근거 |
| --- | ---: | ---: | ---: | --- |
| **Meta Traffic CTR** | 0.8% 미만 | 0.8~1.4% | 1.4% 이상 | 공개 평균: Business Services 1.38%, Industrial & Commercial 1.36%, Animals & Pets 1.64%. [WordStream, Facebook Ads Benchmarks 2025](https://www.wordstream.com/blog/facebook-ads-benchmarks-2025) |
| **LinkedIn CTR** | 0.4% 미만 | 0.4~0.8% | 0.8% 이상 | 공개 평균: B2B SaaS 분기별 0.82~0.96%. 70곳 이상, 3년간 광고비 2,800만 달러 표본. [HockeyStack, 2025 LinkedIn Ads Benchmark Report](https://www.hockeystack.com/lab-blog-posts/linkedin-ads-benchmarks) |
| **페이지 조회 → 리드 제출률** | 2% 미만 | 2~5% | 5% 이상 | 공개 중앙값: SaaS 전체 3.8%, paid social 2.9%, Facebook 3.5%. [Unbounce, SaaS Conversion Rate Benchmark](https://unbounce.com/conversion-benchmark-report/saas-conversion-rate/) |

<small>※ 링크 클릭 대비 랜딩페이지 조회율은 기술 상태 확인용 진단 지표로만 사용하며, 비교 가능한 공개 근거가 없어 별도 성공 구간을 설정하지 않음.</small>

### 6.3 소재별 가설 우선순위 판정

| 판정 | 결과 조합 | 후속 의사결정 |
| --- | --- | --- |
| **1순위 가설** | 동일 채널 내 CTR이 다른 소재보다 1.5배 이상 높고 CTA 클릭·리드 제출도 상대적 우위 | 해당 문제·해결 방식을 데모·인터뷰의 우선 검증 대상으로 선정. (1.5배는 통계적 유의성이 아닌 내부 비교 규칙) |
| **문제 반응 우세·해결 방식 미확인** | CTR은 높지만 CTA 클릭·리드 제출은 낮음 | 문제 가설은 유지하고 해결 방식, 랜딩페이지 설명과 오퍼를 수정해 재검증 |
| **소수 ICP의 강한 신호** | CTR은 낮지만 제출된 리드의 적합성이나 후속 행동이 높음 | 대중적 소재로는 후순위화하되 해당 ICP를 대상으로 인터뷰·직접 접촉 검증 |
| **후순위 가설** | 예산 100% 소진 후 CTR·CTA·리드 제출이 모두 다른 소재보다 낮음 | 세 가설 내 우선순위를 낮춤. 시장 니즈 부재로 기각하지 않고 이번 메시지·타깃 조건에서 반응 미확인으로 기록 |
| **판정 유보** | 노출·페이지 조회 표본이 작거나 전체 소재 반응이 낮아 차이를 해석하기 어려움 | 소재 간 우열을 정하지 않고 타깃·채널·메시지 조건을 보완한 추가 검증 여부 결정 |
| **제품 가설 진전** | 데모 이후 최소 1개 조직에서 유료 파일럿·후속 미팅·예산 담당자 연결 의사 확인 | 광고 반응을 넘어선 행동 신호로 기록하고 구현 가능성·제공 경로·파일럿 조건 검토 |

### 6.4 Track 1 인터뷰 결과의 Track 2 소재 반영

초기 M1 실행 계획에서 Track 1은 인터뷰를 통한 문제 발견, Track 2는 선정한 문제·해결 방식에 대한 시장 반응 확인으로 구분함. 두 트랙은 병행 운영하되, Track 1 인터뷰에서 기존 A·B·C에 포함되지 않은 새로운 페인포인트나 관점이 확인되면 Track 2 광고 소재 후보로 추가 검토함.

| Track 1 인터뷰 발견 | Track 2 반영 방식 |
| --- | --- |
| A·B·C와 구분되는 새로운 페인포인트 확인 | 신규 소재 후보로 추가하고 문제제기형·해결책형 구성 검토 |
| 기존 페인포인트에 대한 새로운 표현·맥락 확인 | 해당 소재의 카피·타깃·랜딩페이지 설명 보완 |
| 특정 조직에만 해당하는 특수 문제 확인 | 범용 소재로 즉시 추가하지 않고 ICP·조직 유형별 가설로 별도 기록 |
| 반복성·긴급성·현재 대안이 구체적으로 확인되지 않은 단일 의견 | 추가 인터뷰 근거 확보 전까지 소재 후보로 보류 |

> 신규 소재 추가 시 기존 A·B·C와 동일한 예산·기간을 기계적으로 적용하지 않고, 남은 예산과 비교 가능성을 고려해 별도 테스트 여부 결정.

# 3. Track 2 광고·랜딩 준비안

> 미팅 배정: 20분  
> 목적: 판매가 아니라 인터뷰 참여자 확보와 문제 가설 비교  
> 근거: 기존 시장·경쟁사 리서치, Gina 인터뷰, Track 2 사전 정리  
> 제외: 합성소비자 인터뷰는 아직 진행하지 않았으므로 결과에 반영하지 않음

## 제안 결론

첫 캠페인은 완성된 Shelter CRM을 판매하는 광고가 아니라, `임보 기록 누락`, `최신 상태 파악`, `입력 부담` 중 어떤 문제가 인터뷰 참여자 모집에 효과적인지 비교하는 실험으로 설계한다. Meta 광고를 주 채널로 사용하고, LinkedIn은 구매 책임자 반응을 소규모로 검증하는 보조 채널로 운영한다.

## 1. 초기 세그먼트

### 1순위: 임보 기반 민간 레스큐의 운영 실무자

- 역할: Foster Coordinator, Volunteer Coordinator, Operations Manager, Rescue Manager
- 조직: 시설 없이 임보 네트워크로 운영하거나 임보 비중이 높은 민간 레스큐
- 가설 규모: 연간 입양 50~300건, 상근 1~5명, 임보자 20~80명
- 현재 도구: 저가 CRM 또는 스프레드시트와 문자·메신저 병행
- 인터뷰 가치: 임보자에게 정보를 요청하고 다시 시스템에 옮기는 반복 업무 확인

### 2순위: 소규모 조직의 대표·운영 총괄

- 역할: Founder, Executive Director, Director of Operations
- 조건: 예산 결정과 일상 운영을 겸하는 조직
- 인터뷰 가치: 문제의 비용, 도입 계기, 승인 조건 확인

### 비교군: 크로스보더 레스큐

- 역할: 국가 간 구조, 수송, 입양 운영 담당자
- 인터뷰 가치: Gina 사례가 다른 국제 레스큐에서도 반복되는지 확인
- 주의: 크로스보더 특수 문제를 미국 로컬 레스큐의 공통 문제로 합치지 않음

## 2. 채널 구성

| 채널 | 역할 | 운영 방식 | 성공 기준 |
| --- | --- | --- | --- |
| Meta 광고 | 운영 실무자 모집의 주 채널 | 관심사와 직무를 조합한 소액 광고, 세 가지 문제 카피 비교 | 적합한 인터뷰 신청 수 |
| Facebook 그룹 | 실무자가 사용하는 표현과 문제 사례 탐색 | 홍보 규칙 확인 후 질문형 게시물 또는 운영자 허가 요청 | 구체적인 업무 사례와 소개 |
| LinkedIn | 대표와 운영 책임자 보조 모집 | 기존 후보 직접 접촉과 소량 정밀 광고 | 구매 관점 인터뷰 확정 |
| Reddit | 문제 언어 탐색 | 광고보다 리스닝 우선, 판매성 게시 금지 | 반복 표현과 예외 사례 수집 |
| Gina 소개 | 크로스보더 및 뉴욕 레스큐 확보 | SPCA International, 뉴욕 레스큐 1~2곳 후속 | 소개 기반 인터뷰 확정 |

광고 클릭률은 보조 지표다. 주 지표는 `적합한 인터뷰 신청 수`, `예약 완료 수`, `참여자의 초기 고객군 부합률`이다.

## 3. 광고 카피 가설

### 가설 A. 임보 기록을 다시 요청하는 업무

**헤드라인**  
임보자에게 사진과 건강 기록을 다시 요청하고 계신가요?

**본문 초안**  
임보 가정의 건강·행동·사진 기록이 문자, 이메일, 스프레드시트에 흩어지는 과정을 조사하고 있습니다. 미국 동물 레스큐에서 임보 운영을 맡고 있다면 30분 인터뷰로 실제 업무를 들려주세요.

### 가설 B. 최신 상태를 한 번에 찾지 못하는 문제

**헤드라인**  
한 동물의 최신 상태를 확인하려면 몇 군데를 찾아봐야 하나요?

**본문 초안**  
CRM을 사용하면서도 위치, 의료 일정, 임보 기록을 다른 도구에서 다시 확인하는 이유를 조사하고 있습니다. 제품 판매가 아닌 업무 인터뷰입니다.

### 가설 C. 등록과 갱신의 입력 부담

**헤드라인**  
동물 한 마리를 등록하고 게시하기까지 몇 번 입력하시나요?

**본문 초안**  
반복 입력과 화면 이동이 구조·입양 업무를 얼마나 늦추는지 조사하고 있습니다. 실제로 등록과 게시 업무를 맡는 분의 경험을 찾습니다.

`Intake 9분, 37개 필드`는 내부 데모에서 확인한 특정 제품의 과업 수치다. 시장 전체 평균으로 오인할 수 있으므로 초기 광고 본문에서 제외한다.

## 4. 랜딩페이지 구성

| 순서 | 내용 | 작성 기준 |
| ---: | --- | --- |
| 1 | 문제 중심 헤드라인 | 제품명보다 실제 업무 장면을 먼저 제시 |
| 2 | 조사 목적 | 미국 쉘터·레스큐의 현재 운영 방식 조사임을 명시 |
| 3 | 참여 대상 | 조직 유형, 현재 역할, 실제 업무 범위 표시 |
| 4 | 인터뷰 방식 | 온라인 30분, 판매 미팅 아님, 녹화 여부 사전 안내 |
| 5 | 참여 신청 | 이름, 조직, 역할, 조직 규모, 임보 운영 여부, 현재 도구, 연락처 |
| 6 | 선택형 스크리닝 | 최근 한 달 안에 해당 업무를 직접 수행했는지 확인 |
| 7 | 개인정보 안내 | 수집 목적, 보관 기간, 연락과 녹화 동의 분리 |

CTA는 `데모 신청`이 아니라 `30분 업무 인터뷰 신청`으로 통일한다.

## 5. 2주 준비 일정

| 시점 | 작업 | 산출물·판정 |
| --- | --- | --- |
| 1~2일차 | 세그먼트와 세 가지 문제 가설 확정 | 광고 매트릭스 승인 |
| 3~4일차 | 광고 3종과 랜딩 초안 제작 | 내부 문구 검토 |
| 5일차 | 합성소비자 인터뷰 | 질문 이해, 신뢰 저해 표현, 신청 이탈 요인 점검 |
| 6일차 | 실제 대상자 또는 유사 직무 2명 사전 검토 | 카피와 스크리닝 수정 |
| 7일차 | 추적과 예약 흐름 점검 | 광고 클릭부터 일정 확정까지 테스트 |
| 8~12일차 | 소액 집행 | 세그먼트별 신청과 예약 기록 |
| 13일차 | 부적합 리드와 이탈 원인 검토 | 타겟과 카피 조정 |
| 14일차 | 1차 판정 | 유지, 수정, 중단 결정 |

## 6. 최소 측정표

| 단계 | 지표 | 판단 질문 |
| --- | --- | --- |
| 광고 | 노출, 클릭률, 클릭당 비용 | 어떤 문제 표현에 반응했는가 |
| 랜딩 | 방문 대비 신청률 | 참여 조건과 신뢰 설명이 충분했는가 |
| 스크리닝 | 초기 고객군 부합률 | 원하는 역할과 조직이 들어왔는가 |
| 예약 | 신청 대비 예약률 | 일정 조율과 인터뷰 조건이 장벽인가 |
| 인터뷰 | 참석률, 유효 인터뷰 수 | 실제 업무 사례를 확보했는가 |

## 7. 펫나우팀과 정할 사항

- 초기 캠페인의 1순위: 임보 운영 실무자 또는 대표·운영 총괄
- Meta 광고 집행 가능 여부와 테스트 예산
- 인터뷰 참여 보상 제공 여부
- 랜딩에 Petnow 이름과 제품 화면을 어느 수준까지 공개할지
- 개인정보 수집과 인터뷰 녹화 동의 문구의 담당 검토자
- 합성소비자 인터뷰 후 실제 광고를 시작할 날짜

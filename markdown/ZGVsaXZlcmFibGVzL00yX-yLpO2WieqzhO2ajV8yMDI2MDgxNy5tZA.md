## 한 줄 결론

M1의 리드 기반 디스커버리(LMF 1차)가 시장의 페인포인트 존재를 확인했으므로, M2는 이 축을 두 트랙으로 강화한다. **Track 1**은 1차 LMF 리드로 지불 의향과 실제 구매 전환을 확인하고(데모·PoC 유도), **Track 2**는 1차와 결이 다른 소재로 또다른 축의 페인포인트가 있는지 같은 프로세스로 검증한다. 네트워크 인터뷰는 보조 수단으로 내린다.

## 2. M2 트랙 정의

| 트랙 | 목적 | 방법 |
| --- | --- | --- |
| **Track 1** | 1차 LMF에서 확인한 페인포인트에 대해 **지불 의향과 실제 구매 전환**을 확인 | 리드 데모 콜 → 유료 PoC 유도 |
| **Track 2** | 1차와 결이 다른 소재로 **또다른 축의 페인포인트** 존재 여부 검증 | 1차 LMF 프로세스 그대로 차용, 소재만 교체 |

### 왜 이렇게 가는가

**Track 1을 지금 열어야 하는 이유**

- 1차 LMF가 답한 것은 매출까지 가는 5단계 중 1단계(문제 인식)뿐이다. 남은 광고 예산을 A·B 우열 정밀화에 써도 "돈을 내는가"에는 한 걸음도 다가가지 못한다 (중간 보고 §0)
- 리드는 광고비를 내면 계속 오지만, **한 번 만난 리드를 같은 질문으로 다시 만날 수는 없다.** 프로토콜 없이 콜을 흘려보내는 것이 지금 가장 비싼 낭비다
- M1 최대 미확인 사항 3개(초기 고객군·유료 진입 기능·월 $99 지불 의향)가 킥오프 이후 그대로다. 셋 다 인터뷰에서만 답이 나오는데 그 입구가 막혀 있다가 이제 열렸다

**Track 2를 동시에 돌려야 하는 이유**

- 1차 가설 풀은 데스크리서치와 인터뷰 1건으로 짠 약한 풀이었고, 그중 상위 2개만 시장에 물었다. 상위 2개가 통과했다는 것은 **"내부 운영 정보가 알아서 모인다"는 한 축이 통한다**는 뜻이지, 다른 축이 없다는 뜻이 아니다
- 랜딩·추적·예약·팔로업 엔진이 전부 만들어져 있어 소재 하나 추가하는 한계 비용이 낮다. 반대로 A·B에 수렴한 뒤에는 발산 실험을 다시 열기 어렵다
- 결과가 A·B보다 높든 낮든 정보다. 높으면 우선순위 재편, 동급이면 제품 범위 확장 후보, 낮으면 A·B 축에 집중할 근거. **4개 가설 모두의 좌표가 잡힌다**

**두 트랙을 병행할 수 있는 이유**

- Track 1은 사람 시간(콜)을, Track 2는 광고비를 쓴다. 리소스가 겹치지 않는다
- Track 2에서 유입되는 A·B 리드는 그대로 Track 1로 흐른다. 두 트랙이 서로를 먹인다

## 3. Track 1 — 지불 의향·구매 전환

### 3.1 대상과 흐름

- 대상: 1차 LMF 리드 전량(신청·Keep me posted 포함) + Track 2 집행 중 유입되는 리드
- 흐름: `데모 콜 30분 → 온도별 CTA → 유료 PoC 제안 → PoC 진입`
- 데모 콜은 [리드 인터뷰 가이드](Track2_리드인터뷰_가이드_20260817.md)로 통일 (통증 청취 → 데모 → 반응·지불 의향 → CTA)
- 미예약·미응답 리드는 Lead Radar 팔로업 흐름으로 회수

### 3.2 답할 것

| 질문 | 수집 지점 |
| --- | --- |
| 광고에서 반응한 통증이 실제 업무 사례로 확인되는가 | 가이드 §2 |
| 데모가 그 통증을 해소한다고 보는가 | 가이드 §5 |
| 지불 의향과 가격 범위 | 가이드 §5 (현재 지출 앵커 후 질문) |
| 유료 PoC에 들어오는가 | CTA "뜨거움" 분기 |
| ICP 규모 두 축(연간 입양·현재 임보자) | 가이드 인트로 |

- 성공 기준(데모 콜 N건 중 유료 의향·PoC 진입 M건)은 리드 유입 페이스를 보고 펫나우와 합의해 정한다
- 결과는 가설 보드 §6 갱신표와 M1 종합 보고서 부록 D로 들어간다

### 3.3 선행 결정 (펫나우)

| 항목 | 내용 |
| --- | --- |
| **PoC 상품 정의** | 데모 콜 CTA 최상단이 유료 PoC 제안인데 "들어오면 뭘 받는가"가 비어 있음. ①컨시어지형 — 체크인 요청·수집·요약을 사람+시트로 수동 운영. 개발 0, 수주 안에 시작 가능, "돈 내고 계속 쓰는가"까지 검증됨 ②개발 선행형 — MVP 후 PoC. 검증이 개발 기간만큼 후행. 마켓핏랩 의견은 ① |
| PoC 가격 | 가설 보드 실험 D의 $300~500 4주 파일럿을 출발점으로 |

## 4. Track 2 — 결이 다른 소재 2종 (F · H)

### 4.1 프로세스

1차 LMF 기획안 v1.2의 실험 설계(ICP·채널·성공 기준·조기 중단·캠페인 세팅·리드 대응·예산 스펙트럼)를 그대로 차용한다. 바뀌는 것은 소재뿐이며, A·B를 컨트롤로 함께 집행해 상대 비교는 같은 시기 실측끼리 한다. 폼 규모 문항(연간 입양·현재 임보자)은 4개 소재 모두 함께 받는다(1차 미결 종료).

### 4.2 검증 가설

| 항목 | 소재 F — H-F 신규 인력 즉시 투입 | 소재 H — H-H 오너 연결 |
| --- | --- | --- |
| 유즈케이스 | UC-9 신규 직원·봉사자 교육 | UC-16 입양 후 새 가족 체크인 (2일·10일·6주) |
| A·B와의 결 차이 | 사람이 **바뀔 때**의 비용 | 조직 **밖 사용자**(입양자)와의 연결. 유일하게 사용자가 쉘터 밖으로 확장 |
| ICE(8/9) | 60 (I5·C3·E4) | 72 (I6·C3·E4) |
| **당시 배제된 배경** | Confidence가 6→3으로 깎였다. 원래 근거가 Chameleon 리뷰의 학습곡선 불만이었는데 Chameleon을 민간 ICP 비교군에서 빼면서 근거가 통째로 사라졌고, Pawlytics엔 "배우기 쉽다" 리뷰가 다수라 시장에 반례가 있었다. Ease 4는 "새 사람이 바로 쓴다"를 증명하려면 신규 사용자 무도움 과업 테스트가 필요해 광고·데모로 보여주기 어렵다는 판단 | Confidence 3은 근거가 펫나우 내부 전언 n=2, 원문 발화가 없어서다. 정황 정합성은 있었다(ASPCA 사후 연락 권고, 파양 다수가 첫 2개월). Ease 4는 이 가설만 유일하게 사용자가 쉘터 밖(입양자)으로 확장돼 제품이 양면 플랫폼으로 바뀌기 때문. 당시 처리는 "광고도 기능도 아니고 인터뷰 질문으로만" |
| **지금 해보려는 이유** | 반례가 있는 가설을 리뷰 해석이 아니라 시장 반응으로 판정한다. 민간에서 반응 없으면 산타바바라 트랙(Chameleon 실사용)에만 남기면 된다 | 저확신 가설을 싸게 확인하는 도구가 바로 LMF 광고다. H-A도 크로스보더를 걷어내면 근거가 [Moderate]뿐이었는데 광고로 확인했다. 펫나우가 보호자용 앱을 이미 가진 회사라 경쟁 4사 대비 실현 가능성이 다른 축이기도 하다 |

- H-H는 UC-15(입양 신청)와 UC-16(입양 후 체크인) 중 **UC-16 하나로** 소재를 만든다. UC-15는 A와 거리가 좁고, 한 소재에 두 통증을 넣으면 반응 원인 판별이 안 된다

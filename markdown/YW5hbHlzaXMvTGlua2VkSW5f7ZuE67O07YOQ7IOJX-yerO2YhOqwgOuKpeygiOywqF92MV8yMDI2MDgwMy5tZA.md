# LinkedIn 인터뷰 후보 탐색·검증 표준 절차 v1

> 결론: 동일한 검색어, 탐색 순서, 판정 규칙, 증거 우선순위 및 중단 조건을 적용하여 미국 동물보호소·레스큐 인터뷰 후보 목록을 반복 생성하고, 실행 간 차이를 정량 비교하기 위한 절차임.

## 1. 적용 범위

| 항목 | 기준 |
| --- | --- |
| 조사 목적 | 미국 동물보호소·레스큐의 CRM 운영 문제 및 구매 조건 인터뷰 후보 확보 |
| 조사 대상 | 미국 소재 동물보호소·동물서비스 기관·민간 구조단체의 현직자 |
| 목표 후보 수 | 검증 완료 후보 50명 또는 아래 중단 조건 충족 시점까지 |
| 우선 역할 | 임보, 자원봉사자 운영, 입양·배치, 입소·성과, 수송, 쉘터 운영, 재무·시설, 조직 총괄 |
| 제외 대상 | 동물복지 업무가 과거 경력뿐인 사람, 개인 LinkedIn URL 미확보자, 마케팅·모금만 담당하는 사람, 미국 외 소재자 |
| 결과 단위 | 후보자 1명당 1행 |

본 절차에서 `LinkedIn 연락 가능`은 이름이 표시되는 개인 LinkedIn 프로필 URL을 확보한 상태를 의미함. 연결 신청 버튼 또는 무료 노트 발송 가능 여부는 별도 확인 항목으로 기록함.

## 5. 프로필 직접검증 절차

후보별로 아래 항목을 순서대로 확인함. 화면이 없거나 접근이 제한되면 `미확인`으로 기록하고 다른 항목에서 추정하지 않음.

1. LinkedIn 상단: 이름, 헤드라인, 지역, 현재 조직
2. 소개: 담당 업무, 전문 분야, 정량 성과, 시스템·데이터 관련 언급
3. 경력 `모두 표시`: 현재 직책, 조직, 시작일, 종료일, 고용형태, 업무 설명
4. 봉사 경력: 현재 역할이 경력인지 봉사활동인지 구분
5. 추천사: 받은 추천사 유무, 동물복지·운영 관련 추천 내용
6. 최근 활동: 최근 게시물·댓글·반응 시점과 현재 조직 관련 활동
7. 연락 가능성: 연결 신청, 메시지 또는 프로필 공개 상태

LinkedIn의 헤드라인과 경력 섹션이 충돌하면 경력 섹션을 우선함. 경력 섹션과 조직 공식 자료가 충돌하면 최신 날짜가 명확한 자료를 우선하고 충돌 내용을 `판정 주의`에 기록함.

## 6. 외부 근거 교차검증 절차

### 6.1 증거 우선순위

1. 조직 공식 개인 소개·리더십·팀 페이지
2. 정부·지자체 공식 문서 또는 조직 공식 공고
3. 최신 Form 990 원문 또는 ProPublica Nonprofit Explorer
4. 조직 공식 LinkedIn 게시물
5. 신뢰 가능한 지역 언론·전문 협회
6. LinkedIn 개인 프로필 단독

### 6.2 URL 채택 기준

- 페이지 본문에 후보 이름이 표시되는 URL만 개인 근거로 채택
- 중간 이름·자격 표기 생략은 이름 일치로 인정
- 동일 조직명만 있고 후보 이름이 없으면 개인 근거 URL에서 제외
- 검색결과 스니펫만 확인되고 원문에서 이름을 찾을 수 없으면 제외
- 여러 URL을 한 셀에 기록할 때 URL별 줄바꿈 적용
- 외부 개인 근거가 없으면 LinkedIn URL만 남기고 `LinkedIn만 확인`으로 표시

## 7. 고용형태 판정

| 판정 | 필요 증거 |
| --- | --- |
| 풀타임 직접 확인 | LinkedIn 경력의 `정규직`·`Full-time`·`Permanent Full-time`, 공식 자료의 full-time 명시, 또는 Form 990의 주 35시간 이상과 보수 확인 |
| 유급 직원 확인·시간 미확인 | Form 990 보수, 공식 채용·직원 소개 등 유급 근거는 있으나 근무시간 미확인 |
| 시간제 직접 확인 | LinkedIn `시간제`·`Part-time` 또는 공식 자료의 시간제 명시 |
| 봉사 직접 확인 | LinkedIn 봉사 경력, 공식 페이지의 volunteer 명시, Form 990 주 0시간·무보수 이사회 역할 |
| 미확인 | 직함만 확인되고 고용형태 직접 근거 없음 |

`Executive Director`, `Manager`, `Coordinator`, `Director`라는 직함만으로 정규직 또는 유급을 추정하지 않음.

## 9. 발송 우선순위 계산

아래 조건을 위에서부터 순차 적용함. 상위 조건에서 판정이 끝나면 하위 조건으로 상향하지 않음.

| 우선순위 | 판정 조건 |
| --- | --- |
| 1순위 | LinkedIn 개인 URL 확보, 미국 현직, 풀타임 직접 확인, 구매·예산 또는 운영 실무, 최근 활동 또는 공식 개인 근거 중 하나 이상 확인 |
| 2순위 | 미국 현직이며 업무 관련성은 높지만 시간제이거나 유급 직원의 근무시간 미확인 |
| 3순위 | 미국 현직 봉사자 또는 고용형태 미확인 실무자 |
| 보류 | 현재성 미확인, 관련 역할이 과거 경력이거나 최근 조직 활동을 확인하지 못함 |
| 제외 | 개인 LinkedIn URL 미확보, 미국 외 소재, 업무 관련성 낮음, 동일 후보 중복 |

우선순위 계산 근거는 `LinkedIn 연락 가능 · 현직 · 고용형태 · 역할 유형 · 근거 수준 · 최근 활동` 순으로 문장화함.

## 10. 특징 컬럼 작성

특징은 아래 순서의 최대 세 문장으로 작성함.

1. 현재 역할과 직접 확인된 핵심 업무
2. 인터뷰에서 확인할 수 있는 운영 흐름 또는 구매 관점
3. 근거 한계 또는 인터뷰에서 추가 확인할 항목

확인되지 않은 예산 권한, 이사회 지위, 임보 배치 업무 또는 시스템 사용 경험을 특징에 단정하지 않음.

## 12. 품질관리 및 중단 조건

### 12.1 후보별 완료 조건

- LinkedIn 이름·현재 조직·현재 역할 확인
- 고용형태를 직접 근거 기준으로 판정하거나 `미확인` 처리
- 주·도와 도시권 확인 또는 `미확인` 처리
- 외부 URL에서 후보 이름 확인 여부 기록
- 특징 문장과 근거 자료 간 모순 없음

### 12.2 전체 목록 완료 조건

- 후보 50명 검증 완료 또는 3절의 전체 검색어 소진
- LinkedIn URL 중복 0건
- 후보명 공란 0건
- 필수 열 공란은 `미확인`으로 치환
- 1순위 후보의 고용형태 근거 없는 사례 0건
- URL 감사 결과에서 이름 미표시 외부 URL 0건

## 13. 독립 재현성 검증 방법

독립 실행 결과를 기존 기준 목록과 아래 지표로 비교함.

| 지표 | 계산식 | 목표 |
| --- | --- | ---: |
| 후보 일치율 | 교집합 후보 수 ÷ 합집합 후보 수 | 0.70 이상 |
| 기존 목록 재현율 | 교집합 후보 수 ÷ 기존 후보 수 | 0.80 이상 |
| 1순위 정밀도 | 양쪽 모두 1순위인 후보 수 ÷ 독립 실행 1순위 후보 수 | 0.85 이상 |
| 고용형태 일치율 | 공통 후보 중 실무용 분류가 같은 후보 수 ÷ 공통 후보 수 | 0.90 이상 |
| 역할 유형 일치율 | 공통 후보 중 역할 유형이 같은 후보 수 ÷ 공통 후보 수 | 0.90 이상 |
| 지역 일치율 | 공통 후보 중 주·도가 같은 후보 수 ÷ 공통 후보 수 | 0.95 이상 |

LinkedIn 검색 개인화와 프로필 변경 때문에 후보 일치율 1.00을 목표로 하지 않음. 후보 일치율이 0.70 미만이면 검색 모집단 또는 중단 조건이 충분히 고정되지 않은 것으로 판정하고 절차를 개정함.

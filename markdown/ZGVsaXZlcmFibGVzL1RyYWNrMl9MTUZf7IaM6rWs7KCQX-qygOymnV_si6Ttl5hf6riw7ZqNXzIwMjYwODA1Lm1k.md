## 한 줄 결론

인터뷰 섭외가 진행되는 4주 동안 광고와 랜딩페이지를 병행 운영해, 미국 레스큐 운영자가 가장 강하게 반응하는 문제 소구점을 상대 클릭률로 선별한다. 1차 라운드 집행 대상은 소재 A·B 2종이다.

## 1. 목적 및 방향

- 인터뷰 대기 기간을 시장 반응 데이터 확보 기간으로 활용
- 소구점 가설을 동시에 집행해 고객 언어와 맞는 메시지 확인
- 클릭률 우세 소재에 집행 주 후반 예비 예산을 집중하고 후속 인터뷰 질문 보강
- Track 1 고객 인터뷰와 병행하며, 인터뷰를 광고 실험으로 대체하지 않음

1차 측정 지표는 클릭률(CTR, 광고 노출 대비 클릭 비율)이다. 클릭률은 구매 의향이 아니라 “제시된 문제가 나에게도 있다”는 초기 반응을 빠르게 확인하는 지표다.

## 3. 성공 판단 기준

### 3.1 소재 간 클릭률 1.5배 기준

최고 클릭률 소재가 최저 클릭률 소재보다 1.5배 이상 높으면 소구점의 방향성이 확인된 것으로 판단한다. 소재당 예상 노출 8,000~15,000회에서는 무작위 변동이 클 수 있으므로, 1.2배 수준의 차이는 판단 근거로 사용하지 않는다.

> **왜 1.5배인가 (2026-08-15 산출 근거 추가)**
> 소재당 노출 8,000~15,000회면 클릭이 88~165건이다. 클릭이 이 정도 수량이면 같은 광고를 다시 돌려도 측정되는 CTR이 **±15~25%**(p-value 0.05 기준) 위아래로 달라진다 — 표본이 작아 측정값이 참값 주위에서 튄다.
> 두 소재를 비교하면 이 흔들림이 양쪽에 겹치므로, **관측 비율이 1.24~1.34배는 돼야 유의**해지고 **참값이 1.43~1.52배는 돼야 80% 확률로 잡힌다**. 1.5배는 그 위에 잡은 보수적인 선이고, 1.2배는 흔들림과 구분되지 않는다.

### 3.2 조기 중단 기준

집행 4일 차 중간 점검에서 최저 클릭률 소재가 최고 클릭률 소재의 50% 미만이면 해당 소재를 즉시 중단하고, 남은 3일간 우세 소재에 예비 예산을 재배분한다.

### 3.3 해석 범위

- 클릭률: 문제·메시지에 대한 초기 반응
- 랜딩페이지 전환: 추가 정보를 남길 정도의 관심
- 구매 의향: 후속 인터뷰와 3단계 수렴형 실험에서 별도 확인
- 퍼소나별 차이: 소재별 리드의 직무 구성비를 비교해 퍼소나 반응 신호로 기록

- H-B 임보자 독촉 없이 기록 수집: 336점
- H-A 입양 준비 상태 판단: 240점
- H-D 신규 동물 등록 속도: 240점 — ICE 점수와 무관하게 경쟁우위 근거 부재로 1차 라운드 제외

1차 라운드는 소구점 자체의 반응을 비교하는 실험이므로 소재별로 대상을 나누지 않고 동일 오디언스에 노출한다. 퍼소나 간 반응 차이는 소재별 리드의 직무 구성비로 사후 확인하며, 우세 소구점이 확인된 뒤 3단계 수렴형 실험에서 Diane과 Alex의 역할에 맞게 문구를 분화한다.

## 7. 실행 전제

### 7.1 랜딩페이지

- Petnow 도메인 하위 경로 사용 권장: `petnow.ai/shelter-a`, `/shelter-b`, `/shelter-c`
- 소재별 독립 경로와 UTM 추적값 적용
- 공통 행동 유도 문구: 데모 신청 또는 얼리 액세스 등록

### 7.2 광고 계정

- Meta: 마켓핏랩 계정 사용. 접근 권한 확보 완료. Pixel·CAPI·전환 이벤트 검증까지 완료
- ~~LinkedIn~~: 광고 계정(`Petify for Shelter`, USD) 확보 완료. **1차 라운드 집행 제외.** 계정과 접근 권한은 유지하되 예산 미배정, Insight Tag·Lead Conversion 미생성
- 상세 절차: [Meta·LinkedIn 광고 계정 설정 가이드](Track2_광고계정_설정가이드_Meta_LinkedIn_20260805.md)

### 7.3 리드 대응

`CTA 데모 신청 → 폼 제출(Lead 전환 발생) → 날짜 부킹(폴 캘린더 연동) → 부킹 완료 화면 및 확인 메일 자동 발송` 순으로 운영한다.

폼 제출 즉시 날짜 부킹 화면을 노출해 일정 조율 단계를 제거한다. 폼 응답으로 초기 고객군 적합 여부를 자동 판정해 다음과 같이 분기한다.

| 판정 | 처리 |
| --- | --- |
| 적합 | 날짜 부킹 화면 노출(폴 캘린더 연동) → 부킹 완료 화면 → 확인 메일 자동 발송 |
| 부적합 | 감사 화면 및 자료 안내 메일. 부킹 화면 미노출 |

판정 기준은 응답자 직무, 조직 유형, 연간 입양 건수이며 사람이 개입하지 않는다.

폼은 다음 핵심 3문항을 포함한다.

1. 연간 입양 건수
2. 현재 사용하는 운영 도구
3. 가장 큰 운영 문제

실제 구현된 랜딩 폼은 위 3문항에 응답자 직무·조직 유형·임보자 수 등을 더해 13개 항목을 수집한다. 6.2의 퍼소나 사후 분류는 이 확장된 필드를 근거로 한다. 필드 정의는 [Track 2 LMF 랜딩 구현 및 이벤트 정의서](Track2_LMF_랜딩_구현_및_이벤트_정의서_20260810.md) 참조.

전환 이벤트는 폼 제출 성공 시점의 `Lead`와 부킹 완료 시점의 `Schedule`을 분리해 기록한다. 광고 최적화는 `Lead`에 건다. 부킹 완료는 전환량이 적어 최적화 기준으로 쓰면 학습이 진행되지 않으므로 측정 전용으로 사용하며, 리드 품질은 `Lead → Schedule` 전환율로 사후 확인한다.

광고 집행은 2주 차 1주로 한정한다. 소재 A·B를 동시 런칭하고 집행 4일 차 중간 점검에서 열등 소재를 중단한 뒤, 남은 3일간 우세 소재에 예비 예산을 집중한다. 예비 예산 70만 원의 소재는 이 중간 점검에서 결정한다. 기존 예비 25만 원에 LinkedIn 배정분 30만 원과 소재 C 배정분 15만 원을 합산해 이월했다. 1차 집행분을 미리 증액하지 않은 이유는 배분 근거를 중간 점검 데이터에서 확보하기 위함이며, Facebook은 클릭당 비용이 낮아 소재별 15만 원으로도 4일 내 판정 표본 확보가 가능한 것으로 판단했다.

### 8.1 Meta 캠페인 세팅 조건

타기팅은 Meta 학습에 맡기고 수동 조건은 최소화한다. 정밀도는 상세 타기팅이 아니라 리드 최적화로 확보한다. 단, 예산 배분과 크리에이티브 변형은 수동으로 고정한다. 자동화하면 소재 간 비교가 성립하지 않는다.

| 항목 | 설정 |
| --- | --- |
| 캠페인 목표 | 리드, 전환 위치 웹사이트 |
| 최적화 이벤트 | 표준 이벤트 `Lead`, 폼 제출 성공 시 1회 발생 |
| 캠페인 구조 | 소재 A·소재 B 광고 세트 2개로 분리. Meta A/B 테스트 기능으로 오디언스 무작위 분할 |
| 예산 방식 | 광고 세트별 고정 예산(ABO). 캠페인 예산 최적화(CBO) 미사용 — 알고리즘이 한쪽에 예산을 몰면 소재 비교 불가 |
| 오디언스 | Advantage+ 오디언스. 상세 타기팅·관심사·행동 미설정. 타기팅 정밀도는 최적화 이벤트가 담당 |
| 지역·언어·연령 | 미국 / 영어 / 25~65세 이상 |
| 노출 위치 | Advantage+ 배치(자동) |
| 소재 구성 | 광고 세트당 크리에이티브 2개(동일 카피, 이미지 2종). 헤드라인·본문 변형 없음 |
| Advantage+ 크리에이티브 | 사용하지 않음 — 문구를 자동 변형하면 어떤 소구점에 반응했는지 판별 불가 |
| 전환 추적 | Pixel과 CAPI 병행, 표준 이벤트 `Lead`, 동일 `event_id`로 중복 제거 |
| 어트리뷰션 | 7일 클릭, 1일 조회 |
| 학습 단계 대응 | 광고 세트당 주 50전환 미만이면 학습이 종료되지 않아 단가가 흔들림. 4일 차에 열등 소재를 중단하고 예비 예산을 우세 소재 한 세트에 집중해 전환을 모음. 학습 완료는 어려우므로 단가 절대값이 아닌 소재 간 상대 비교로만 판정 |

광고 중단과 성공 판단 기준은 [3. 성공 판단 기준](#3-성공-판단-기준) 참조.

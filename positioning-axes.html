0324PetShelter — 레코드와 거래로 구성

공개 기능 그룹 6종이 전부 레코드 또는 거래에 해당함. 화면 제목도 manage로 시작하는 형태로 일관됨.

구조의 배경 — 수익모델

  • 소프트웨어 정기 요금 없음. 입양 1건당 $5 + 입양 건당 무료 마이크로칩 + PetPlace 생태계로 수익 발생
  • 입양 건 처리가 매출 조건이므로 체크아웃·영수증·계약이 1차 출시에 포함되고, 준비 과정 관리가 후순위로 배치되는 것은 정합적 선택임
  • 향후 수개월 내 출시 예정: over-the-counter 거래 · 외부 결제수단 · 다중 아웃컴 · 계약서 유형 · 고급 권한 · 포스터 관리 · 온라인 리스팅 · 켄넬 카드

05자사 차별 요소 — 흐름이 아니라 판정

기존 서술(“단일 흐름”, “다음 행동 우선”)은 결과 기술에 해당하며, 이를 생성하는 메커니즘은 다음과 같음.

차별 메커니즘

조직이 준비 완료 기준을 직접 편집 (Health 30일 · Behavior 14일 · 공개용 사진 3장)
→ 룰이 상태를 자동 판정
→ 미충족 항목이 대기열로 전환
→ 각 행에 사유 · 담당자 · 다음 행동 부착

24PetShelter에서는 해당 판정이 성립 불가함. Ready to publish 상태가 성립하려면 게시 요건 정의가 선행되어야 하나 온라인 리스팅 자체가 미출시 상태임.

조직 외부 데이터 수집계정 불요 임보자 전용 링크 · 1탭 제출포스터 관리 자체가 미출시
대외 표현 수정 권고

“서로 다른 제품처럼 분리되지 않는다”는 ‘화면을 통합했다’로 해석될 여지가 있음. 24PetShelter도 동물 프로필 내 Animal·Adoption 탭을 병렬 배치함. 차별점은 화면 통합이 아니라 단계 간 판정이므로 “다음 단계로 진행 가능한지를 제품이 판정한다”가 방어 가능한 표현임. “정보 구조보다 다음 행동 우선”은 현행 유지.

06리스크

항목내용대응
근거 폭24PetShelter 판단은 화면 6점·공개 기능 목록 기반이며 대상은 단순 운영 조직용 초기 릴리스임. 예정 기능에 포스터 관리·온라인 리스팅 포함“현재 미제공”을 “향후에도 미제공”으로 진술하지 않음
포지션 중첩24PetShelter는 소프트웨어 요금이 없어 예산 경합이 발생하지 않음. 준비 속도 향상은 입양 건수 증가로 이어져 24Pet 매출에도 기여기존 24Pet 고객 대상 보완재 각도로 활용 가능. 동시에 해당 층의 흡수 가능성 상존
자사 진술 강도데모의 룰 계산은 고정 문자열 상태 (실물화 항목 2번)대외 커뮤니케이션에서 구현 상태와 상충되지 않는 범위로 조정

07미확인 사항

  • 24PetShelter Action Center의 실제 성격 — 작업 수행 영역 여부, 할 일 대기열 포함 여부
  • Next Due 미충족 항목의 동물 단위 집계 화면 존재 여부
  • 포스터 관리·온라인 리스팅의 출시 시점과 설계 방향
  • 공공기관 고객의 이전 가능성 — 신제품에 면허·출동·수납 기능이 없어 당분간 Chameleon 잔류 가능성이 높으며, 산타바바라 카운티 판단에 직접 영향
